50. （2分）以下说法正确的是：
%%% choices
A. 建立套接字连接的客户端和服务器端的IP地址不能相同
B. IP协议提供了可靠的主机与主机之间的数据包传输能力
C. 一个域名可以映射到多个IP，也可以不映射到任何IP
D. 为了防止内存泄漏，使用 getaddrinfo 函数获得的 addrinfo 链表只能调用
freeaddrinfo函数释放

%%% answer
答案：C、D。

解析：一个域名可以解析到多个 IP 地址，也可能暂时没有 IP 映射，故 C 正确；`getaddrinfo` 返回的 `addrinfo` 链表应由 `freeaddrinfo` 整体释放，故 D 正确。A 错在客户端与服务器可以运行在同一主机上；B 错在 IP 本身提供尽力而为的数据报服务，可靠传输由 TCP 等上层协议实现。原卷没有提供官方答案。
