19.C语言中传参n×n二维数组时，如果n是变量，应该如何传递？补全下面的汇编代码。
```
# int var_ele(size_t n, int a[n][n], size_t i, size_t j)
# { return a[i][j]; }
# hint: %rdi,%rsi,%rdx,%rcx
```
```
var_ele:
	movq	%rdx, %rax
	________________, %rax
	________________, %rax
	movl	(%rsi,%rax,4), %eax
	ret
```
%%% answer
答案：
① `imulq %rdi, %rax`
② `addq %rcx, %rax`

补全后的完整代码：
```
# { return a[i][j]; }
# hint: %rdi,%rsi,%rdx,%rcx
var_ele:
	movq	%rdx, %rax
	imulq	%rdi, %rax
	addq	%rcx, %rax
	movl	(%rsi,%rax,4), %eax
	ret
```

解析：

1. 参数寄存器（题面 `# hint:` 已给出）：`%rdi = n`、`%rsi = a`、`%rdx = i`、`%rcx = j`。
2. 传参方式：C 语言里把「n×n 的二维数组」作为参数传递时，数组名退化为**首元素指针** `int (*)[n]`，函数实际拿到的只是一个地址（即 `&a[0][0]`，存在 `%rsi`）；行宽 n 不是编译期常量，**必须作为第一个参数显式传进来**。这正是本题与定长二维数组（如 `arr_data[4][4]`，可以直接 `shlq $4, %rdi` 用移位算偏移）的区别——n 是变量时只能用乘法。
3. 寻址公式：`a[i][j]` 按行优先存放，其元素下标为 `i * n + j`，字节偏移再乘 `sizeof(int)=4`。
4. 于是三条算术指令的作用是：
   - `movq %rdx, %rax` → `%rax = i`；
   - ① `imulq %rdi, %rax` → `%rax = i * n`（64 位有符号乘法，结果取低 64 位放回 `%rax`）；
   - ② `addq %rcx, %rax` → `%rax = i * n + j`，得到元素下标；
   - `movl (%rsi,%rax,4), %eax` → 用「基址 + 变址×比例」寻址读取 4 字节：基址 `%rsi` 是数组首地址，比例 4 是 `sizeof(int)`。
5. 易错点：①处不能像定长数组那样用 `shlq`（n 未知）；两条指令的顺序不能颠倒（必须先乘 n 再加 j）；末尾寻址的比例是 4 而不是 8（元素是 `int`）；写成 `addq %rax, %rcx`（把结果放进 `%rcx`）会与后续 `%rax` 的用法对不上。
