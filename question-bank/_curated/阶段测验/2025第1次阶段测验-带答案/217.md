16.以下两组对应的C语言代码和汇编语言代码：
```
0000000000400640 <multstore>:
void multstore (long x, long y,
400640: push %rbx
long *dest)
400641: mov %rdx,%rbx
{
400644: callq 400650 <mult2>
long t = mult2(x, y);
400649: mov %rax,(%rbx)
*dest = t;
40064c: pop %rbx
}
40064d: retq
long mult2 (long a, long b)
0000000000400650 <mult2>:
{
400650: mov %rdi,%rax
long s = a * b;
400653: imul %rsi,%rax
return s;
400657: retq
}
```
（1）假设准备执行 callq 指令时，%rsp 内容为 0x110。执行完 callq 指令后，%rsp 内容、%rsp 指向的内存中的数值，以及随后执行完地址 400657 处的 retq 指令后 %rsp 的内容分别是什么？（均为十六进制）
（2）C代码中的下列变量分别保存在哪个寄存器中：
x：____　y：____　a：____　b：____　s：____
（3）汇编代码中，地址400641的指令修改了%rbx，地址400649的指令使用了%rbx，
而二者中间有过程调用call，是什么机制保证了%rbx不会被修改：
（4）如果把 C 代码中的 mult2(x,y) 改为 mult2(y,x)，汇编代码会有什么变化？
%%% answer
（1）0x108；%rsp 指向的内存中的数值为 0x400649；随后执行完地址 400657 处的 retq 指令后，%rsp 内容为 0x110。
（2）x：%rdi；y：%rsi；a：%rdi；b：%rsi；s：%rax。
（3）ABI 中规定的寄存器保存规则，要求 %rbx 是被调用者保存寄存器。
（4）需要在 call 指令之前交换 %rdi 和 %rsi 的内容。
