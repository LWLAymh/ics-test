18.考虑下面的C语言代码:
```
#define CNT 4
int arr_data[CNT][CNT] =
{{900, 901, 902, 903},
{910, 911, 912, 913},
{920, 921, 922, 923},
{930, 931, 932, 933}};
int get_digit(int x, int y)
{
return arr_data[x][y];
}
```
补全对应的汇编代码：
```
get_digit:
shlq $4, %rdi
movl arr_data(%rdi, %rsi, 4 ), %eax
```
