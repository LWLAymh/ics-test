23.（3分）阅读下面这段程序
```c
#include <stdio.h>
#include <unistd.h>
int main() {
printf("A\n");
pid_t pid = fork();
if (pid == 0) {
printf("B\n");
} else {
printf("C\n");
fork();
}
printf("D\n");
return 0;
}
```
该程序正常运行后，问
（1）会输出几次 D：____ 次

（2）B 和 C 哪个先输出：____

（3）`ACDBDD` 这个输出序列是否可能：____
%%% answer
第 1 空：3；第 2 空：不确定；第 3 空：是。
