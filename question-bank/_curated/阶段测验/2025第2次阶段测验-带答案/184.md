15.（4分）下面这段代码哪些地方体现了局部性原理？分别体现了什么类型的局部性。
```
int sum_array_rows(int a[M][N])
{
int i, j, sum = 0;
for (i = 0; i < M; i++)
for (j = 0; j < N; j++)
sum += a[i][j];
return sum;
}
```
答：共四种情况：指令、数据；空间、时间局部性。各1分:1）顺序执行的指令序列，
体现空间局部性；2）循环内部指令会反复执行，体现时间局部性；3）sum等变量反复被
读写，体现时间局部性；4）数组a中的数据按地址依次被读取，体现空间局部性。
