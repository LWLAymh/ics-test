10. 对如下两个 C 程序，分别用 GCC 生成对应的 `.o` 模块，再链接得到可执行程序 `a.out`。下列说法正确的是：

`main.c`：

```c
#include <stdio.h>

static int a;

int main() {
    int *func();
    printf("%ld\n", func() - &a);
    return 0;
}
```

`util.c`：

```c
int a = 0;

int *func() {
    return &a;
}
```
%%% choices
A. 在 `main.o` 中，符号 `a` 位于 `.COMMON` 伪节
B. 在 `util.o` 中，符号 `a` 位于 `.COMMON` 伪节
C. 无论怎样链接和运行 `a.out`，输出结果都相同，但一定不为 0
D. 以上说法都不正确
%%% answer
答案：D。
