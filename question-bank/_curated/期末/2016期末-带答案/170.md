9.  对于以下一段代码，可能的输出为：
```
   int count = 0;
    int pid = fork();
    if (pid == 0){
        printf("count = %d\n",--count);
    }
    else{
        printf("count = %d\n",++count);
    }
    printf("count = %d\n",++count);
A.1 2 -1 0       B.0 0 -1 1
C.1 -1 0 0       D.0 -1 1 2
```
%%% answer
答案:A(printf从后向前处理，注意fork出的子进程与父进程执行顺序不确定)
