8.  C 源文件 m1.c 和 m2.c 的代码分别如下所示，编译链接生成可执行文件后执行，结果最可能为 (  )

```
$ gcc –o a.out m2.c m1.c ; ./a.out
0x1083020
```

```c
// m1.c
#include <stdio.h>

int a1 ;
int a2 = 2 ;
extern int a4 ;

void hello()
{
    printf("%p ", &a1);
    printf("%p ", &a2);
    printf("%p\n", &a4);
}
```

```c
// m2.c
int a4 = 10 ;

int main()
{
    extern void hello() ;

    hello() ;
    return 0 ;
}
```
%%% choices
A. `0x1083018, 0x108301c`
B. `0x1083028, 0x1083024`
C. `0x1083024, 0x1083028`
D. `0x108301c, 0x1083018`
%%% answer
答案：D（a2和a4在.data中, a1在.bss中, 按照布局, .data地址比.bss
要小, 又由于m2.c的编译先于m1.c, 故选D不选A ）
