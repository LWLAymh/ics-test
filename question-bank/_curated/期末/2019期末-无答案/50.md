1.  已知浮点运算表达式：

```c
t = a + b; x = t + c; y = d + t;
```

下列表达式中，x, y不能都得到相同的计算结果的是：
%%% choices
A. `x = a + b + c; y = d + a + b;`
B. `x = a + b + c; y = d + (a + b);`
C. `x = c + (a + b); y = a + b + d;`
D. `x = (a + b) + c; y = d + (a + b);`
%%% answer
答案：A（来源：2019、2020期末-答案解析）
解析：唯有这一项会先算 d+a（`b` 与 `d` 先相加），破坏了与题设 `t=a+b` 相同的结合顺序。
