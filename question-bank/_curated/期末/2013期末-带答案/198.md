16、已知如下代码段
```
write(fd1, str1, strlen(str1));
write(fd2, str2, strlen(str2));
```
可以在原本为空的文件ICS.txt中写下字符串 I love ICS!
对于下面这些对于变量fd1, fd2, str1, str2的定义：
```
(1)
int fd1 = open("ICS.txt", O_RDWR);
int fd2 = open("ICS.txt", O_RDWR);
char *str1 = "I love ";
char *str2 = "ICS!";
(2)
int fd1 = open("ICS.txt", O_RDWR);
int fd2 = dup(fd1);
```
