11. 下面是一段C程序代码：
```
#include <stdio.h>
#include "csapp.h"
int main()
{
  printf("2");
  if (Fork())
  {
    printf("33");
    Write(STDOUT_FILENO, "lol", 3);
  }
  else
  {
    Sleep(1);
    printf("233");
    Write(STDOUT_FILENO, "hhhh", 4);
  }
  fflush(stdout);
  return 0;
}
```
编译后运行程序，程序正常退出。那么程序的输出是：
%%% choices
A.  233lol233hhhh
B.  lol233hhhh2233
C.  233lol2233hhhh
D.  2lol33hhhh233
%%% answer
答案：B。
说明：`printf` 所属的标准 IO 是有缓冲区的，直到关闭文件、遇到换行符或者
`fflush`时才会输出；write则没有缓冲区立刻输出。
