9.  在系统调用成功的情况下，下面哪个输出是可能的？
```
int main() {
  int pid = fork();
  if (pid == 0) {
    printf("A");
  } else {
    pid = fork();
    if (pid == 0) {
      printf("A");
    } else {
      printf("B");
    }
  }
  exit(0);
}
```

%%% choices
A. AAB
B. AAA
C. AABB
D. AA
%%% answer
答案：A
总共有3个进程（父进程和两个子进程），共输出2个A和1个B。
