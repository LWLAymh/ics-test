答案：（1 每空1分共8分；2 全对得2分，有错得0分，部分对得1分）
(1) 
| 协议 | 数据包类型 | 软件实现 |
| --- | --- | --- |
| HTTP | Web content | User code |
| TCP | Streams (end to end) | Kernel code |
| IP | Datagrams | Kernel code |

(2) 正确的是 **B、C、F**（原卷答案「B, C, F」）。
- B：套接字在 Unix 里就是一个文件描述符（文件标识符）。
- C：IP 地址标识的是主机的网络适配器（network interface card），
  一台主机有多个适配器就有多个 IP 地址。
- F：Internet（因特网）是一个特定的 internet（互连网络），
  即「Internet 是一种 internet」。

解析：
**(1) 协议栈自上而下的对应关系（原卷答案，见 `原文` 第 783–789 行）**
- **HTTP** 是应用层协议，它传输的「数据包类型」就是 **web content**
  （网页内容），其实现完全在**用户态**（User code，浏览器/服务器进程里的库与
  应用程序代码）。
- **TCP** 是传输层协议，向上提供**端到端的字节流**（Streams (end to end)），
  其实现位于**内核**（Kernel code，TCP/IP 协议栈在内核里）。
- **IP** 是网络层协议，提供的是**数据报**（Datagrams）服务，同样在**内核**里实现。
- 关键词里 `UDP` 也是传输层/数据报式，但题目只让填 web 应用自上而下的三层
  （HTTP/TCP/IP），故不填；`Kernel code` 与 `User code` 各自可被多次填入。

**(2) 六个选项判断**
- **A. 错。** 服务器是用 `listenfd`（监听套接字）**接受**连接：每 `accept` 一次
  会返回一个**新的 connfd**，真正与该 client 通信的是这个 connfd。
  「用 listenfd 和多个 client 同时通信」的说法不准确（listenfd 只负责接受连接）。
- **B. 对。** socket 在 Unix/Linux 里就是文件描述符（`open`/`accept` 都返回
  文件描述符），可以用 Unix I/O 读写。
- **C. 对。** 准确地说，IP 地址标识的是**网络适配器**（网卡/NIC），不是主机本身
  —— 一台主机可以有多张网卡、多个 IP 地址。
- **D. 错。** Web 是**基于 HTTP 协议的互联网应用**（应用/服务），
  HTTP 才是协议；Web 本身不是协议。
- **E. 错。** 域名与 IP 不是一一对应：一个域名可以对应多个 IP（如负载均衡），
  一个 IP 也可以对应多个域名（虚拟主机、一个 IP 上跑多个站点）。
- **F. 对。** 专有名词 Internet（因特网）是一个具体的 internet（互连网络），
  即「Internet 是一种 internet」。
