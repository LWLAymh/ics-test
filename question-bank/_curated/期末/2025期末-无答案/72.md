3. 对任意 `unsigned int x`，定义：

```c
unsigned int y = (x >> 5) << 5;
```

下列说法哪些正确？
%%% choices
A. `y == (x & ~31u)`
B. `y <= x`
C. `x - y` 的取值一定在 `[0, 31]`
D. 若 `x` 是 32 的倍数，则 `y == x`
E. 若 `x` 不是 32 的倍数，则 `y == x + 1`
%%% answer
答案：A、B、C、D

表达式会清零 `x` 的低 5 位，因此 E 错误：`y` 是 `x` 减去其低 5 位表示的余数，而不是 `x + 1`。
