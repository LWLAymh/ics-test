21.执行下面的C程序代码
```c
int *p = malloc(sizeof(int));
*p = 10;
pid_t pid = fork();
if (pid == 0) {
    *p = 20;
    _exit(0);
}
wait(NULL);
printf("%d\n", *p);
```
下列说法哪些正确？
%%% choices
A. 输出一定为 20
B. 输出一定为 10
C. 输出有可能是10，也有可能是20，取决于进程调度顺序
D. fork之后，父进程由于Copy-on-Write可能会发生缺页异常
E. fork之后，子进程由于Copy-on-Write可能会发生缺页异常
%%% answer
答案：BE
解析：fork 后父子地址空间逻辑上独立，但常用 COW 让它们先共享物理页；一方写入时再复制，因此父仍读到 10，而子写可能触发一次“为了复制而产生”的 fault。改成共享匿名映射则写入可见。
