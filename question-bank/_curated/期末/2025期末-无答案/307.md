21.执行下面的C程序代码
```
int *p = malloc(sizeof(int));
*p = 10;
pid_t pid = fork();
if (pid == 0) { *p = 20; _exit(0); }
wait(NULL);
printf("%d\n", *p);
```
下列说法哪些正确？
%%% choices
A. 输出一定为 20
B. 输出一定为 10
C. 输出有可能是10，也有可能是20，取决于进程调度顺序
D. fork之后，父进程由于Copy-on-Write可能会发生缺页异常
E. fork之后，子进程由于Copy-on-Write可能会发生缺页异常
