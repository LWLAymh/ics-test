三 链接相关主题（10分）
本题基于下列两个 C 语言文件编译生成的 `main.o` 和 `sum.o`，编译和运行
在 x86-64/Linux 环境下完成，未开启优化选项。
```c
// main.c
#include <stdio.h>
extern int sum_array(int *arr, int n);
int arr[5] = {1, 2, 3, 4, 5}, result;
static int fix = 2010;
int main() {
    result = sum_array(arr, 5)+fix;
    printf("sum = %d\n", result);
    return 0;
}
```

```c
// sum.c
int sum_array(int *arr, int n) {
    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum += arr[i];
    }
    return sum;
}
```
校对说明：原卷该处印作 `res1`，但前文声明并赋值的是 `result`；按上下文校为 `result`，原卷疑似笔误。
