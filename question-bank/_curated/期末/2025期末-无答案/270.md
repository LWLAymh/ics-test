19.观察下面的C程序代码：
```
volatile sig_atomic_t count = 0;
void h(int sig){ count++; }
int main(void){
sigset_t m;
```


```
sigemptyset(&m);
sigaddset(&m, SIGINT);
Signal(SIGINT, h);
sigprocmask(SIG_BLOCK, &m, NULL);
```
raise(SIGINT);// raise()用于向当前进程发出指定信号
```
raise(SIGINT);
sigprocmask(SIG_UNBLOCK, &m, NULL);
printf("%d\n", (int)count);
}
```
该程序正常执行完，下列说法哪些正确？
%%% choices
A. count 一定为 0
B. count 一定为 1
C. count 可能为 2
D. 在解除阻塞之前，handler可能会运行
E. 在设置阻塞之前，handler可能会运行
%%% answer
答案：B
解析：普通信号（非实时信号）通常不排队：阻塞期间同种信号 pending 只记一次，因此解除阻塞后 handler 只会跑一次，解除阻塞前不会递送（D 错）。（答案表原文此处附注“B/E 对”，与所给答案 B 不一致，以答案行 B 为准。）
