19. 观察下面的 C 程序代码。假设程序运行期间没有收到外部发送的 `SIGINT`：

```c
volatile sig_atomic_t count = 0;

void h(int sig) {
    count++;
}

int main(void) {
    sigset_t m;
    sigemptyset(&m);
    sigaddset(&m, SIGINT);
    Signal(SIGINT, h);
    sigprocmask(SIG_BLOCK, &m, NULL);
    raise(SIGINT);  // raise() 向当前进程发送指定信号
    raise(SIGINT);
    sigprocmask(SIG_UNBLOCK, &m, NULL);
    printf("%d\n", (int)count);
}
```

该程序正常执行完，下列说法哪些正确？
%%% choices
A. `count` 一定为 0
B. `count` 一定为 1
C. `count` 可能为 2
D. 在解除阻塞之前，handler 可能会运行
E. 在设置阻塞之前，handler 可能会运行
%%% answer
答案：B

普通信号不排队。阻塞期间连续两次 `raise(SIGINT)` 只留下一个待处理的 `SIGINT`；解除阻塞后 handler 执行一次，因此 `count` 为 1。题面明确排除了外部 `SIGINT`，从而消除原答案稿对选项 E 的歧义。
