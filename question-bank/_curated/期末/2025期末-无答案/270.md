19. 观察下面的 C 程序代码：

```c
volatile sig_atomic_t count = 0;

void h(int sig) {
    count++;
}

int main(void) {
    sigset_t m;
    sigemptyset(&m);
    sigaddset(&m, SIGINT);
    Signal(SIGINT, h);
    sigprocmask(SIG_BLOCK, &m, NULL);
    raise(SIGINT);  // raise() 向当前进程发送指定信号
    raise(SIGINT);
    sigprocmask(SIG_UNBLOCK, &m, NULL);
    printf("%d\n", (int)count);
}
```

该程序正常执行完，下列说法哪些正确？
%%% choices
A. `count` 一定为 0
B. `count` 一定为 1
C. `count` 可能为 2
D. 在解除阻塞之前，handler 可能会运行
E. 在设置阻塞之前，handler 可能会运行
%%% answer
答案：B

答案册给出 B。阻塞期间连续两次 `raise(SIGINT)` 只留下一个待处理的 `SIGINT`；解除阻塞后 handler 执行一次。原卷没有说明是否会在设置阻塞前收到外部 `SIGINT`：若收到，handler 可先运行一次，解除阻塞后还会处理一次待决信号，因此题面存在歧义；答案册的 B 隐含了“不考虑外部信号”的假设。
