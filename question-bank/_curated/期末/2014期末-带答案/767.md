第七题（10分）系统 I/O

请阅读下面的代码：

```c
int main(int argc, char **argv) {
    int fd1 = open("ICS.txt", O_CREAT | O_RDWR,
                   S_IRUSR | S_IWUSR);
    write(fd1, "abc", 3);

    int fd2 = fd1;
    int fd3 = dup(fd2);
    int fd4 = open("ICS.txt", O_APPEND | O_RDWR);
    write(fd2, "defghi", 6);
    write(fd4, "xyz", 3);

    int fd5 = fd4;
    dup2(fd3, fd5);
    write(fd4, "pqr", 3);

    close(fd1);
    return 0;
}
```

1. 在 `close(fd1)` 刚执行完后，请填写打开文件表和 v-node 表中有关表项的 `pos`、`refcnt`、是否释放等信息，并画出描述符表、打开文件表和 v-node 表之间的指向关系。（6分）

初始时 `ICS.txt` 不存在；所有系统调用均成功；表项从上到下依次分配；描述符表的前 3 个表项初始已被占用。对于已经释放的打开文件表项，请填写其释放前一刻的值和所指向的 v-node 表项。
%%% answer
参考答案：

- 描述符 `3` 已关闭。
- 描述符 `4`、`5` 都指向第一次 `open` 创建的打开文件表项；该表项 `pos = 12`、`refcnt = 2`，未释放，并指向 `ICS.txt` 的 v-node 表项。
- 第二次 `open` 创建的打开文件表项在 `dup2(fd3, fd5)` 时被释放；释放前 `pos = 12`、`refcnt = 0`，也指向 `ICS.txt` 的同一个 v-node 表项。

关键关系如下：

| 描述符 | 打开文件表项 | `pos` | `refcnt` | 已释放 | v-node |
| ---: | --- | ---: | ---: | --- | --- |
| 4 | 表项 1 | 12 | 2 | 否 | `ICS.txt` |
| 5 | 表项 1 | 12 | 2 | 否 | `ICS.txt` |
| — | 表项 2 | 12 | 0 | 是 | `ICS.txt` |

请根据表项数值与指向关系自评。
