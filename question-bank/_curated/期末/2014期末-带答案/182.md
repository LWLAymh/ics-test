12. 下列这段代码的输出不可能是(      )
```
void handler()
{
    printf("h");
}
int main()
{
    signal(SIGCHLD, handler) ;
    if ( fork() == 0 ) {
        printf("a") ;
    } else {
        printf("b") ;
    }
    printf("c") ;
    exit(0) ;
}
A. abcc   B. abch    C. bcach    D. bchac
```
【答案】Ｄ
【说明】SIGCHLD信号只有在fork的子进程结束时产生，因此h只会出现在ac
之后。
