12. 下列这段代码的输出不可能是(      )
```
void handler()
{
    printf("h");
}
int main()
{
    signal(SIGCHLD, handler) ;
    if ( fork() == 0 ) {
        printf("a") ;
    } else {
        printf("b") ;
    }
    printf("c") ;
    exit(0) ;
}
```
%%% choices
A. abcc
B. abch
C. bcach
D. bchac
%%% answer
答案：D
【说明】`SIGCHLD`信号只有在`fork`的子进程结束时产生，因此`h`只会出现在ac
之后。
