答案：
（1）`c(b(a(1))) = 0x800000`
（2）`a(b(c(1))) = 0`

解析（原卷自带答案，此处补全推导）：
`d[256]` 就是**8 位比特反转表**：`d[x]` 把 x 的 8 个比特整个反过来
（`d[1] = 0x80`、`d[0x80] = 1`、`d[0x0F] = 0xF0` …）。
三个函数都是**按字节/半字/字做整数的比特反转**：
- `a(x) = d[x]`：8 位内反转比特；
- `b(x) = (a(x & 0xff) << 8) | a(x >> 8)`：把低字节与高字节交换、各自再反转比特
  ⇒ 16 位整数的比特反转；
- `c(x) = (b(x & 0xffff) << 16) | b(x >> 16)`：两个半字交换、各自再做 16 位反转
  ⇒ 32 位整数的比特反转。

（1）逐步算：
- `a(1) = d[1] = 0x80`
- `b(0x0080)`：低字节 0x80、高字节 0x00 ⇒ `(a(0x80) << 8) | a(0x00)`
  `= (0x01 << 8) | 0x00 = 0x0100`
- `c(0x00000100)`：低半字 0x0100、高半字 0x0000 ⇒ `(b(0x0100) << 16) | b(0x0000)`
  `= (0x0080 << 16) | 0x0000 = 0x800000`
⇒ **`c(b(a(1))) = 0x800000`**，与原卷答案一致。

（2）逐步算：
- `c(1)`：低半字 0x0001、高半字 0x0000
  ⇒ `(b(0x0001) << 16) | b(0x0000)`，其中 `b(0x0001) = (a(0x01) << 8) | a(0x00) = 0x0100`
  ⇒ `c(1) = 0x0100 << 16 = 0x01000000`
- `b(0x01000000)`（unsigned short 形参，取低 16 位 0x0000 与高 16 位 0x0100）
  ⇒ `(a(0x00) << 8) | a(0x0100)`；`a` 的形参是 unsigned char，0x0100 截断为 0x00
  ⇒ `0x00 | d[0x00] = 0`
- `a(0) = d[0] = 0`
⇒ **`a(b(c(1))) = 0`**，与原卷答案一致。

> 备注：`b`/`c` 的语义就是「对本宽度的整数做完整比特反转」（字节序交换 + 逐字节
> 反转比特）。第（1）问把 1 放在 32 位里反转落在 bit24（= 0x800000），第（2）问
> 反转后被 `a` 截到低 8 位，结果为 0。
