10. 在系统调用成功的情况下，下列代码会输出几个`hello`？(      )
```
void doit()
{
if ( fork() == 0 ) {
        printf("hello\n");
        fork();
    }
    return ;
}
int main()
{
    doit();
    printf("hello\n");
    exit(0) ;
}
```
%%% choices
A. 3
B. 4
C. 5
D. 6
%%% answer
答案：B
【说明】考查学生对`fork`执行机制的理解和掌握。
