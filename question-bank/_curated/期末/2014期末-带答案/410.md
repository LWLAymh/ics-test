解析（原卷自带答案，此处补全推导）：
**反汇编格式与汇编格式的区别**：objdump 输出的是 AT&T 语法，寄存器带 `%`、立即数
带 `$`、指令不带后缀（`movzbl`/`mov` 这种带宽度后缀的写法本身就来自 objdump）。
本题每空要填的是**操作数**：寄存器操作数写 `%eax` 这种带 `%` 的形式，立即数要写成
`$0x8`（带 `$`，与原卷答案一致）。

函数 `b(unsigned short x)` 的实现是：
```
return (a(x & 0xff) << 8) | a(x >> 8);
```
即「低字节查表后放到高 8 位，高字节查表后放到低 8 位」。

对 `b`：
- `mov %edi,%eax`：eax = x（低 16 位有效）。
- `movzbl %dil,%edx`：edx = x 的低字节。
- `movzbl 0x6009a0(%rdx),%edx`：edx = d[x & 0xff] = a(x & 0xff)。
- `movzbl %ah, (1)`：`%ah` 是 eax 的次低字节，正是 x 的高字节；下一步要用
  `0x6009a0(%rax)` 以它为下标查表，所以它必须被放进 **%eax**
  ⇒ **(1) = %eax**（`movzbl %ah,%eax` 会把 eax 变成高字节的零扩展值）。
- `movzbl 0x6009a0(%rax),%eax`：eax = d[x >> 8] = a(x >> 8)。
- `shl (2),%edx`：把先算出的那一项左移 8 位（放进高字节）⇒ **(2) = `$0x8`**。
- `or %edx,%eax`：合并成 16 位结果。

对 `c`：
```
return (b(x & 0xffff) << 16) | b(x >> 16);
```
- `mov %edi,%eax`：eax = x。
- `push (3)` …… 后面 `pop (3)`：因为要用 `%bh`（只能用 ebx 的次低字节）暂存 x 的
  第二个字节，必须先保护调用者保存寄存器 %rbx ⇒ **(3) = %rbx**（注意是 64 位名）。
- `mov %edi,%ebx`：ebx = x。
- `shr (4),%eax`：eax = x >> 16（取高半字，供内层 `b` 用）⇒ **(4) = `$0x10`**。
- `movzbl %bh,%ebx`：ebx = (x >> 8) & 0xff = 第二个字节（内层 `b` 的第二项下标）。
- `movzbl %al, (5)`：%al 是 `x >> 16` 的低字节；接下来
  `movzbl 0x6009a0(%rdx),%edx` 以它为下标查表 ⇒ 应送进 **%edx** ⇒ **(5) = %edx**。
- `movzbl %ah, (6)`：`x >> 16` 的高字节；后面 `movzbl 0x6009a0(%rax),%eax`
  以它为下标 ⇒ 应送进 **%eax** ⇒ **(6) = %eax**。
- `shl (7),%edx`：把第一项左移 8 位 ⇒ **(7) = `$0x8`**。
- `or %edx,%eax`：得到内层 `b(x >> 16)`。
- `movzbl %dil,%edx` / `movzbl 0x6009a0(%rdx),%ecx`：ecx = a(x & 0xff)。
- `movzbl 0x6009a0(%rbx),%edx`：edx = a((x >> 8) & 0xff)。
- `movzwl %ax,%eax`：把刚算好的内层结果截成 16 位。
- `shl $0x8,%ecx` / `or %ecx,%edx`：拼出 `b(x & 0xffff)`。
- `shl $0x10,%edx` / `or %edx, (8)`：把 `b(x & 0xffff)` 移到高 16 位后与
  `b(x >> 16)`（此刻在 %eax）合并 ⇒ **(8) = %eax**。
