14. 有程序段如下：


```
int foo( ) {
  char str1[20], *str2;
  str2 = (char*)malloc(20*sizeof(char));
  free(str2);
}
```
下列说法中正确的是(      )
%%% choices
A. str1和str2指向的内存都是分配在栈空间内的
B. str1和str2指向的内存都是分配在堆空间内的
C. str1指向的内存是分配在栈空间内的，str2指向的内存是分配在堆空间内的
D. str1指向的内存是分配在堆空间内的，str2指向的内存是分配在栈空间内的
【答案】Ｃ
【说明】考察malloc函数是显式地分配和释放堆存储器
%%% answer
答案：C
考察malloc函数是显式地分配和释放堆存储器。
