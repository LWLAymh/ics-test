20. 某进程的主线程和对等线程的代码如下所示：
```
sem_t sem;
int main(void) {
    int i;
    pthread_t tids[3];
    sem_init(&sem, 0, 1);
    for (i = 0; i < 3; i++) {
        pthread_create(&tids[i], NULL, thread, NULL);
    }
    for (i = 0; i < 3; i++) {
        pthread_join(&tids[i], NULL);
    }
    return 0;
}
int y = 15;
void *thread(void *arg) {
    P(&sem);
    y = y - 3;
    V(&sem);
    printf("%d\n", y);
}
```
  执行上述代码后，会产生多少种不同的输出？
%%% choices
A. 11
B. 12
C. 13
D. 14
%%% answer
答案：原题选项无正确答案；按程序语义共有 **5 种不同的输出序列**。

解析：`y -= 3` 在信号量保护下依次执行三次，`y` 依次变为 12、9、6；每次 `printf` 在临界区外读取当时的共享 `y`。因此：

- 在第二次递减前打印的值只能是 12，至多出现一次；
- 在第三次递减前打印的值只能是 9，最多出现两次；
- 第三次递减完成后尚未打印的线程都读到 6，且至少有一个线程此时才打印。

打印值的顺序只能是若干个 12、随后若干个 9、最后若干个 6。所有可行序列为：`6 6 6`、`9 6 6`、`9 9 6`、`12 6 6`、`12 9 6`，共 **5 种**。选项 11、12、13、14 均不正确，本题应标为无正确选项。
