7.  C源文件f1.c 和 f2.c的代码分别如下所示：
```
// f1.c
#include <stdio.h>

void f(void);
int x;

int main(void) {
    x = 1;
    f();
    printf("%x\n", x);
    return 0;
}

// f2.c
float x;

void f(void) {
    x = 2;
}
```
运行下面的命令后得到的结果是:
```
$ gcc f1.c f2.c
$ ./a.out
```
%%% choices
A. 1
B. 2
C. 3f800000
D. 40000000
%%% answer
答案：D
解析：f1.c 的 int x 与 f2.c 的 float x 都是未初始化的全局变量（COMMON 弱符号），链接器把它们合并成同一个 4 字节符号；f() 写入的是浮点 2.0（位模式 0x40000000），main 再按 int 以 %x 打印就得到 40000000。
