3. 对任意 unsigned int x，定义：
```c
unsigned int y = (x >> 5) << 5;
```
下列说法哪些正确？
%%% choices
A. `y == (x & ~31u)`
B. `y <= x`
C. x - y 的取值一定在 [0, 31]
D. 若 `x` 是 `32` 的倍数，则 `y == x`
E. 若 `x` 不是 `32` 的倍数，则 `y == x + 1`
%%% answer
答案：A, B, C, D
（清零低 5 位；E 错在不是 +1 而是减去低 5 位形成的余数）
