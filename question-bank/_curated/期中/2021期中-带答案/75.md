2.函数g定义如下：
```
int g(float f){
union {
float f;
int i;
} x;
x.f = f;
return x.i ^ ((1u << (x.i < 0 ? 31 : 0)) - 1);
}
```
则对于两个float型变量a,b，有a<b是g(a)<g(b)的:B

当a，b有意义时，a<b与g(a)<g(b)等价，而当a与b是NaN或者正负0时，
g(a)<g(b)无法推出a<b。
