20. 以下哪些程序优化编译器总是可以自动进行？（假设int i, int j, int
A[N], int B[N], float m都是局部变量，N是一个整数型常量，int
foo(int) 是一个函数）
请判断下列哪一项“优化前”到“优化后”的转换总是可以自动进行。
A.

优化前：
```c
for (j = 0; j < N; j++)
    m += i * N * j;
```

优化后：
```c
int temp = i * N;
for (j = 0; j < N; j++)
    m += temp * j;
```
B.

优化前：
```c
for (j = 0; j < N; j++)
    B[i] *= A[j];
```

优化后：
```c
int temp = B[i];
for (j = 0; j < N; j++)
    temp *= A[j];
B[i] = temp;
```

C.

优化前：
```c
for (j = 0; j < N; j++)
    m = (m + A[j]) + B[j];
```

优化后：
```c
for (j = 0; j < N; j++)
    m = m + (A[j] + B[j]);
```

D.

优化前：
```c
for (j = 0; j < foo(N); j++)
    m++;
```

优化后：
```c
int temp = foo(N);
for (j = 0; j < temp; j++)
    m++;
```

%%% choices
A. 第一项转换
B. 第二项转换
C. 第三项转换
D. 第四项转换
%%% answer
原卷答案：A

原卷说明：考察 procedure、memory aliasing 和 floating 的精度问题。

> ⚠️ 原题存在歧义：题干明确把 `A[N]` 与 `B[N]` 写成两个局部数组，按 C
> 语言中不同数组对象互不重叠的字面理解，B 项将 `B[i]` 暂存在局部变量中也可能被认为
> 是安全的。这里仍按原卷公布的答案 A 判分；这条说明用于提示题目本身的假设与官方解释
> 并不完全一致。
