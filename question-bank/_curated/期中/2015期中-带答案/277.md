第二题（20分）
1.对于下面的每一个表达式，请选择以下选项中的一个或多个（即“不定项”），使
得该表达式恒成立，如果没有满足条件的选项则选E。
A.  <       B.  >       C.  ==      D.  !=       E.  none
题目中出现的变量定义如下（浮点数保证不是NaN或者Inf）:
```
int x, y;
unsigned ux = x;
double d;
```
1) 如果x > 0, 则 x + 1      0
2) 如果 x > y, 则 ux       y
3) 如果 ($(x << 31)$ >> 31) < 0, 则x & 1       0
4) 如果((unsigned char)x >> 1) < 64， 则(char)x      0
5) 如果d < 0， 则d * 2      0
6) 如果d < 0, 则 d * d      0
```
7) x ˆ y ˆ (˜x) - y       y ˆ x ˆ (˜y) - x
8) (((!!ux)) << 31) >> 31)       (((!!x) << 31) >> 31)
```

分）
