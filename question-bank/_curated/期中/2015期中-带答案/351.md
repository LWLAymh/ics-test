第三题（20分）
1.考虑下面的union的声明，回答后面的问题。
```
union ELE {
  struct {
    int x;
    int *p;
  }e1;
  struct {
    union ELE * next;
    int y;
  }e2;
};
```
(注：32位机器)
这个 union 总共大小为多少{{blank:union-size}}字节？（2分）
%%% answer
答案：8 字节（32 位机器上 e1 占 4+4=8 字节，e2 占 4+4=8 字节，union 取较大者）
