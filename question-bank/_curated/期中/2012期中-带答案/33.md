3. Consider the following code, what is the output of the printf? **(m-f10-a 1-1)**

```c
int x = 0x15213F10 >> 4;
char y = (char) x;
unsigned char z = (unsigned char) x;
printf("%d, %u", y, z);
```
%%% choices
   a) -241, 15
   b) -15, 241
   c) -241, 241
   d) -15, 15
%%% answer
答案：B
`x = 0x15213F10 >> 4 = 0x015213F1`；`y = (char)x = 0xF1 = -15`；`z = (unsigned char)x = 0xF1 = 241`。
