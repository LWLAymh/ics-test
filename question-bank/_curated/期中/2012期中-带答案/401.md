   b) Please write a single line of C code to represent the instruction mov (%rdi,%rax,4),%eax (Use
      C variables named rdi and rax, you can ignore types).
%%% answer
答案：`eax = *(rdi + rax)`（rdi is int *）；`eax = *(rdi + 4 * rax)`（rdi is char *）
