**Problem E -- The Hit or Miss Question (15 pts)**

Given a 32-bit Linux system that has a 2-way associative cache of size 128 bytes with 32 bytes
per block. Long longs are 8 bytes. For all parts, assume that table starts at address 0x0.

```c
int i;

int j;

long long table[4][8];

for (j = 0; j < 8; j++) {

    for (i = 0; i < 4; i++) {

        table[i][j] = i + j;

    }

}
```

**A.** This problem refers to code sample 1. In the table below write down in each space whether that
element’s access will be a hit or a miss. Indicate hits with a ‘H’ and misses with a ‘M’.

| | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 0 |  |  |  |  |  |  |  |  |
| 1 |  |  |  |  |  |  |  |  |
| 2 |  |  |  |  |  |  |  |  |
| 3 |  |  |  |  |  |  |  |  |


What is the miss rate of this code sample?
%%% answer

| | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 0 | M | M | M | M | M | M | M | M |
| 1 | M | M | M | M | M | M | M | M |
| 2 | M | M | M | M | M | M | M | M |
| 3 | M | M | M | M | M | M | M | M |
