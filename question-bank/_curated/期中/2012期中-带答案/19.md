2. For which values can X not be equal to Z in the code below (circle all that apply) **(f-f09 1-B)**

```c
int X = CONSTANT;
float Y = X;
int Z = Y;
```
%%% choices
   a) For large positive values of CONSTANT (e.g.,>1,000,000,000)
   b) For large negative values of CONSTANT (e.g.,>-100)
   c) For small positive values of CONSTANT (e.g.,<100)
   d) For small negative values of CONSTANT (e.g.,<-1,000,000,000)
   e) None of the above (i.e., X==Z in all of these cases)
%%% answer
答案：AD
（原卷标注：A&D。）x 为大正数时 int→float 丢精度，x 为绝对值很大的负数时同样丢精度，故 A、D 两种情况下 X 可能不等于 Z。
原卷选项 B 的示例写作 “large negative values (e.g., >-100)”，与“large negative”语义不符；此处保留原卷文字，不据此推断选项答案。
