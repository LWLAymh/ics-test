14、仅考虑以下代码，哪些程序优化总是被编译器自动进行？（假设 int i, int


j, int A[N], int B[N], int m, int *p 都是局部变量，N 是一个整数型常量，int foo(int) 是一个函数）

%%% choices
A. 优化前：
```c
for (j = 0; j < N; j++)
    B[i] *= A[j];
```
优化后：
```c
int temp = B[i];
for (j = 0; j < N; j++)
    temp *= A[j];
B[i] = temp;
```
B. 优化前：
```c
for (j = 0; j < N; j++)
    m += i * N * j;
```
优化后：
```c
int temp = i * N;
for (j = 0; j < N; j++)
    m += temp * j;
```

```c

    m = j;
```
优化后：
```c
j = foo(N);
if (*p != 0)
    m = j;
```

```c
for (j = 0; j < foo(N); j++)
    m++;
```

```c

```
