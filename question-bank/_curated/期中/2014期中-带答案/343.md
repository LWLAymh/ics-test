第三题 （10 分）

阅读以下代码。假设代码运行在 IA32 的计算机上，字长为 4，请给出各个变量在内存中的十六进制字节表示（地址从小到大）。

注意 tiny_float 是一种 8 位的浮点数，1 个符号位，4 个指数位，3 个尾数位。

```c
int main()
{
        int a = 0x15213;
        unsigned char b = ((char)-5);
        tiny_float c = 19;
        float d;
        if (b < 4)
                d = -0.96875;
        else
                d = 769;
}
```

%%% answer
答案：各变量在内存中的十六进制字节表示（地址从小到大）：

- a：`13 52 01 00`
- b：`FB`
- c：`5A`
- d：`00 40 40 44`
