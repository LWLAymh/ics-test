第四题 请分析 Y86-64 ISA 中新加入的一组条件 POP 指令 cpopqXX。cpopqXX 和 popq 指令的机器码格式如下。
```
cpopqXX  B  fun  rA  F
popq  B  0  rA  F
```
类似cmovXX，该组cpopqXX指令在条件码(Cnd)满足时，会将栈顶的8字节数据
读入到寄存器rA中，并且使栈指针增加8；如果条件不满足，则不执行该指令，即
对rA、栈指针都无影响。

1. **SEQ 处理器：**

| 阶段 | 操作 |
| --- | --- |
| Fetch | `icode:ifun ← M1[PC]`；`rA:rB ← M1[PC+1]`；`valP ← PC+2` |
| Decode | `valB ← R[%rsp]`；`valA ← R[%rsp]` |
| Execute | `valE ← valB + 8`；`Cnd ← Cond(CC, ifun)` |
| Memory | `valM ← M8[valA]` |
| Write back | 若 `Cnd`，则 `R[%rsp] ← valE`；若 `Cnd`，则 `R[rA] ← valM` |
| PC update | `PC ← valP` |

（每空 1 分，共 7 分）

2. ① `ICPOPQXX`（原卷答案键写作 `IPOPQ`，并注明 `ICPOPQXX` 也算对）；② `!e_Cnd`。（每空 1 分，共 2 分）

3. 触发条件：`E_icode in {IMRMOVQ, IPOPQ} && e_dstM in {d_srcA, d_srcB}`。

| F | D | E | M | W |
| --- | --- | --- | --- | --- |
| stall | stall | bubble | normal | normal |

（共 3 分。）

4. `n=1` 时需要执行 17 个周期；`n=3` 时需要执行 29 个周期。

原卷解析：循环过程为 Line 4–9，共 6 条。`n=3` 时为 `4 + 3 + 6×3 + 1 + 2 + 1 = 29`；`n=1` 时为 `4 + 3 + 6 + 1 + 2 + 1 = 17`。周期数从执行 `foo` 第一条指令开始，直到返回指令 `ret` 完全通过流水线为止。
