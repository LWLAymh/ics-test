2.对于 `float` 类型变量 a, b, c下列说法正确的是：
%%% choices
A. 若 `a > b`，则 `a + c > b + c`
B. 若 `a == b`，则 `a + c == b + c`
C. 若 `a + b + c == 0.0`，则 `c + b + a == 0.0`
D. 若 `a + b == 0.0`，则 `b + a == 0.0`
%%% answer
答案：D
本题考察浮点数运算律，A选项`c = INF`，B选项`c = NAN`时不对，C、D选项变相
考察浮点数不满足结合律但满足交换律
