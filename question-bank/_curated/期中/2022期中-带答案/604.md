1.在一个8-bit地址空间的机器上，考虑如下的高速缓存：此高速缓存共有4组
（S=4），为二路组相联（E=2），Tag段的大小为3-bit（t=3），替换策略为LRU。
初始状态下各组的有效位（V）和Tag位如下表所示：
```
  V  Tag  V  Tag
SET 0  1  000  0  001
SET 1  0  001  1  110
SET 2  0  110  1  101
SET 3  1  010  0  001
```
（1）此 cache 所能存储的数据总容量为 `C = ______ Bytes`。（3 分）

（2）现要读取地址空间 `0xd2` 处的数据，此访存是否命中 cache？______（填“是”或“否”）。（2 分）请在下表中写出经过此次访存后更新的 cache 有效位（V）和 Tag 位。仅写出有修改的部分即可；如果认为没有修改，此表可以为空。（2 分）

| Set | V | Tag | V | Tag |
| --- | --- | --- | --- | --- |
| 0 |  |  |  |  |
| 1 |  |  |  |  |
| 2 |  |  |  |  |
| 3 |  |  |  |  |

（3）在（2）访存的基础上，考虑如下访存序列：`0xc8, 0x16, 0x01, 0xb5`（均读取一个字节）。这四次数据访问的命中率（hit rate）为______。（2 分）假设 cache 的命中时间（hit time）为 10 个周期，不命中处罚（miss penalty）为 190 个周期，则总延迟为______周期。（2 分）
%%% answer
（1）64 Bytes。（由 `S=4` 得 `s=2`，故 `b=8-s-t=3`，每个 cache block 大小为 `B=2³=8 Bytes`；总容量 `C=S×E×B=4×2×8=64 Bytes`。）

（2）否。`0xd2` 的二进制为 `110 10 010`，组号为 set 2。set 2 中虽有 tag=`110` 的块，但其有效位为 0，因此未命中。该组有一个无效块，访问后将该块的有效位置为 1、Tag 设为 `110`。

（3）命中率为 `2/4=50%`；总延迟为 `2×10 + 2×(10+190) = 420` 周期。`0xc8` 命中 set 1；`0x16` 在 set 2 未命中，并按 LRU 替换 tag `101`；`0x01` 命中 set 0；`0xb5` 在 set 2 未命中，因为 tag `101` 已被替换。

本题考查 cache 容量、访问行为和 LRU 替换。
