8.考虑下面的C语言代码：
```
int comp(data_t a, data_t b){
return a COMP b;
}
```
代码给出了数据a和b之间比较的一般形式，这里参数的数据类型data_t为某
种有符号或无符号的整数类型。COMP操作通过#define进行定义。假设a在%rdi
中某个部分，b在%rsi某个部分。对于下面每个指令序列，组合和描述正确的是
（    ）
%%% choices
A. 指令序列 `cmpl %esi,%edi` / `setl %al`，data_t = long，COMP = `＜`
B. 指令序列 `cmpw %si,%di` / `setge %al`，data_t = short，COMP = `≥`
C. 指令序列 `cmpb %sil,%dil` / `setbe %al`，data_t = char，COMP = `≤`
D. 指令序列 `cmpq %rsi,%rdi` / `setne %al`，data_t = int，COMP = `!＝`
%%% answer
答案：B，ACD分别应该是int、unsigned char和long
