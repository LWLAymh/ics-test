11. 假设已有声明 `int i, int sum, int *p, int *q, int *r`，`const int n = 100`，`float a[n], float b[n], float c[n]`，`int foo(int), void bar()`，以下哪项程序优化编译器总是可以进行？
%%% choices
A. 浮点数组循环：
```c
for (i = 0; i < n; ++i) {
    a[i] += b[i];
    a[i] += c[i];
}
```
优化为：
```c
for (i = 0; i < n; ++i) {
    tmp = b[i] + c[i];
    a[i] += tmp;
}
```
B. 指针读写：
```c
*p += *q;
*p += *r;
```
优化为：
```c
tmp = *q + *r;
*p += tmp;
```
C. 循环索引缩放：
```c
for (i = 0; i < n; ++i)
    sum += i * 4;
```
优化为：
```c
N = n * 4;
for (i = 0; i < N; i += 4)
    sum += i;
```
D. 含函数调用的循环：
```c
for (i = 0; i < foo(n); ++i)
    bar();
```
优化为：
```c
tmp = foo(n);
for (i = 0; i < tmp; ++i)
    bar();
```
%%% answer
答案：C
A 浮点数不满足结合律。
B `p`、`q`、`r` 可能指向同一个地址。
D `foo` 函数可能有副作用。
