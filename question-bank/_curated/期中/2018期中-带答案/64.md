3.  考虑如下函数
```c
void XOR(int x, int y) {
      y = x ^ y;
      x = x ^ y;
      y = x ^ y;
    printf(x, y);
}
```
XOR(a,b)的输出结果为？
%%% choices
A. A) a, b
B. B) b, a
C. C) b,0
D. D) b, $a^b$
%%% answer
答案：C
本题考查xor的特殊用法，x xor x = 0 , 0 xor x = x ;
答案修订：应为B，该代码将x, y值进行交换。另外，题面应为printf(“%d, %d”,
x, y);
