3. 考虑如下函数：

```c
void XOR(int x, int y) {
    y = x ^ y;
    x = x ^ y;
    y = x ^ y;
    printf("%d, %d", x, y);
}
```

`XOR(a, b)` 的输出结果为？
%%% choices
A. `a, b`
B. `b, a`
C. `b, 0`
D. `b, a ^ b`
%%% answer
答案：B

三次异或运算交换了 `x` 和 `y` 的值，因此输出 `b, a`。原卷题面中的 `printf(x, y)` 为笔误，这里按答案稿的修订写为 `printf("%d, %d", x, y)`。
