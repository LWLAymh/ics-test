第三题（15分，每空1分）
数据结构定义如下：（测试用机：64位Linux机器）
typedef struct s1 {
         char cc[N];
         int ii[N];
         int *ip;
} S1;
S1 t1[N];
1、计算该数据结构的空间：
当N=3时，sizeof(S1) =     (1)     ，sizeof(t1) =     (2)
当N=4时，sizeof(S1) =     (3)     ，sizeof(t1) =     (4)
当N=5时，sizeof(S1) =     (5)     ，sizeof(t1) =     (6)
%%% answer
答案：
（1）24 （2）72
（3）32 （4）128
（5）40 （6）200
