5.  以下代码的输出结果是
```c
union {
    double d;
    struct {
        int i;
        char c[4];
    } s;
} u;
u.d = 1;
printf("%d\n", u.s.c[2]);
```
%%% choices
A. 0
B. -16
C. 240
D. 191
%%% answer
答案修订：A、B、C均可成立，原题未限定字节序，也未规定`char`是否为有符号类型。
  题目未说明大小端，若为大端法，选择A。若为小端法，u.s.c[2]为(11110000)2，
由于char在不同的编译器上会被实现成signed char或unsigned char，因此扩
展为int时-16和240均有可能，B，C均正确。
