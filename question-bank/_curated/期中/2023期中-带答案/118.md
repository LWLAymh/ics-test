5.有如下函数（包含一处空缺，用__表示）:
```
long func1(long a[][3], long x, long y) {
    return a[x*2+y][__];
}
```
该函数经gcc –Og编译后得到如下x86-64汇编代码
```
// x86_64 Linux calling convension
// return: RAX
// parameters: RDI, RSI, RDX, RCX
// sizeof(int) = 4
// sizeof(long) = 8
func1(long (*) [3], long, long):
        leaq    (%rdx,%rsi,2), %rax
        leaq    (%rax,%rax,2), %rax
        movq    48(%rdi,%rax,8), %rax
        ret
```
则空缺处应为：
%%% choices
A.0
B.2
C.4
D.6
%%% answer
答案：D
