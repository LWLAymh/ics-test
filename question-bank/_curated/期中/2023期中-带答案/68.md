2. 下列说法中，正确的是：
%%% choices
A. 对于 `int` 类型的变量 `x`、`y`、`z`，在执行 `z = x * y` 后，可以用 `z / x == y` 判断乘法运算是否没有发生溢出
B. 对于 `int` 类型的变量 `x`，`(x >> 1) <= x` 总为真
C. 对于 `int` 类型的变量 `x`，`(x >> 1) == (x / 2)` 总为真
D. 对于 `int` 类型的变量 `x`，总存在一个 `k`，使得 `x & (-x)` 的结果等于 `1 << k`
%%% answer
答案：D（按原卷答案；严格按题面，x=0 时 D 不成立，因此题面缺少 x≠0 的条件。）

A 错误：`x` 可能为 0，表达式 `z / x` 此时无效。

B 错误：当 `x < -1` 时不成立，例如 `(-2) >> 1` 的结果为 `-1`。

C 错误：算术右移向下取整，而整数除法向零取整，例如 `(-1) >> 1` 为 `-1`，`(-1) / 2` 为 `0`。

D 正确：若 `x` 的低位有连续 `k` 个 0，则 `x & (-x)` 仅保留最低的 1，结果为 `1 << k`。
