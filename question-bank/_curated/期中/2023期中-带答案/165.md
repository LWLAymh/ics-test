8.在x86-64架构、Linux操作系统下，有如下C定义。
```
  struct {
  union {
      short s1;
      char c[3];
  } u;
  double d;
  short s2;
  } s;
```
考虑使用GCC默认选项进行编译，下列逻辑表达式为真的是：
%%% choices
A. `sizeof s.u == 3`
B. `sizeof s.u == 8`
C. `(&s.s2 - &s.u.s1) == 8`
D. `(&s.s2 - &s.u.s1) == 16`
%%% answer
答案：C
`sizeof s.u`应为4。
