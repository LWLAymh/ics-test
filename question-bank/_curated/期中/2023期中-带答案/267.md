14. 阅读如下一段代码
```
int a = -15;
unsigned b = 0xfffffff0;
printf("%d", ((int)0x80000001 + a) - ((unsigned)0x80000002 +
b))
```
请问运行这段代码后的输出是什么：
%%% choices
A. 0
B. 1
C. -2147483647
D. -2147483647 - 1
%%% answer
按课程采用的 32 位补码环绕语义，答案为 A。严格按 ISO C，`(int)0x80000001 + a`
发生有符号整数溢出，程序行为未定义；原卷答案隐含了补码环绕这一机器假设。
