14. 阅读如下一段代码
```
int a = -15;
unsigned b = 0xfffffff0;
printf("%d", ((int)0x80000001 + a) - ((unsigned)0x80000002 +
b))
```
请问运行这段代码后的输出是什么：
%%% choices
A. 0
B. 1
C. -2147483647
D. -2147483647 - 1
%%% answer
答案：A. 主要考察two's complement(负数的二进制值)，二进制值和表示方
式的关系（表示方式是对二进制值的解读方法，计算结果与表示方式无关）
