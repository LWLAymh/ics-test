3. 假定静态 `int` 型二维数组 `a` 和指针数组 `pa` 的声明如下：

```c
static int a[4][4] = {
    {3, 8, -2, 6},
    {2, 1, -5, 3},
    {1, 18, 4, 10},
    {4, -2, 0, 8}
};
static int *pa[4] = {a[0], a[1], a[2], a[3]};
```

若 `a` 的首地址为 `0x601080`，则 `&pa[0]` 和 `pa[1]` 分别是：
%%% choices
A. `0x6010c0`、`0x601090`
B. `0x6010e0`、`0x601090`
C. `0x6010c0`、`0x6010a0`
D. `0x6010e0`、`0x6010a0`
%%% answer
A
