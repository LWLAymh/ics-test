1. 取指：`icode:ifun ← M1[PC]`；`rA:rB ← M1[PC+1]`；`valC ← M8[PC+2]`；`valP ← PC + 10`。
   译码：`valA ← R[rA]`；`valB ← R[rB]`。
   执行：rmmovq 与 cmrmovqXX 均为 `valE ← valB + valC`；cmrmovqXX 另有 `Cnd ← Cond(CC, ifun)`。
   访存：rmmovq 为 `M8[valE] ← valA`；cmrmovqXX 为 `valM ← M8[valE]`，或 `if(Cnd) valM ← M8[valE]`。
   写回：rmmovq 为 none；cmrmovqXX 为 `if(Cnd) R[rA] ← valM`。
   更新PC：`PC ← valP`。
2. W 阶段保持的流水线信号：`W_Cnd`
   ① `E_icode == ICMRMOVQ && e_Cond`
   ② `{d_srcA, d_srcB}`
   ③ `{D_icode, E_icode, M_icode}`
   ④ `E_icode == IJXX && !e_Cond`
