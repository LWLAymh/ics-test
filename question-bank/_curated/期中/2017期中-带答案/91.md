6.  有如下代码段：
```
int func(int x, int y);
int (*p) (int a, int b);
p = func;
p(0,0);
```
对应的下列x86-64过程调用正确的是：
%%% choices
A. `call *%rax`
B. `call (%rax)`
C. `call *(%rax)`
D. call func
%%% answer
答案：A（D 也对，视优化级别而定）
解析：用O0编译可以得到A，用Og编译可以得到D。原题面在此处有歧义，
判定时按 A 计分；若答 D 也应算对。
