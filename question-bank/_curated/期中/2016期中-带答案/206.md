第二题（20分）
（边凯归，周明辉）
1.在64位机器上，判断下列等式是否恒成立
/* random_int()函数返回一个随机的int类型值 */
int x = random_int();
int y = random_int();
int z = random_int();
unsigned ux = (unsigned)x;
long lx = (long)x;  /* long为64位 */
long ly = (long)y;
double dx = (double)x;
double dy = (double)y;
double dz = (double)z;
Expression  Always True?
(x >= 0) || (3*x < 0)  Y     N
(x >= 0) || (x < ux)  Y     N
($(x >> 1)$ << 1) <= x  Y     N
((x-y)<<3) + $(x>>1)$ - y == 8*x - 9*y + x/2  Y     N
(x - y > 0)  ==   ((y+~x+1)>>31 == 1)  Y     N
dx + dy == (double) (y+x)  Y     N
dx + dy + dz == dz + dy + dx  Y     N
(int)((lx+ly)>>1)   ==   ((x&y) +  Y     N
(($x^y$)>>1))
（前6题每题1分; 7、8两题每题2分; 共10分）
%%% answer
答案：1. N（考虑 x = `(1<<31)>>1`）
2. N（考虑 x = -1）
3. Y
4. N（考虑 x = -1，y = 0）
5. N（考虑 x - y = Tmin）
6. N（考虑 x + y 溢出）
7. Y（恒成立，每一个 int 型都可以由一个 double 型精确表示）
8. Y（恒成立）
