%%% answer
1. Fetch：`icode:ifun ← M1[PC]`；`valP ← PC + 1`
   Decode：`valB ← R[%esp]`；`valA ← R[%esp]`
   Execute：`valE ← valB + 4`；`Cnd ← Cond(CC, ifun)`
   Memory：`valM ← M4[valA]`
   Write back：`if (Cnd) R[%esp] ← valE`
   PC update：`PC ← Cnd ? valM : valP`
2. 流水线寄存器 `W_Cnd`（填 `W_Bch` 也算对）；一共会错误取指 3 条指令。
3. Trigger（算两个空）：`(E_icode = ICRETXX && e_Cnd) || (M_icode = ICRETXX && M_Cnd)`
   各级控制信号：F = Normal，D = bubble，E = bubble，M = normal，W = normal
4. 不会发生 load-use 和 misprediction cret 组合的 hazard 情况（答：不会）。
   各级控制信号：F = stall，D = stall，E = bubble，M = normal，W = normal
