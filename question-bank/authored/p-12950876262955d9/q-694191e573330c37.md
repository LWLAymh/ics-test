%%% stem
7.考虑下面的C语言代码，我们省略了被计算的表达式：
```c
long scale2(long x, long y, long z){
    long t = __________________________;
    return t;
}
```
用GCC编译实际的函数得到如下的汇编代码：
```
scale2:
    leaq  (%rdi, %rdi, 2), %rax
    leaq  (%rax, %rsi, 4), %rax
    leaq  (%rax, %rdx, 8), %rax
    ret
```
则C代码中缺失的表达式是（     ）
