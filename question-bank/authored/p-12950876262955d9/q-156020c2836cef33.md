%%% stem
8.考虑下面的C语言代码：
```c
int comp(data_t a, data_t b){
    return a COMP b;
}
```
代码给出了数据`a`和`b`之间比较的一般形式，这里参数的数据类型`data_t`为某
种有符号或无符号的整数类型。`COMP`操作通过#define进行定义。假设`a`在`%rdi`
中某个部分，`b`在`%rsi`某个部分。对于下面每个指令序列，组合和描述正确的是
（    ）
%%% reference
答案：B，ACD分别应该是int、unsigned char和long
%%% option: A
指令序列 `cmpl %esi,%edi` / `setl %al`，`data_t = long`，COMP = `＜`
%%% option: B
指令序列 `cmpw %si,%di` / `setge %al`，`data_t = short`，COMP = `≥`
%%% option: C
指令序列 `cmpb %sil,%dil` / `setbe %al`，`data_t = char`，COMP = `≤`
%%% option: D
指令序列 `cmpq %rsi,%rdi` / `setne %al`，`data_t = int`，COMP = `!＝`
