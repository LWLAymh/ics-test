1.已知 a 是 `int` 类型变量，表达式 `a < 0` 为真，下列选项中一定为真的表达
式是：
%%% reference
答案：D
本题考察整数的运算律，A选项`a = TMIN`时，`-a = TMIN`不满足；B,C选项中若 a
= -1，由补码表示和向零舍入，`a/2 = ~a = 0`。
%%% option: A
`-a > 0`
%%% option: B
`~a > 0`
%%% option: C
`(a / 2) < 0`
%%% option: D
`(a >> 1)` < 0
