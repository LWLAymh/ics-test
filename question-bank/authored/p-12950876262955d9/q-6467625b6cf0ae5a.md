%%% stem
1. 已知 `a` 是 `int` 类型变量，表达式 `a < 0` 为真，下列选项中一定为真的表达式是：
%%% reference
答案：D。

按本题采用的补码运算及算术右移模型：

- A：当 `a = TMIN` 时，补码取负的结果仍为 `TMIN`，不大于 0。
- B、C：当 `a = -1` 时，`~a = 0`，且整数除法向零舍入，`a / 2 = 0`。
- D：负数算术右移后符号位仍为 1，因此 `(a >> 1) < 0`。

注意：这里沿用 ICS 的机器级运算模型；标准 C 中对 `INT_MIN` 取负属于有符号溢出。
%%% option: A
`-a > 0`
%%% option: B
`~a > 0`
%%% option: C
`(a / 2) < 0`
%%% option: D
`(a >> 1) < 0`
