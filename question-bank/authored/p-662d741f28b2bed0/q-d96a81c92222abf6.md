%%% stem
2. 假设C语言中新定义了一种数据类型T,该类型为12-bit长的浮点数，此浮
点数遵循IEEE浮点数格式，其字段划分如下：
符号位（s）：1-bit；阶码字段（exp）：6-bit；小数字段（frac）：5-bit。
1) 若将该格式下能表示的所有正规格数从小到大依次排列，则
相邻两数之间差值的最小值为 {{blank:min-diff}}
相邻两数之间差值的最大值为 {{blank:max-diff}}
2) 现定义了如下变量：
```c
T a = -15.875;
T b = (1<<28) + (1<<24) + (1<<22);
T c = a*b;
```
请写出各变量的二进制表示（每个字段之间以空格分隔）：

| 变量 | 二进制表示 |
| --- | --- |
| `a` | {{blank:a}} |
| `b` | {{blank:b}} |
| `c` | {{blank:c}} |
（每空2分; 共10分）
%%% reference
答案：
1）
$2^{-35}$
$2^{26}$
2）
1 100011 00000 (发生进位)
0 111011 00010 (发生舍入)
1 111111 00000 (溢出，+∞)
