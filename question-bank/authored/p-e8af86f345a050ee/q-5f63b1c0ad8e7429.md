练习题 7.2：对每种情形说明链接器如何解析对重复定义符号的引用。使用题目中的格式填写 `DEF(module.symbol)`；若发生链接错误，填“错误”。

A.
```c
/* Module 1 */        /* Module 2 */
int main() { }        int main;
                      int p2() { }
```
`REF(main.1) →` {{blank:a1}}；`REF(main.2) →` {{blank:a2}}

B.
```c
/* Module 1 */        /* Module 2 */
void main() { }       int main = 1;
                      int p2() { }
```
链接结果：{{blank:b}}

C.
```c
/* Module 1 */        /* Module 2 */
int x;                double x = 1.0;
void main() { }       int p2() { }
```
`REF(x.1) →` {{blank:c1}}；`REF(x.2) →` {{blank:c2}}
%%% reference
A. Module 1 的 `main` 是强符号，Module 2 的 `main` 是弱符号，故两个引用均解析到 `DEF(main.1)`。B. 两个模块定义同名强符号 `main`，发生链接错误。C. Module 1 的 `x` 是弱 COMMON 符号，Module 2 的 `x` 是已初始化的强符号，两个引用均解析到 `DEF(x.2)`。
