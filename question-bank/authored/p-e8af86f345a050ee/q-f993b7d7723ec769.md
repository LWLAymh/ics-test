%%% stem
`REF(x,i) → DEF(x,k)` 表示把模块 i 对 x 的引用关联到模块 k 的定义。采用教材传统 common 符号模型：多个强定义报错，强定义优先于弱定义，多个弱定义可任意选取。填写 `符号.模块号`；报错填“错误”，任意选取填“未知”。

A.

```c
/* Module 1 */
int main()
{
}

/* Module 2 */
static int main = 1;
int p2()
{
}
```

`REF(main,1) → DEF(`{{a1}}`)`；`REF(main,2) → DEF(`{{a2}}`)`。

B.

```c
/* Module 1 */
int x;
void main()
{
}

/* Module 2 */
double x;
int p2()
{
}
```

`REF(x,1) → DEF(`{{b1}}`)`；`REF(x,2) → DEF(`{{b2}}`)`。

C.

```c
/* Module 1 */
int x = 1;
void main()
{
}

/* Module 2 */
double x = 1.0;
int p2()
{
}
```

`REF(x,1) → DEF(`{{c1}}`)`；`REF(x,2) → DEF(`{{c2}}`)`。
%%% reference
A：`main.1`、`main.2`，模块 2 的静态对象是局部符号。B：均“未知”，两个暂定定义按教材规则为弱定义，所有引用最终使用同一个被选中的定义。C：均“错误”，两个初始化全局对象均为强定义。现代 GCC 默认 `-fno-common` 时 B 也可能报错，本题使用教材模型。
