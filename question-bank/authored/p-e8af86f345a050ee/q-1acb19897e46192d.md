下面给出 `m.c`（图 7-5）以及能够记录调用次数的 `swap.c`。按教材 ELF 目标文件模型，填写 `swap.o` 中每个符号是否有 `.symtab` 条目；若有，给出类型（局部、全局或外部）、定义模块（`swap.o` 或 `m.o`）和定义所在节（`.text`、`.data` 或 `.bss`）。

```c
/* m.c */
void swap();
int buf[2] = {1, 2};

int main()
{
    swap();
    return 0;
}
```

```c
/* swap.c */
extern int buf[];
int *bufp0 = &buf[0];
static int *bufp1;

static void incr()
{
    static int count = 0;
    count++;
}

void swap()
{
    int temp;

    incr();
    bufp1 = &buf[1];
    temp = *bufp0;
    *bufp0 = *bufp1;
    *bufp1 = temp;
}
```

自动局部变量 `temp` 不属于链接器符号。`static count` 有静态存储期，通常以带编译器后缀的名字出现；零初始化对象放在 `.bss`。`buf` 在 `swap.o` 中是未定义的外部引用，表中的 `.data` 是其在 `m.o` 中的定义节。按教材保留符号的模型回答；优化器可能删除未使用符号。
