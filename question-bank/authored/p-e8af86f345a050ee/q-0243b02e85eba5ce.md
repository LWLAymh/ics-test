考虑由下列两个目标模块组成的程序：

```c
/* foo6.c */
void p2(void);

int main()
{
    p2();
    return 0;
}
```

```c
/* bar6.c */
#include <stdio.h>
char main;

void p2()
{
    printf("0x%x\n", main);
}
```

教材描述：在其 x86-64 Linux 环境中，程序打印 `0x48` 并正常终止，即使 `p2` 未初始化变量 `main`。按教材传统 common 符号模型解释。
%%% reference
函数 `main` 是强定义，未初始化对象 `main` 是弱定义，因此链接器把后者的引用绑定到函数入口。`p2` 把函数入口的第一个机器码字节当作 `char` 读出；教材编译结果的首字节为 `0x48`（x86-64 REX 前缀）。输出依赖具体机器码，不是一般 C 保证。现代默认 `-fno-common` 的工具链可能拒绝链接。
