%%% stem
`a → b` 表示目标模块或静态库 a 引用了 b 定义的符号，文件均在当前目录。按从左至右扫描静态库模型，分别给出保证解析下列依赖关系的最小命令行，要求目标文件与库参数总数最少（使用普通文件参数，可重复库）：

A. `p.o → libx.a → p.o`

B. `p.o → libx.a → liby.a`，并且 `liby.a → libx.a`

C. `p.o → libx.a → liby.a → libz.a`，并且 `liby.a → libx.a → libz.a`
%%% reference
```sh
# A
gcc p.o libx.a
# B
gcc p.o libx.a liby.a libx.a
# C
gcc p.o libx.a liby.a libx.a libz.a
```

普通目标文件总会被加入，因此 A 无需重复 `p.o`。B 中 `liby.a` 可引入新的 x 引用，需要再次扫描 x。C 把 z 放在两次 x 和一次 y 后，一并解决它们引出的 z 引用。这是仅凭给定库级依赖可保证解析的顺序；具体库成员布局可能恰好不需重复。
