%%% stem
24.（6分）阅读下面的 C 程序。假定所有系统调用成功，标准输出连接终端且每次换行都会刷新。进程总数**包含最初运行程序的进程**；各进程的全局变量 `x` 在 `fork` 后分别保存。

```c
#include <stdio.h>
#include <unistd.h>
#include <sys/wait.h>

int x = 1;

int main(void) {
    printf("start: x = %d\n", x);
    pid_t pid1 = fork();
    if (pid1 == 0) {
        x += 1;
        printf("x = %d\n", x);
        sleep(1);
        pid_t pid2 = fork();
        if (pid2 == 0) {
            x += 2;
            printf("x = %d\n", x);
        } else {
            x += 3;
            printf("x = %d\n", x);
            wait(NULL);
        }
    } else {
        x += 4;
        printf("x = %d\n", x);
        wait(NULL);
        printf("x = %d\n", x);
    }
    return 0;
}
```
%%% reference
两个 `fork()` 各创建一个子进程，进程总数为 3（不是仅计算新创建的 2 个子进程）。两个 `wait(NULL)` 保证原父进程的最后一次输出在全部后代输出之后。

%%% part-reference: q-50a647f5a470d688
答案：3 个进程
%%% part-stem: q-a255defea0f15cf2
（2）（2分）总共会输出多少行？{{blank:q24-output-lines}}
%%% part-reference: q-a255defea0f15cf2
答案：6 行。依次计数：`start` 一行，原父进程两行，第一子进程两行，第二次 `fork` 创建的子进程一行。进程间具体交错可变，但总数不变。
%%% part-stem: q-8c64e5287043dc94
（3）（2分）最后一行输出是：
%%% part-reference: q-8c64e5287043dc94
答案：D，`x = 5`。第一子进程等待它创建的子进程结束，原父进程又等待第一子进程结束；最后执行的是原父进程 `wait` 后的那次打印。父进程自己的 `x` 从 1 加 4 得到 5，不会被其他进程修改。
