%%% stem
20.（不定项选择，2分）下面这段代码中，属于链接器要解析的符号包括：

```c
#include <stdio.h>

int cnt = 10;
extern void print_value(int x);

int main(void) {
    int val = 5;
    print_value(val + cnt);
    return 0;
}
```
%%% reference
答案：**D、E、G**，即 `cnt`、`print_value`、`main`。

`cnt` 和 `main` 是本目标模块定义的外部可见符号；`print_value` 是本模块引用、需由链接器解析的外部函数。`include` 是预处理指令的名字，`stdio.h` 是头文件名，`int` 是类型关键字；参数 `x` 和自动局部变量 `val` 也不是这里所问的链接器符号。

**原卷勘误：**带答案卷标为 `ADEG`，其中 A 是误选。`#include` 在预处理阶段展开，不会把名字 `include` 作为符号交给链接器。这里明确更正判分键，不把原答案照抄为标准答案。参见 [GCC 的 include 处理说明](https://gcc.gnu.org/onlinedocs/cpp/Include-Operation.html)。
