6.（8分）以下是 SEQ 处理器 ALU 的 A 口输入信号 `aluA` 的分析，仅列出部分指令。根据指令功能，补全表格中的 2 空和 HCL 代码中的 6 空。每空只填缺少的名称或数值，不重复填写已有标点和指令名。

| 指令 | Execute 阶段 |
| --- | --- |
| `OPq rA, rB` | `valE ← valB OP valA` |
| `cmovXX rA, rB` | `valE ← 0 + valA` |
| `rmmovq rA, D(rB)` | `valE ← valB + valC` |
| `popq rA` | `valE ← valB + 8` |
| `jXX Dest` | 不需要 ALU |
| `call Dest` | `valE ← valB + (`{{blank:q6-call-step}}`)` |
| `ret` | `valE ← valB + (`{{blank:q6-ret-step}}`)` |

```hcl
int aluA = [
    icode in { IRRMOVQ, {{blank:q6-val-a-op}} } : valA;
    icode in { IIRMOVQ, {{blank:q6-val-c-op}}, IMRMOVQ } : valC;
    icode in { {{blank:q6-minus-op}}, IPUSHQ } : {{blank:q6-minus-value}};
    icode in { {{blank:q6-plus-op}}, IPOPQ } : {{blank:q6-plus-value}};
    # Other instructions don't need ALU
];
```
%%% reference
表格依次填 `-8`、`8`；HCL 代码依次填 `IOPQ`、`IRMMOVQ`、`ICALL`、`-8`、`IRET`、`8`。

```hcl
int aluA = [
    icode in { IRRMOVQ, IOPQ } : valA;
    icode in { IIRMOVQ, IRMMOVQ, IMRMOVQ } : valC;
    icode in { ICALL, IPUSHQ } : -8;
    icode in { IRET, IPOPQ } : 8;
    # Other instructions don't need ALU
];
```

算术指令与条件传送使用 `valA`；立即数和访存位移使用 `valC`；入栈／调用令栈指针减 8，出栈／返回令其加 8。代码与 [CS:APP 作者的 SEQ HCL](https://csapp.cs.cmu.edu/3e/waside/waside-hcl.pdf) 中 `aluA` 的四个分支一致。
