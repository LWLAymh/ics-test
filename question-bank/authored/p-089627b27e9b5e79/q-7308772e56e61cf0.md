%%% stem
10. 假设所有系统调用成功，`stdout` 连接终端并按行缓冲，每次带换行的 `printf` 都在后续 `fork` 之前刷新完毕。下列代码会输出几个 `hello`？
```c
void doit()
{
    if (fork() == 0) {
        printf("hello\n");
        fork();
    }
    return ;
}
int main()
{
    doit();
    printf("hello\n");
    exit(0) ;
}
```
%%% reference
答案：B
第一次 `fork` 的子进程先输出一次，再 `fork` 出一个进程；最终三个进程各在 `main` 中输出一次，总计四次。若输出被重定向并采用全缓冲，未刷新的第一行会随第二次 `fork` 复制，可能得到五次；本题已明确排除这种情况。

4
