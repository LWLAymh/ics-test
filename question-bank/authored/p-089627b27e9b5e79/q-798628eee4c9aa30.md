19. 对于如下 C 语言程序（已修正原清单混用包装函数和返回码的笔误，假设线程创建成功）：
```c
#include "csapp.h"
void *thread (void * arg)
{
    printf("Hello World");
    Pthread_detach(pthread_self());
    return NULL;
}
int main(void)
{
    pthread_t tid;
    Pthread_create(&tid, NULL, thread, NULL);
    pthread_exit(NULL);
}
```

答案：B

%%% option: A
使主线程阻塞以等待线程`thread`结束
%%% option: B
线程 `thread` 结束后，系统自动回收其线程栈和线程描述信息，无需其他线程 `join`（不代表自动释放该线程申请的所有堆内存）
%%% option: C
线程`thread`运行后主动释放CPU给其他线程
