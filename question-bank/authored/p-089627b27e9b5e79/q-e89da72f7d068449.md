%%% stem
9.  在`foo.c`文件中的函数外，如果添加如下一条语句：
       `static int count = 0xdeadbeef`;
  那么它在编译为`foo.o`后，会影响到ELF可重定位目标文件中的除.text以外
的那些字段？
%%% reference
答案：B
这是一个本地静态全局变量，它在.data中占有位置，它不需要重定位，
因为它的初始值是确定的，但是它在符号表中占有一个位置。
考察ELF文件格式。
%%% option: A
.rodata
%%% option: B
.data,.symtab,
%%% option: C
`.data,.symtab,.rel.data`
%%% option: D
`.rodata,.symtab,.rel.data`
