%%% stem
12. 下列这段代码的哪些输出不可能出现？（可多选）

按课程的输出顺序模型分析：`fork` 成功，每次输出一个字符立即可见、不会丢失或交错，不考虑在信号处理程序中调用 `printf` 的异步信号安全问题。输出统计到父、子进程都结束；父进程退出后不再处理子进程的信号。

> 原卷勘误：B 选项 `abch` 缺少一个必然输出的 `c`，也不可能出现；原答案只列 D 不完整。本题保留原选项，改为多选 B、D。

```c
void handler()
{
    printf("h");
}
int main()
{
    signal(SIGCHLD, handler) ;
    if ( fork() == 0 ) {
        printf("a") ;
    } else {
        printf("b") ;
    }
    printf("c") ;
    exit(0) ;
}
```
%%% reference
答案：B、D。

父进程必输出 `bc`，子进程必输出 `ac`，所以总有两个 `c`；B 只有一个 `c`，不可能。子进程退出后才可能产生对应的 `SIGCHLD`，故处理程序的 `h` 必在子进程的 `ac` 之后，D 也不可能。

A 可以由交错顺序 `a`、`b`、父进程 `c` 并退出、子进程 `c` 并退出产生，此时父进程来不及处理信号。C 可以由父进程输出 `bc` 后暂停、子进程输出 `ac` 并退出、父进程处理信号输出 `h` 产生。
