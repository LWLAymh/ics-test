%%% stem
3.  左边的C函数中，在x86_64服务器上采用GCC编译产生的汇编语言如右边
所示。那么（1）和（2）的内容分别是：
左侧的 C 函数：
```c
int arith(int x, int y) {
    return (x < y) ? ( 1 ) : ( 2 );
}
```

右侧的汇编：
```asm
<arith>:
    lea    (%rsi,%rdi,1),%eax
    mov    %esi,%edx
    sub    %edi,%edx
    cmp    %esi,%edi
    cmovge %edx,%eax
    retq
```
（提示：第一个参数放在`rdi`寄存器中，第二个参数放在`rsi`寄存器中）
