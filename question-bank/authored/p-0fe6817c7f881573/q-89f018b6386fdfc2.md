15. 假设已有声明 `int a, int b, int i, int* pa, int* pb, float fa, float fb, float fc, char s[100], int f()`，以及 `#include<string.h>`，以下优化正确的是：
%%% reference
答案：C。
A 错：`pa` 和 `pb` 可能指向同一内存位置，异或交换会把值清零。
B 错：f() 可能产生副作用，不能省略第二次调用。
C 正确：`strlen(s)` 在循环中重复计算；先保存长度不改变结果。
D 错：浮点数运算不满足分配律。
%%% option: A
原程序：`int c = *pa; *pa = *pb; *pb = c;`；优化程序：`*pb ^= *pa; *pa ^= *pb; *pb ^= *pa;`
%%% option: B
原程序：`a = f(); b = f(); int sum = a+b;`；优化程序：`a = f(); int sum = a+a;`
%%% option: C
原程序：`int sum = 0; for(i = 0; i < strlen(s); ++i) sum += s[i] - 'a';`；优化程序：`int sum = 0; int len = strlen(s); for(i = 0; i < len; ++i) sum += s[i] - 'a';`
%%% option: D
原程序：`float ret = fa*fc + fb*fc;`；优化程序：`float ret = (fa+fb)*fc;`
