第二题（15分）
GCC的内联汇编（inline assembly）特性允许在C程序中直接嵌入汇编代码，
使开发者能够访问常规 C 代码无法直接访问的底层机器特性，例如寄存器的值或
特定的处理器指令。通过这种方式，开发者可以对硬件进行精细控制，提升程序性
能或实现特定的底层操作。请结合教材第二、三章的相关知识，回答下列问题。
1. 下列运行在x86-64机器上的C 代码展示了一个使用内联汇编的例子：
```
float *p = 0x7ffc3608bf40;
float value;
/* inline assembly starts */
__asm__ __volatile__(
    "vmovss (%1), %0"
    : "=x"(value)
    : "r"(p)
);
/* inline assembly ends */
printf("%.2f\n", value);
```
这段代码通过在 C 代码中插入浮点指令 `vmovss`（Vector  Move  Scalar
Single-Precision Floating-Point）将内存地址`0x7ffc3608bf40`处的
浮点数数据读取到`float`类型的变量value中。
（1）  （2分）请判断以下说法是否正确（填“是”或“否”）：

a. 这段代码也可以在任何不是 x86-64 的机器上编译、运行。（{{blank:portable}}）

b. 插入的内联汇编代码的效果等同于语句 `value = *p;`。（{{blank:equivalent}}）

（2）（2分）若内存中从地址 `0x7ffc3608bf40` 开始的 4 个字节依次为 `00 00 70 40`，且浮点编码遵循 IEEE 754，则输出为 {{blank:output}}。
%%% part-reference: q-49ad744352e4e33c
参考答案：
1. （1） 否；是。  （每空1分）
（2） 3.75。  （2分）

754标准编码浮点数会造成一些内存浪费。下面基于IEEE-754标准定义一种
8位的浮点数，符号位、阶码位和尾数位长度分别为1,5,2。
（1）  （4分）该浮点数格式可表示的最大的负非规格化数（不考虑-0）的二进

数，无需计算出结果中2的幂的值）。
（2）  （2分）只考虑符号位为0的情况，表示NaN的浮点数有 {{blank:nan-count}} 个。
