%%% stem
4.在 x86-64 架构、Linux 操作系统下，有如下代码：
```c
#include <stdio.h>
struct student {
    int id;
    char name[6];
    short age;
    char gender;
    float score;
};
int main() {
    struct student s;
    struct student* (*p[8])[4];
    printf("%lu\n", sizeof(s));
    printf("%lu\n", sizeof(**p));
    printf("%lu\n", (char*)&p[2] - (char*)p);
    printf("%lu\n", &p[4] - p);
    return 0;
}
```
那么四个输出之和为？
%%% reference
答案：A。

1. `student` 的成员按对齐要求排列后占 `20` 字节，所以 `sizeof(s)=20`。
2. `p` 是含 8 个指针的数组；每个指针指向一个含 4 个 `struct student *` 的数组。因此 `**p` 的类型是含 4 个指针的数组，`sizeof(**p)=4*8=32`。不能把 `p` 本身说成含 4 个元素的数组。
3. `(char*)&p[2] - (char*)p` 按字节计算距离，结果为 `2*8=16`。
4. `&p[4] - p` 按 `p` 的数组元素计数，结果为 `4`。

四个值之和为 `20+32+16+4=72`。
