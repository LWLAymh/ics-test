%%% stem
15. （2分）下面给出了`oddBits`函数的代码，该函数将所有奇数位设置为1（设整数x
的二进制表示为`x[31]x[30]...x[1]x[0]`，奇数位是指j 为奇数的所有`x[j]`）。
下面哪个选项给出了`byte`的正确设置：
```
/*
 * oddBits - return word with all odd-numbered bits set to 1
*/
int oddBits(void) {
  int byte = ________;
  int word = byte | byte<<8;
  return word | word<<16;
}
```
%%% reference
答案：B

解析：目标是奇数位全 1、偶数位全 0 的 `0xAAAAAAAA`：`byte | byte<<8` 得 `0xAAAA`，再 `word | word<<16` 得 `0xAAAAAAAA`，所以 `byte` 应取 `0xAA`。`0x55` 会得到 `0x55555555`（偶数位全 1），`0x11`、`0xff` 也不符。故选 B。
