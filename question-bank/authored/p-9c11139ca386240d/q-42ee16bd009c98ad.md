11. （2 分）下面给出了 `satMul2` 函数的代码，其中变量 `overflow` 在结果溢出时会被设置为 `0xFFFFFFFF`，否则为 0。下面哪一个选项正确给出了 `overflow` 的表达式（提示：可根据 `x` 和 `2 * x` 的符号位来判断是否溢出）：

```c
/*
 * satMul2 - multiplies by 2, saturating to Tmin or Tmax if overflow
 *   Examples: satMul2(0x30000000) = 0x60000000
 *             satMul2(0x40000000) = 0x7FFFFFFF (saturate to TMax)
 *             satMul2(0x90000000) = 0x80000000 (saturate to TMin)
*/
int satMul2(int x) {
    int overflow, negative_x, raw_result, tmin, tmax;
    overflow = ____________________
    negative_x = x >> 31;
    raw_result = x << 1;
    tmin = 1 << 31;
    tmax = tmin + ~0;
    return (overflow & negative_x & tmin)
         | (overflow & ~negative_x & tmax)
         | (~overflow & raw_result);
}
```
%%% reference
答案：C

解析：溢出的判据是 `x` 与 2x 的符号位不同，而 `(x << 1)` 的最高位正是 2x 的符号位，所以 `x ^ (x << 1)` 的最高位为 1 时溢出，算术右移 31 位即得全 1（溢出）或全 0，故 C 对。A 用 x+1、B 用 x-1、D 用 `x>>1` 都取不到"2x 的符号位"。
