第六题（15分）
下面这段代码可以用于评测计算机系统的存储系统性能。在某款现代的个人计算机
上，采用该评测程序的不同的配置参数（数据集大小和访问步长），得到了如下图
所示的性能表现。

![图](assets/期中/2019期中-带答案/p21-memory-mountain.png)

```
long data[MAXELEMS];  /* Global array to traverse */
/* test - Iterate over first "elems" elements of
 *        array “data” with stride of "stride", using
 *        using 4x4 loop unrolling.
 */
int test(int elems, int stride) {
    long i, sx2=stride*2, sx3=stride*3, sx4=stride*4;
    long acc0 = 0, acc1 = 0, acc2 = 0, acc3 = 0;
    long length = elems, limit = length - sx4;
    /* Combine 4 elements at a time */
    for (i = 0; i < limit; i += sx4) {
        acc0 = acc0 + data[i];
        acc1 = acc1 + data[i+stride];
        acc2 = acc2 + data[i+sx2];
        acc3 = acc3 + data[i+sx3];
    }
    /* Finish any remaining elements */
    for (; i < length; i++) {
        acc0 = acc0 + data[i];
    }
    return ((acc0 + acc1) + (acc2 + acc3));
}
```
（1）图中 A1-D1 这几个点有一些较为平缓的“平台”，这主要体现了访存行为的什么特性？ ______（2分）
（2）如果图中D1体现了内存的性能，那A1、B1、C1分别体现存储层次结构中
的什么部件的性能：A1：______、B1: ______、C1: ______。
(每空1分)
其中，B1所体现的部件，容量可能是多大？ ______（2分）
  a. 32KB  b. 256KB    c.1MB    d.8MB
C1所体现的部件，容量可能是多大？ ______（2分）
  a. 32KB  b. 256KB    c.1MB    d.8MB
（3）图中B2和B1、C2和C1之间的“斜坡”，这主要是由于访存行为的什么特
性导致的？ ______（2分）
（4）图中B2和C2的性能指标差别不大，不像B1和C1之间的差距那么大，主
要是什么原因导致的？ ______（2分）
（5）实际评测时，需要把 `test()`函数先运行一遍，然后再运行一次获取评测数
据，这是为了避免什么现象的影响？ ______(2分)
%%% reference
答案：(1) 时间局部性（2分）
(2) A1：L1 Cache；B1：L2 Cache；C1：L3 Cache（每空 1 分）。B1 所体现的部件容量可能是 b. 256KB（2分）；C1 所体现的部件容量可能是 d. 8MB（2分）。
(3) 空间局部性（2分）
(4) 高速缓存的预取功能（2分）
(5) 高速缓存的 cold miss（2分）
