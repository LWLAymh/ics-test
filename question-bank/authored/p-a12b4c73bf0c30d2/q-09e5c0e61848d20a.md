第六题（15分）
下面这段代码可以用于评测计算机系统的存储系统性能。在某款现代的个人计算机
上，采用该评测程序的不同的配置参数（数据集大小和访问步长），得到了如下图
所示的性能表现。
假设数据已初始化且驻留内存，测量不含页面首次分配/换入开销。概念类空位仅填标准术语（可用中英文），容量空可填选项字母或带单位容量。

![图](assets/期中/2019期中-带答案/p21-memory-mountain.png)

```
long data[MAXELEMS];  /* Global array to traverse */
/* test - Iterate over first "elems" elements of
 *        array “data” with stride of "stride", using
 *        using 4x4 loop unrolling.
 */
int test(int elems, int stride) {
    long i, sx2=stride*2, sx3=stride*3, sx4=stride*4;
    long acc0 = 0, acc1 = 0, acc2 = 0, acc3 = 0;
    long length = elems, limit = length - sx4;
    /* Combine 4 elements at a time */
    for (i = 0; i < limit; i += sx4) {
        acc0 = acc0 + data[i];
        acc1 = acc1 + data[i+stride];
        acc2 = acc2 + data[i+sx2];
        acc3 = acc3 + data[i+sx3];
    }
    /* Finish any remaining elements */
    for (; i < length; i += stride) {
        acc0 = acc0 + data[i];
    }
    return ((acc0 + acc1) + (acc2 + acc3));
}
```
原清单尾循环的 `i++` 与题定步长不一致，这里改为 `i += stride`，其余展开部分保持原意。
