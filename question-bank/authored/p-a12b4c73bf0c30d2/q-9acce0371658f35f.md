第四题（15分）
请分析Y86-64 ISA中新加入的一族算术指令： irOpq V, rA, rB，其格式如
下：
C  Fn  rA  rB  V（8字节）
  与Opq类似，这族指令由四个指令组成，分别是iraddq, irsubq, irandq
和irxorq。其功能为：计算`R[rA] OP V`并将结果存入`R[rB]`中，这里OP根
据Fn的取值分别取+, -, &和`^`，且此过程会设置条件码寄存器。

后面三小问共用以下循环，行号按注释对应原卷：

```asm
Loop:
    mrmovq 0(%rdi), %r10   # 1
    rmmovq %r10, 0(%rsi)   # 2
    andq %r10, %r10        # 3
    jle Npos              # 4
    irmovq $1, %r10       # 5
    addq %r10, %rax        # 6
Npos:
    irmovq $1, %r10       # 7
    subq %r10, %rdx        # 8
    irmovq $8, %r10       # 9
    addq %r10, %rdi       # 10
    addq %r10, %rsi       # 11
    andq %rdx, %rdx       # 12
    jg Loop              # 13
    ret                  # 14
```

%%% part-reference: q-bffbee417aaeea5f
答案：1.（每空 1 分）`irOpq V, rA, rB` 各阶段的操作：

```
Stage  irOpq V, rA, rB
Fetch  icode : ifun ← M1[PC]
rA : rB ← M1[PC + 1]
valC ← M8[PC + 2]
valP ← PC + 10
Decode  valA ← R[rA]
Execute  valE ← valA OP valC
Set CC
Memory  none
Write Back  R[rB] ← valE
Update PC  PC ← valP
```
目的寄存器 rB 的旧值不参与这条指令的运算，因此译码不必读取 `R[rB]`；额外读取但未使用不会改变功能，不应作为必填操作。
