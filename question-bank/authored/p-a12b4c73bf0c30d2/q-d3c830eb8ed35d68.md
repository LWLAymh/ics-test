%%% stem
2. （4 point）假设IEEE 754 浮点数标准，请回答以下问题（每空1分）
| 浮点数 | Decimal values |
| --- | --- |
| `0x80000000` |  |
| `0x41180000` |  |

| 表达式 | 是否正确 |
| --- | --- |
| $(2 + 2^{50}) - 2^{50} != 2 + (2^{50} - 2^{50})$ |  |
| $2^{25} + 1 + 1 + 1 + 1 == 2^{25} + 4$ |  |
%%% reference
答案：2.

| 浮点数 | Decimal values |
| --- | --- |
| `0x80000000` | -0 |
| `0x41180000` | +9.5 |

| 表达式 | 是否正确 |
| --- | --- |
| $(2 + 2^{50}) - 2^{50} != 2 + (2^{50} - 2^{50})$ | 是 |
| $2^{25} + 1 + 1 + 1 + 1 == 2^{25} + 4$ | 否 |

Associative: Only 23 bits of mantissa (M), so $2 + 2^{50} = 2^{50}$ (2 gets rounded off). So LHS = 0, RHS = 2.

Cumulative: 1 is 25 powers of 2 away from $2^{25}$, so $2^{25} + 1 = 2^{25}$, but 4 is 23 powers of 2 away from $2^{25}$, so it doesn't get rounded off.
