练习题 2.43 原程序为 `result = x*M + y/N`。编译器生成的优化后代码如下，求常数 M 与 N：

```c
int optarith(int x, int y) {
    int t = x;
    x <<= 5;
    x -= t;
    if (y < 0) y += 7;
    y >>= 3; /* arithmetic shift */
    return x + y;
}
```

%%% reference
