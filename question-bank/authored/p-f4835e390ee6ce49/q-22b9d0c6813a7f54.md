练习题 2.22 通过应用等式（2.3），表明下面每个位向量都是 -5 的补码表示。

A. `[1011]`

B. `[11011]`

C. `[111011]`
%%% reference
按等式（2.3），最高位的权重为负，其余位权重为正：

- A：`-2³ + 2¹ + 2⁰ = -8 + 2 + 1 = -5`。
- B：`-2⁴ + 2³ + 2¹ + 2⁰ = -16 + 8 + 2 + 1 = -5`。
- C：`-2⁵ + 2⁴ + 2³ + 2¹ + 2⁰ = -32 + 16 + 8 + 2 + 1 = -5`。
