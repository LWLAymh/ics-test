%%% stem
填写返回表达式，测试第一个浮点参数是否小于或等于第二个。`f2u` 返回与浮点参数位表示相同的 32 位无符号数。假设参数均非 NaN，`+0` 与 `-0` 相等。只能使用 `ux`、`uy`、`sx` 和 `sy`。

```c
int float_le(float x, float y) {
    unsigned ux = f2u(x);
    unsigned uy = f2u(y);
    unsigned sx = ux >> 31;
    unsigned sy = uy >> 31;
    return {{blank:expr}};
}
```
%%% reference
可填：

```c
((ux << 1) == 0 && (uy << 1) == 0) ||
(sx && !sy) ||
(!sx && !sy && ux <= uy) ||
(sx && sy && ux >= uy)
```

先将两种零视为相等；异号时负数较小；两者非负时位模式的无符号顺序与数值顺序相同，两者负时顺序相反。存在多种等价表达式，因此此空由参考解析自评。
