假定 `x`、`f`、`d` 分别为 `int`、`float`、`double`。`f` 和 `d` 不等于无穷大或 NaN，除此之外它们的值任意。

按本章的机器模型，`int` 为 32 位，`float` 和 `double` 分别采用 IEEE 754 binary32、binary64，向偶数舍入；表达式按对应类型的精度计算，不启用改变运算语义的快速数学优化。

| 原题 | 判断 | 理由或反例 |
| --- | --- | --- |
| A | 总为真 | binary64 能精确表示所有 32 位 `int`，再转回不会损失。 |
| B | 不总为真 | `x = 16777217` 时，转为 `float` 舍入为 `16777216`，转回仍为 `16777216`。 |
| C | 不总为真 | `d = 16777217.0` 时，转为 `float` 再转回得到 `16777216.0`。 |
| D | 总为真 | binary32 到 binary64 的转换精确，再转回原值。 |
| E | 总为真 | 两次取负恢复原值（含正负零，比较也相等）。 |
| F | 总为真 | 两边都做浮点除法，结果均为精确可表示的 0.5。 |
| G | 总为真 | 有限实数平方得到非负数、正零或正无穷，不产生 NaN。 |
| H | 不总为真 | `f = 1.0e20f`、`d = 1.0` 时，加法中 1 被舍入掉，再减去 `f` 得 0。 |

以上反例不依赖超出 `int` 范围的浮点转整数结果。来源答案曾用 `TMax` 举 B 的反例；这种写法可能触发越界转换，故在此使用 16777217。
