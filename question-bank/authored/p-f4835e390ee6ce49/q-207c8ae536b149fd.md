练习题 2.20 请说明等式（2.5）如何应用到练习题 2.19 的各项。为便于独立作答，相关定义和数据如下。

`T2U_w(x)` 将一个 `w` 位补码数保持位模式不变、重新解释成无符号数；等式（2.5）为：

$$
\mathrm{T2U}_{w}(x) = \begin{cases}
x + 2^{w}, & x < 0, \\\\
x, & x \ge 0.
\end{cases}
$$

练习题 2.19 的 `w = 4`，六个补码数依次为 `-8, -3, -2, -1, 0, 5`。请逐项指出使用哪个分支，并说明它得到的无符号值。
%%% reference
本题 `w = 4`，所以 $2^{w} = 16$。负数使用 $x + 16$ 分支，非负数使用 $x$ 分支：

| 补码数 $x$ | 使用的分支 | 无符号值 |
| --- | --- | --- |
| $-8$ | $x + 16$ | $8$ |
| $-3$ | $x + 16$ | $13$ |
| $-2$ | $x + 16$ | $14$ |
| $-1$ | $x + 16$ | $15$ |
| $0$ | $x$ | $0$ |
| $5$ | $x$ | $5$ |

转换只改变数值的解释方式，不改变原有的 4 位位模式。
