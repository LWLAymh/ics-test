练习题 2.20 请说明等式（2.5）如何应用到练习题 2.19 的各项。为便于独立作答，相关定义和数据如下。

`T2U_w(x)` 将一个 `w` 位补码数保持位模式不变、重新解释成无符号数；等式（2.5）为：

$$
T2U_w(x)=\begin{cases}x+2^w,&x<0,\\x,&x\ge 0.\end{cases}
$$

练习题 2.19 的 `w = 4`，六个补码数依次为 `-8, -3, -2, -1, 0, 5`。请逐项指出使用哪个分支，并说明它得到的无符号值。
%%% reference
表中前四项的 x 为负数，使用等式（2.5）的 x < 0 分支，即 `T2U₄(x) = x + 2⁴`。后两项 x 为非负数，使用 x ≥ 0 分支，即 `T2U₄(x) = x`。因此对应结果依次为 8、13、14、15、0、5。
