练习题 2.26 使用 `strlen` 判断字符串 `s` 是否比 `t` 长。其声明为 `size_t strlen(const char *s);`，原函数为：

```c
int strlonger(char *s, char *t) {
    return strlen(s) - strlen(t) > 0;
}
```

假定 `size_t` 是无符号整数类型：A. 什么情况下会返回错误结果？B. 为什么？C. 如何修改表达式使其可靠？
%%% reference
A. 当 s 比 t 短时，函数会错误地返回 1。

B. `strlen` 返回无符号数，差值按无符号算术计算。较短长度减较长长度会回绕为很大的正数，因此大于 0。

C. 直接比较长度：`return strlen(s) > strlen(t);`。
