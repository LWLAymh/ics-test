练习题 2.9 通过混合红、绿、蓝三种光（每种光可关闭 `0` 或打开 `1`）产生颜色。下图示意三种光源投射到玻璃屏幕上的情形：

![练习题 2.9 光源示意](assets/csapp/ch2/ex-2-9-color-lights.jpg)

基于光源 R（红）、G（绿）、B（蓝），可以创建以下八种颜色。RGB 位向量从高位到低位表示红、绿、蓝三个分量。

| RGB | 颜色 | RGB | 颜色 |
|---|---|---|---|
| `000` | 黑色 | `100` | 红色 |
| `001` | 蓝色 | `101` | 红紫色 |
| `010` | 绿色 | `110` | 黄色 |
| `011` | 蓝绿色 | `111` | 白色 |

A. 颜色的补是关闭已经打开的光源、打开已经关闭的光源。填写八种颜色各自的补色。

| 颜色编码 | 补色 |
|---|---|
| `000` | {{blank:c000}} |
| `001` | {{blank:c001}} |
| `010` | {{blank:c010}} |
| `011` | {{blank:c011}} |
| `100` | {{blank:c100}} |
| `101` | {{blank:c101}} |
| `110` | {{blank:c110}} |
| `111` | {{blank:c111}} |

B. 描述下列颜色应用布尔运算的结果：

| 运算 | 结果 |
|---|---|
| 蓝色 `\|` 绿色 | {{blank:op1}} |
| 黄色 `&` 蓝绿色 | {{blank:op2}} |
| 红色 `^` 红紫色 | {{blank:op3}} |
%%% reference
红、绿、蓝三个位分量逐位取反即可得到补色；表中三个布尔运算分别按 RGB 位向量执行，完整结果如下：

| 颜色/运算 | 位向量 | 结果 |
|---|---|---|
| 黑色的补 | `000` → `111` | 白色 |
| 蓝色的补 | `001` → `110` | 黄色 |
| 绿色的补 | `010` → `101` | 红紫色 |
| 蓝绿色的补 | `011` → `100` | 红色 |
| 红色的补 | `100` → `011` | 蓝绿色 |
| 红紫色的补 | `101` → `010` | 绿色 |
| 黄色的补 | `110` → `001` | 蓝色 |
| 白色的补 | `111` → `000` | 黑色 |
| 蓝色 `\|` 绿色 | `001 \| 010 = 011` | 蓝绿色 |
| 黄色 `&` 蓝绿色 | `110 & 011 = 010` | 绿色 |
| 红色 `^` 红紫色 | `100 ^ 101 = 001` | 蓝色 |
