%%% stem
`int` 为 32 位补码，`float` 为 IEEE 32 位，`double` 为 IEEE 64 位。产生任意整数，并转换为 `double`：

```c
int x = random();
int y = random();
int z = random();
double dx = (double)x;
double dy = (double)y;
double dz = (double)z;
```

对于以下表达式，判断是否总为 1；若是，解释原理；若否，给出反例。考察所有 32 位整数输入，整数部分按教材补码字模型处理，浮点运算按各自格式舍入；不使用 80 位扩展精度作为中间结果。

A. `(float)x == (float)dx`

B. `dx - dy == (double)(x - y)`

C. `(dx + dy) + dz == dx + (dy + dz)`

D. `(dx * dy) * dz == dx * (dy * dz)`

E. `dx / dx == dz / dz`
%%% reference
A 总成立。任何 32 位整数都可被 `double` 精确表示，两条路径最后都把同一个精确整数舍入到 `float`。

B 不总成立。例如 `x=2147483647`、`y=-1`：左边为 2147483648，补码字模型下 `x-y` 回绕为 −2147483648，右边为该负数。严格 ISO C 中该整数溢出未定义。

C 总成立。三个 32 位整数的和及所有两项和均在 `double` 的精确整数范围内（有效精度 53 位），所以没有舍入误差。

D 不总成立。例如 `x=y=2147483647`、`z=123456789`；两个计算顺序在第一次乘法舍入的误差不同，最终 `double` 结果不同。乘法结合律不普遍成立。

E 不总成立。例如 `x=0`、`z=1`，`dx/dx` 为 NaN，而 `dz/dz` 为 1，比较为假。若 x、z 都非零，则两边都为 1。
