下面对 `show_bytes` 的调用将输出什么结果？

```c
const char *s = "abcdef";
show_bytes((byte_pointer) s, strlen(s));
```

注意字母 `a` ~ `z` 的 ASCII 码为 `0x61` ~ `0x7A`。
%%% reference
它打印 `61 62 63 64 65 66`。`strlen` 不计算终止空字符，所以 `show_bytes` 只打印到字符 `'f'`。
