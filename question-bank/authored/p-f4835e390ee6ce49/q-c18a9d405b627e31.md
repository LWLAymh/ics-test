练习题 2.10 对于任一位向量 `a`，有 `a ^ a = 0`。考虑下面程序，其中 `x`、`y` 分别指向存储值 `a`、`b` 的位置：

```c
void inplace_swap(int *x, int *y) {
    *y = *x ^ *y;  /* Step 1 */
    *x = *x ^ *y;  /* Step 2 */
    *y = *x ^ *y;  /* Step 3 */
}
```

填写每一步后两个位置中的值，并利用 `^` 的属性说明最终实现了交换。表格中的初始值为 `a` 和 `b`。

说明上述结果如何由异或的交换律、结合律和 `a ^ a = b ^ b = 0` 得到。
%%% part-reference: q-c18a9d405b627e31-proof
第 1 步令 `*y = a ^ b`。第 2 步中 `*x = a ^ (a ^ b) = (a ^ a) ^ b = b`。第 3 步中 `*y = b ^ (a ^ b) = (b ^ b) ^ a = a`。因此位置中的两个值交换。
