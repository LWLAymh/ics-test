考虑下面对 `show_bytes` 的三次调用：

```c
int val = 0x87654321;
byte_pointer valp = (byte_pointer) &val;

show_bytes(valp, 1);  /* A. */
show_bytes(valp, 2);  /* B. */
show_bytes(valp, 3);  /* C. */
```

填写小端法机器和大端法机器上每次调用的输出：

| 调用 | 小端法 | 大端法 |
| --- | --- | --- |
| A | {{blank:le1}} | {{blank:be1}} |
| B | {{blank:le2}} | {{blank:be2}} |
| C | {{blank:le3}} | {{blank:be3}} |
%%% reference
| 调用 | 小端法 | 大端法 |
| --- | --- | --- |
| A | `21` | `87` |
| B | `21 43` | `87 65` |
| C | `21 43 65` | `87 65 43` |

`show_bytes` 从低地址开始列出字节。小端法从最低有效字节到最高有效字节排列，大端法顺序相反。
