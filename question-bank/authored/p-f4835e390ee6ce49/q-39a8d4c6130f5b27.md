练习题 2.39 对于从位位置 n 到位位置 m（n ≥ m）的连续 1，形式 B 使用表达式 `(x << (n+1)) - (x << m)`。当 n 为最高有效位时，我们要怎样修改该表达式？
%%% reference
形式 B 原为 `(x << (n+1)) - (x << m)`。当 n 是最高有效位时，`n+1 = w`，而把 x 左移 w 位得到 0。因此表达式等价于 `-(x << m)`。
