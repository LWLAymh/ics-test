练习题 2.41 对于从位位置 n 到位位置 m 的连续 1（n ≥ m），可用形式 A：`(x << n) + (x << (n-1)) + ... + (x << m)`，或形式 B：`(x << (n+1)) - (x << m)`。假设加法和减法开销相同，编译器应如何决定使用哪种形式？说明判断依据。
%%% reference
当 `n = m` 时选形式 A；当 `n = m + 1` 时两种形式都可；当 `n > m + 1` 时选形式 B。

理由：在 `m > 0` 时，形式 A 需要 `n-m+1` 次移位和 `n-m` 次加法；形式 B 需要两次移位和一次减法。边界 `m = 0` 时两者都少一次移位，但比较准则不变。
