%%% stem
练习题 2.11 在练习题 2.10 的 `inplace_swap` 函数基础上，下面的 `reverse_array` 试图将数组首尾元素依次对调：

```c
void reverse_array(int a[], int cnt) {
    int first, last;
    for (first = 0, last = cnt-1;
         first <= last;
         first++, last--)
        inplace_swap(&a[first], &a[last]);
}
```

该函数对偶数长度数组工作正常，但对 `{1, 2, 3, 4, 5}` 得到 `{5, 4, 0, 2, 1}`。
%%% reference

%%% part-stem: q-1d549f83cb6e20a7-A
若数组长度为奇数 `cnt = 2k + 1`，最后一次循环中 `first` 和 `last` 分别是多少？填写两个值：`first = {{blank:first}}`，`last = {{blank:last}}`。
%%% part-reference: q-1d549f83cb6e20a7-A
两者都为 `k`，即 `first = last = k`。
%%% part-stem: q-1d549f83cb6e20a7-B
解释最后一次调用 `inplace_swap` 为什么会把数组中间元素改成 0。
%%% part-reference: q-1d549f83cb6e20a7-B
此时 `&a[first]` 与 `&a[last]` 指向同一位置。第一次赋值等价于该位置执行 `v = v ^ v`，因此变为 0；后续两步仍在同一位置上运算，值保持为 0。异或交换的推导假设两个指针指向不同位置。
%%% part-stem: q-1d549f83cb6e20a7-C
对循环条件作什么简单修改即可避免该问题？
%%% part-reference: q-1d549f83cb6e20a7-C
将循环条件 `first <= last` 改为 `first < last`，中间元素无需与自身交换。
