练习题 2.25 考虑下面试图计算数组元素之和的代码。`length` 为无符号数。

```c
float sum_elements(float a[], unsigned length) {
    int i;
    float result = 0;
    for (i = 0; i <= length-1; i++)
        result += a[i];
    return result;
}
```

当 `length == 0` 时本应返回 `0.0`，却会遇到内存错误。解释原因并说明如何修改代码。
%%% reference
`length` 为无符号数，所以 `length-1` 在 `length==0` 时按模 `2^w` 运算得到 `UMax`。比较也按无符号数进行，循环条件对递增的非负 `i` 始终成立，最终访问数组界外元素。可将循环条件改为 `i < length`；或者将 length 改为有符号类型（实际代码还应考虑索引类型范围和一致性）。
