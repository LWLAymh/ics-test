练习题 2.53 完成下列宏定义，不使用任何 include 文件，生成双精度值 +∞、−∞ 和 −0。可以利用双精度最大有限数约为 `1.8×10^308`。

本题采用 IEEE 754 双精度语义，允许目标实现将超范围浮点字面量处理为无穷。表达式可有多种合法写法，填写后请与参考思路对照自评。

```c
#define POS_INFINITY {{blank:pos}}
#define NEG_INFINITY {{blank:neg}}
#define NEG_ZERO {{blank:zero}}
```
%%% reference
```c
#define POS_INFINITY 1e400
#define NEG_INFINITY (-POS_INFINITY)
#define NEG_ZERO (-1.0/POS_INFINITY)
```

此答案依赖题目采用的实现会把 `1e400` 溢出为正无穷。
