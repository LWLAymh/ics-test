练习题 2.38 LEA 指令可执行 `(a << k) + b`，其中 k 为 0、1、2 或 3，b 为 0 或某个程序值。考虑 b = 0 或 b = a 的情况，用一条 LEA 指令能计算 a 的哪些倍数？

选择所有可能的倍数（可多选）：{{blank:multipliers}}。
%%% reference
当 b = 0 时可得到倍数 `2^k`，即 1、2、4、8；当 b = a 时可得到 `2^k + 1`，即 2、3、5、9。合并并去重后是 1、2、3、4、5、8、9。
