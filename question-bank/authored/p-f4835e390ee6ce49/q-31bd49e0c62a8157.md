练习题 2.31 你的同事给出了下面的 `tadd_ok` 实现。假设其余函数都遵循本章的 w 位补码运算模型，解释为什么这个实现不能检测加法溢出。

```c
int tadd_ok(int x, int y) {
    int sum = x + y;
    return (sum - x == y) && (sum - y == x);
}
```
%%% reference
在 w 位补码加法的模 `2^w` 运算中，加法构成阿贝尔群，因此 `(x + y) - x` 总是还原为 `y`，`(x + y) - y` 总是还原为 `x`，即使 `x + y` 已溢出。这两个检查在该模型下仍会成立，所以返回值不能用来判断溢出。
