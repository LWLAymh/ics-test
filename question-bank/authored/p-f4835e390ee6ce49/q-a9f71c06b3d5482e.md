练习题 2.23 假定在采用补码的 32 位机器上执行，且有符号数值的右移是算术右移、无符号数值的右移是逻辑右移。考虑以下函数：

```c
int fun1(unsigned word) {
    return (int) ((word << 24) >> 24);
}

int fun2(unsigned word) {
    return ((int) word << 24) >> 24;
}
```

用语言描述 `fun1` 和 `fun2` 对参数执行的有用计算，并说明它们的区别。
%%% part-reference: q-a9f71c06b3d5482e-B
两函数都提取参数低 8 位。`fun1` 在无符号数上移位，右移为逻辑移位，因此返回 0 到 255 的值。`fun2` 先转换为 `int`，然后算术右移，低 8 位最高位为 1 时符号扩展，因此结果范围为 -128 到 127。
