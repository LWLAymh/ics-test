机器的 `int` 为 32 位补码，右移是算术右移，`unsigned` 也是 32 位。产生任意整数 `x`、`y` 并转换为无符号值：

```c
int x = random();
int y = random();
unsigned ux = (unsigned)x;
unsigned uy = (unsigned)y;
```

对于每个表达式，指出它是否总为 1；若是，解释数学原理；若否，给出使它为 0 的参数例子。按教材机器模型，考察所有 32 位 `x`、`y`，整数运算按补码字运算解释。

A. `(x < y) == (-x > -y)`

B. `((x + y) << 4) + y - x == 17 * y + 15 * x`

C. `~x + ~y + 1 == ~(x + y)`

D. `(ux - uy) == -(unsigned)(y - x)`

E. `((x >> 2) << 2) <= x`
%%% reference
A 不总成立。例如 `x = -2147483648`、`y = 0`：左侧比较为真，`-x` 在补码字模型下仍为最小负数，右侧比较为假。

B 总成立。模 $2^{32}$ 运算中，左侧为 $16(x+y)+y-x=15x+17y$。

C 总成立。补码恒等式为 `~x = -x - 1`，故两边都等于 `-x-y-1`（模 $2^{32}$）。

D 总成立。无符号减法按模 $2^{32}$ 计算，两边均为 $x-y$ 的同余类。

E 总成立。算术右移后左移清除最低两位，结果为 $4\lfloor x/4\rfloor\le x$。

这些判断使用题目的字级机器模型；严格 ISO C 对有符号溢出和部分有符号左移没有定义这种回绕行为。
