练习题 2.13 VAX 计算机只有 `bis`（位设置）与 `bic`（位清除）操作。`bis(x,m)` 在掩码 `m` 为 1 的位上设置 `x` 对应位；`bic(x,m)` 在掩码 `m` 为 1 的位上清除 `x` 对应位。假设函数声明如下：

```c
int bis(int x, int m);
int bic(int x, int m);
```

%%% reference
`bis(x,m)` 等价于 `x | m`；`bic(x,m)` 等价于 `x & ~m`。因此按提示替换对应的 OR 与 AND-NOT 组合。
