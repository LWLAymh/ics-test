%%% stem
14、仅考虑以下代码，哪些改写可以保持结果不变？（多选）假设 `int i, j, A[N], B[N], m, *p;` 中各变量均为局部量，A、B是两个独立数组，N为正整数常量，`int foo(int)` 可能有副作用。仅考虑数组下标有效、参与运算的值已初始化且不发生有符号溢出的输入，不讨论任意编译器是否开启相应优化。
%%% reference
答案：A、B。A、B是不同的局部数组，不会像两个任意数组指针那样发生别名；循环中对 `B[i]` 的反复更新可先用临时变量累积，再写回。N为正且下标有效的前提保证提前读写 `B[i]` 不引入零次循环时原本不存在的访存。B中的 `i*N` 在循环内不变，也可提到循环外。C、D中的 `foo` 可能有副作用，不能任意减少调用次数。

原卷单选答案只给B，并问“总是被编译器自动进行”，但未指定优化设置；同时题面将A、B明确声明为独立局部数组，使A在上述正常输入范围也可安全改写。网页改问保持结果的改写，并按多选AB核对，不声称所有编译器都保证实施这些优化。
%%% option: A
优化前：
```c
for (j = 0; j < N; j++)
    B[i] *= A[j];
```
优化后：
```c
int temp = B[i];
for (j = 0; j < N; j++)
    temp *= A[j];
B[i] = temp;
```
%%% option: B
优化前：
```c
for (j = 0; j < N; j++)
    m += i * N * j;
```
优化后：
```c
int temp = i * N;
for (j = 0; j < N; j++)
    m += temp * j;
```
%%% option: C
优化前：
```c
i = foo(N);
j = foo(N);
if (*p != 0)
    m = j;
```
优化后：
```c
j = foo(N);
if (*p != 0)
    m = j;
```
%%% option: D
优化前：
```c
for (j = 0; j < foo(N); j++)
    m++;
```
优化后：
```c
int temp = foo(N);
for (j = 0; j < temp; j++)
    m++;
```
