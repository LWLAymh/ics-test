%%% stem
9、对应下述组合电路的正确 HCL 表达式为

![组合电路：A、B 接上方与门，A、C 接下方与门，两个输出接或门](assets/期中/2014期中-带答案/q9-circuit-prompt.png)

（图：组合电路图，输入 A、B 经一个与门输出 D，输入 A、C 经另一个与门输出 E，D 与 E 再经一个或门输出 X）


%%% reference
答案：C。

上方与门输出 `D = A && B`，下方与门输出 `E = A && C`。因此 `X = D || E = (A && B) || (A && C) = A && (B || C)`。
%%% option: A
`Bool X = (A || B) && (A || C)`
%%% option: B
`Bool X = A || (B && C)`
%%% option: C
`Bool X = A && (B || C)`
%%% option: D
`Bool X = A || B || C`
