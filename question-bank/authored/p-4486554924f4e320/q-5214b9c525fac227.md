第六题（10 分）

请分析 Y86 ISA 中新加入的一条指令 `caddXX`（条件加法）。其功能可以参考 `add` 和 `cmovXX` 两条指令。

| 指令 | 第 1 字节高 4 位 | 第 1 字节低 4 位 | 第 2 字节高 4 位 | 第 2 字节低 4 位 |
| --- | --- | --- | --- | --- |
| `caddXX rA, rB` | `C` | `fn` | `rA` | `rB` |

在教材的SEQ处理器上执行这条指令，补全下表10空。已有操作前缀不重复填写；`M1`（也可写 `M_1`）表示读取1字节，寄存器与信号名称区分大小写。（每空1分）

| 阶段 | 操作 |
| --- | --- |
| Fetch | `icode:ifun ←` {{blank:fetch-memory}} `[PC]` |
| Fetch | `rA:rB ← M1[`{{blank:fetch-regids}}`]` |
| Fetch | `valP ←` {{blank:next-address}} |
| Decode | `valA ← R[`{{blank:source-a}}`]` |
| Decode | `valB ← R[`{{blank:source-b}}`]` |
| Execute | `valE ←` {{blank:alu-result}} |
| Execute | `Cnd ←` {{blank:condition}} |
| Memory | {{blank:memory}} |
| Write back | `if (Cnd) R[`{{blank:destination}}`] ← valE` |
| PC update | `PC ←` {{blank:pc}} |

`Cnd` 使用此前已有的条件码；可在条件成立时更新条件码，不允许无条件改写条件码。写回阶段按 `Cnd` 决定是否真正写寄存器，不能仅用始终写回的条件表达式替代。

答案：caddXX rA, rB 在 SEQ 各阶段的操作（每个操作 1 分）：

| Stage | caddXX rA, rB |
| --- | --- |
| Fetch | icode:ifun ← $M_{1}$[PC]；rA:rB ← $M_{1}$[PC+1]；valP ← PC+2 |
| Decode | `valA ← R[rA]` `valB ← R[rB]` |
| Execute | valE ← valA+valB；Cnd ← Cond(CC,ifun) |
| Memory | none |
| Write back | `if(Cnd) R[rB] ← valE` |
| PC update | PC ← valP |
