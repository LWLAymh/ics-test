```c
int fun(unsigned x) {
    int bit_sum = 0;
    while ((int) x > 0) {
        bit_sum += x % 10;
        x = x / 10;
    }
    if (bit_sum % 3 == 0)
        return 1;
    else
        return 0;
}
```
该程序用来判断一个不大于 $2^n-1$ 的非负整数是否为 3 的倍数，如果大于 $2^n-1$，则直接返回 1（3 分）。
