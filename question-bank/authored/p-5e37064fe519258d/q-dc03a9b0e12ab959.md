4.  在下列的x86-64汇编代码中，错误的是：
%%% reference
答案：BD（原卷：B/D 都对）
解析：B 的地址寄存器必须是 64 位寄存器；D 的括号里少了一个逗号。
%%% option: A
`movq %rax, (%rsp)`
%%% option: B
`movl $0xFF, (%ebx)`
%%% option: C
`movsbl (%rdi), %eax`
%%% option: D
`leaq (%rdx, 1), %rdx`
