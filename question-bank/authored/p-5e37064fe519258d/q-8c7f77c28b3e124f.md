%%% stem
12. 已有整数变量i、j、r和正整数常量n，整数数组a、b的实际容量足够容纳下面所有被访问下标，另有外部函数 `int mul(int, int)`。按教材固定字长整数运算模型比较以下源码变换；不借助越界或严格C有符号溢出UB推理，且编译器无法证明mul无副作用、返回值稳定。一般不能直接进行哪组变换？

原卷将a声明为 `a[n]` 却访问 `a[n*8]`，存在越界；这里明确足够容量以保留其程序优化考点。
A.
```c
/* 优化前 */
for (j = 0; j < n; ++j)
    a[n * 8] += b[j];

/* 优化后 */
int tmp = (n << 3);
for (j = 0; j < n; ++j)
    a[tmp] += b[j];
```

B.
```c
/* 优化前 */
for (j = 0; j < n; ++j)
    r = (r * a[j]) * b[j];

/* 优化后 */
for (j = 0; j < n; ++j)
    r = r * (a[j] * b[j]);
```

C.
```c
/* 优化前 */
for (j = 0; j < n; ++j)
    a[mul(n, i) + j] = b[j];

/* 优化后 */
int ni = mul(n, i);
for (j = 0; j < n; ++j)
    a[ni + j] = b[j];
```

D.
```c
/* 优化前 */
for (j = 1; j < n; ++j)
    a[0] += a[j];

/* 优化后 */
int tmp = 0;
for (j = 1; j < n; ++j)
    tmp += a[j];
a[0] += tmp;
```
%%% reference
答案：C。外部mul可能有副作用或返回不同值，不能随意减少调用次数。A的维度计算外提/强度削弱、B的整数结合、D的非别名累加均按本题指定模型理解。
