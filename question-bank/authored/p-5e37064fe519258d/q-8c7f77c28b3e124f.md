12. 假设已有声明`int i, int j, const int n, int r, int a[n], int`
`b[n], int mul(int, int)`以下程序优化编译器一般不会进行的是:
A.
```c
/* 优化前 */
for (j = 0; j < n; ++j)
    a[n * 8] += b[j];

/* 优化后 */
int tmp = (n << 3);
for (j = 0; j < n; ++j)
    a[tmp] += b[j];
```

B.
```c
/* 优化前 */
for (j = 0; j < n; ++j)
    r = (r * a[j]) * b[j];

/* 优化后 */
for (j = 0; j < n; ++j)
    r = r * (a[j] * b[j]);
```

C.
```c
/* 优化前 */
for (j = 0; j < n; ++j)
    a[mul(n, i) + j] = b[j];

/* 优化后 */
int ni = mul(n, i);
for (j = 0; j < n; ++j)
    a[ni + j] = b[j];
```

D.
```c
/* 优化前 */
for (j = 1; j < n; ++j)
    a[0] += a[j];

/* 优化后 */
int tmp = 0;
for (j = 1; j < n; ++j)
    tmp += a[j];
a[0] += tmp;
```
