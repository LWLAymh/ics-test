%%% stem
6. 在 Y86-64 的 PIPE 实现中，仅考虑 `ICALL`、`IPOPQ`、`IPUSHQ`、`IRET` 指令，对 `mem_addr` 的 HCL 描述如下：

```hcl
word mem_addr = [
    M_icode in { ①, ② } : M_valE;
    M_icode in { ③, ④ } : M_valA;
];
```

其中四个空应如何填写？
%%% reference
答案：A
%%% option: A
① `IPUSHQ`　② `ICALL`　③ `IPOPQ`　④ `IRET`
%%% option: B
① `IPUSHQ`　② `IRET`　③ `ICALL`　④ `IRET`
%%% option: C
① `IPUSHQ`　② `IPOPQ`　③ `IRET`　④ `ICALL`
%%% option: D
