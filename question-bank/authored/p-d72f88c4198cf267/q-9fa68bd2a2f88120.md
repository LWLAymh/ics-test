8. 以下哪些选项可以在给定条件下进行所列的完整代码替换？（多选）假设 `N>0`，有关变量已初始化、所有索引与实际访存有效，整数运算不溢出，变量均非 `volatile`。`int i`、`int j`、`int m`、`int A[N]`、`int B[N]` 均为局部变量，`A`、`B` 是两个独立数组；`temp` 为新引入的临时整数；`foo` 可能有副作用。这段代码之后仍会观察 `i`、`j` 的最终值。

> 原卷把A/B声明为独立局部数组，却以二者可能别名否定A；“仅考虑以下代码”也未明确D中i/j的后续活跃性。这里保留数组声明、补齐条件并按语义是否合法判断，不再承诺所有编译器必然执行某个优化。
%%% reference
答案：AB（修正原键B）。A中的两个独立数组不重叠，循环内的A[j]不会被B[i]的写入改变，故可将B[i]累积值保存在临时变量；B的 `i*N` 是循环不变量，可提到循环外。C不能删除未知副作用调用；D虽可推导m=7，却不能删除后续仍观察的i/j赋值。N>0和有效索引排除了A提前读取在原循环零次执行时才会出现的额外访问。
%%% option: A
| 优化前 | 优化后 |
| --- | --- |
| `for (j = 0; j < N; j++) { B[i] *= A[j]; }` | `int temp = B[i]; for (j = 0; j < N; j++) { temp *= A[j]; } B[i] = temp;` |
%%% option: B
| 优化前 | 优化后 |
| --- | --- |
| `for (j = 0; j < N; j++) { m += i*N*j; }` | `temp = i*N; for (j = 0; j < N; j++) { m += temp*j; }` |
%%% option: C
| 优化前 | 优化后 |
| --- | --- |
| `i = foo(N); j = foo(N)+1; if (i != j) { m = j; }` | `m = j;` |
%%% option: D
| 优化前 | 优化后 |
| --- | --- |
| `if (m == 1) { i=3; j=4; } else { i=4; j=3; } m=i+j;` | `m = 7;` |
