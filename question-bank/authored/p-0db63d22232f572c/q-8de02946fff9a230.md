考虑练习题 5.1 的过程：

```c
void swap(long *xp, long *yp)
{
    *xp = *xp + *yp;
    *yp = *xp - *yp;
    *xp = *xp - *yp;
}
```

若 `xp == yp` 且该位置初值为 `3`，过程结束后该位置的值是多少？
%%% reference
因为两个指针指向同一位置，三次赋值依次将值变为 `6`、`0`、`0`。
%%% option: A
`0`
%%% option: B
`3`
%%% option: C
