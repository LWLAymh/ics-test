练习题 5.4

用命令行选项 `-O2` 的 GCC 编译 `combine3`，所得 CPE 性能明显优于 `-O1`：

| 函数 | 方法 | 整数 `+` | 整数 `*` | 浮点数 `+` | 浮点数 `*` |
| --- | --- | ---: | ---: | ---: | ---: |
| `combine3` | 用 `-O1` 编译 | 7.17 | 9.02 | 9.02 | 11.03 |
| `combine3` | 用 `-O2` 编译 | 1.60 | 3.01 | 3.01 | 5.01 |
| `combine4` | 累积在临时变量中 | 1.27 | 3.01 | 3.01 | 5.01 |

其中 `combine3` 的原始 C 代码如下；浮点乘法版本取 `data_t = double`、`IDENT = 1.0`、`OP = *`。`vec_length` 返回向量长度，`get_vec_start` 返回数据数组首地址。

```c
void combine3(vec_ptr v, data_t *dest)
{
    long i;
    long length = vec_length(v);
    data_t *data = get_vec_start(v);
    *dest = IDENT;
    for (i = 0; i < length; i++) {
        *dest = *dest OP data[i];
    }
}
```

考虑浮点乘法版本的内循环，`%rbx` 保存 `dest`，`%rdx` 保存 `data+i`，`%rax` 保存 `data+length`。以下是两个优化等级的循环代码：

```asm
# -O2
.L22:
    vmulsd  (%rdx), %xmm0, %xmm0
    addq    $8, %rdx
    cmpq    %rax, %rdx
    vmovsd  %xmm0, (%rbx)
    jne     .L22
```

```asm
# -O1
.L17:
    vmovsd  (%rbx), %xmm0
    vmulsd  (%rdx), %xmm0, %xmm0
    vmovsd  %xmm0, (%rbx)
    addq    $8, %rdx
    cmpq    %rax, %rdx
    jne     .L17
```

两个循环除指令顺序外，差异是 `-O2` 版本移除了从 `dest` 读入 `%xmm0` 的 `vmovsd`。回答：

A. `%xmm0` 在两个循环中的角色有什么不同？

B. 更优化版本是否忠实实现 `combine3` 的 C 代码（包括 `dest` 与向量数据之间存在内存别名的情况）？

C. 解释为何该优化保持期望行为，或给出一个会产生不同结果的反例。
%%% reference
A. 在 `-O1` 循环中 `%xmm0` 是每次迭代从 `dest` 读入、运算后写回的临时值；在 `-O2` 循环中它作为跨迭代的累加器保存向量元素乘积，类似 `combine4` 的临时变量。

B. 是；两个版本功能相同，且保持了相同的内存别名语义。

C. 每轮开始时从 `dest` 读出的值正是上一轮结束写回的累积值（首次迭代前结果位置已初始化为单位元），所以可直接使用仍保存在 `%xmm0` 的累积值，省去冗余读取而不改变结果。
