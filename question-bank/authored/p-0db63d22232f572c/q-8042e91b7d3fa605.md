下面的函数计算 `n` 个双精度数的乘积，主循环展开 3 次：

```c
double aprod(double a[], long n)
{
    long i;
    double x, y, z;
    double r = 1;
    for (i = 0; i < n - 2; i += 3) {
        x = a[i];
        y = a[i + 1];
        z = a[i + 2];
        r = r * x * y * z;  /* Product computation */
    }
    for (; i < n; i++)
        r *= a[i];
    return r;
}
```

对标记的乘积运算，可以使用下表中的五种结合方式。假设每次浮点乘法延迟为 5 周期，无相关的乘法可重叠执行。确定**仅由乘法数据相关**限制的主循环 CPE 下界（周期／元素，不计尾部循环开销）。可输入精确分数，或四舍五入到小数点后两位。原题建议画依赖图辅助思考，但不要求提交图。

| 方式 | 替换语句 | CPE 下界 |
| --- | --- | --- |
| A1 | `r = ((r * x) * y) * z;` | {{blank:a1}} |
| A2 | `r = (r * (x * y)) * z;` | {{blank:a2}} |
| A3 | `r = r * ((x * y) * z);` | {{blank:a3}} |
| A4 | `r = r * (x * (y * z));` | {{blank:a4}} |
| A5 | `r = (r * x) * (y * z);` | {{blank:a5}} |
%%% reference
每轮计算 3 个元素，若从旧 `r` 到新 `r` 的依赖链有 `P` 次乘法，则下界为 `5*P/3` 周期／元素。

| 方式 | 依赖链乘法数 P | CPE 下界 |
| --- | ---: | --- |
| A1 | 3 | `5` |
| A2 | 2 | `10/3`，约 `3.33` |
| A3 | 1 | `5/3`，约 `1.67` |
| A4 | 1 | `5/3`，约 `1.67` |
| A5 | 2 | `10/3`，约 `3.33` |

只含 `x`、`y`、`z` 的乘积不依赖前一轮的 `r`，可提前或重叠计算；不能把每轮三个乘法的总延迟都当作跨迭代关键路径。
