对次数为 `n` 的多项式求值：

$$
a_0+a_1x+a_2x^2+\cdots+a_nx^n
$$

参数 `degree = n`，假设 `n` 为非负整数。下面的函数同时计算连续的多项式项和 `x` 的幂：

```c
double poly(double a[], double x, long degree)
{
    long i;
    double result = a[0];
    double xpwr = x;
    for (i = 1; i <= degree; i++) {
        result += a[i] * xpwr;
        xpwr = x * xpwr;
    }
    return result;
}
```

参考机的浮点加法延迟为 3 周期，浮点乘法延迟为 5 周期；允许无相关运算重叠执行。

%%% part-stem: q-71b6af082391dc45-a
A. 对次数 `n`，代码执行多少次浮点加法和乘法？只统计多项式求值运算，不计索引更新。使用 `n` 表示次数，可用 `2*n` 这样的形式输入。

加法：{{blank:adds}} 次；乘法：{{blank:mults}} 次。
%%% part-reference: q-71b6af082391dc45-a
加法 `n` 次，乘法 `2*n` 次。循环执行 `n` 次，每轮有一个加法、两个乘法。
%%% part-stem: q-71b6af082391dc45-b
B. 测得该函数 CPE 为 5.00。根据 `result` 与 `xpwr` 更新在连续迭代之间形成的数据相关，解释这个 CPE。
%%% part-reference: q-71b6af082391dc45-b
关键的跨迭代依赖是 `xpwr = x * xpwr`，下一轮必须等上一轮的幂计算完成，延迟为 5 周期。`result` 的累加链每轮只有一次 3 周期的加法；`a[i] * xpwr` 可以利用执行单元流水线与其它工作重叠。因此限制 CPE 的是幂的乘法依赖链，而不是每轮所有运算延迟之和。
