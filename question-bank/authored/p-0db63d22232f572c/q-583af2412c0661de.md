三个保持相同行为的函数版本，运行时间近似为：

| 版本 | 时间（时钟周期） |
| --- | --- |
| 1 | `60 + 35*n` |
| 2 | `136 + 4*n` |
| 3 | `157 + 1.25*n` |

`n` 为非负整数。每个版本在 `n` 取什么值时是三者中最快的？填写区间端点：

- 版本 1：`0 <= n <=` {{blank:v1max}}。
- 版本 2：{{blank:v2min}} `<= n <=` {{blank:v2max}}。
- 版本 3：`n >=` {{blank:v3min}}。
%%% reference
版本 1 在 `n <= 2` 最快；版本 2 在 `3 <= n <= 7` 最快；版本 3 在 `n >= 8` 最快。

两两比较线性时间，并将交点取整到允许的整数 `n` 区间即可。例如版本 2 与版本 3 在 `n = 21/2.75` 处相等，介于 7 与 8 之间。
