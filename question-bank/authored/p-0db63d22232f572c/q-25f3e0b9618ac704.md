%%% stem
用 Horner 法计算次数为 `n` 的多项式，`degree = n` 且 `n` 为非负整数：

$$
a_0+x\bigl(a_1+x(a_2+\cdots+x(a_{n-1}+xa_n)\cdots)\bigr)
$$

```c
double polyh(double a[], double x, long degree)
{
    long i;
    double result = a[degree];
    for (i = degree - 1; i >= 0; i--)
        result = a[i] + x * result;
    return result;
}
```

参考机的浮点加法延迟为 3 周期，浮点乘法延迟为 5 周期。作为对比，直接求值法每轮执行 `result += a[i] * xpwr; xpwr = x * xpwr;`，其跨迭代的 `xpwr` 依赖链只有一次乘法。

B. 测得 Horner 版本的 CPE 为 8.00。根据连续迭代对 `result` 的数据相关解释这一数值。

C. 为什么直接求值法虽然执行更多操作，却能够比这个 Horner 版本运行得更快？
%%% part-reference: q-25f3e0b9618ac704-b
B. 每轮的 `result = a[i] + x * result` 必须先乘（5 周期）再加（3 周期），新 `result` 又是下一轮的输入，所以跨迭代关键路径为 8 周期。

C. 直接求值法每轮虽然有两个乘法，但只有计算 `xpwr` 的一个乘法在跨迭代关键路径上，另一乘法可与其它工作重叠，瓶颈为 5 周期。总运算数更少不等于依赖链更短。
