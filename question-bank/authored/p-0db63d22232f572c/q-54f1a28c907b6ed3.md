考虑数组复制中的加载—存储相关：

```c
void copy_array(long *src, long *dest, long n)
{
    long i;
    for (i = 0; i < n; i++)
        dest[i] = src[i];
}
```

数组 `a` 长度为 1000，每个小问都从独立的初始状态 `a[i] = i` 开始（`0 <= i <= 999`）。**源正文初值转写为 `a[i] = 1`，与所附答案矛盾；这里明确采用与源答案一致的 `a[i] = i`。**
%%% reference

%%% part-stem: q-54f1a28c907b6ed3-a
A. 调用 `copy_array(a + 1, a, 999)` 后，对 `0 <= i <= 998`，`a[i] =` {{blank:value}}。`a[999]` 不变。请使用关于 `i` 的简单表达式。
%%% part-reference: q-54f1a28c907b6ed3-a
`a[i] = i + 1`。每轮从尚未覆盖的下一元素读取，最后一个元素仍为 999。
%%% part-stem: q-54f1a28c907b6ed3-b
B. 调用 `copy_array(a, a + 1, 999)` 后，对 `1 <= i <= 999`，`a[i] =` {{blank:value}}。`a[0]` 不变。
%%% part-reference: q-54f1a28c907b6ed3-b
全为 `0`。第一轮将 `a[0]` 的 0 写入 `a[1]`，下一轮又读取这个刚写入的 0，如此传播到数组末尾。
%%% part-stem: q-54f1a28c907b6ed3-c
C. 在参考机上，A 的 CPE 为 1.2（4 次展开后约为 1.0），B 的 CPE 为 5.0。什么因素造成了这样的差异？
%%% part-reference: q-54f1a28c907b6ed3-c
B 每轮加载的地址恰好是前一轮存储的地址，存在跨迭代的写／读相关，下一轮必须等前一轮的存储值可用。A 中前一轮的写入地址不会成为下一轮的读取地址，加载与存储能够更充分重叠。
%%% part-stem: q-54f1a28c907b6ed3-d
D. 在同一参考机、相同未展开循环条件下，预计 `copy_array(a, a, 999)` 的 CPE 约为多少？{{blank:cpe}} 周期／元素。
%%% part-reference: q-54f1a28c907b6ed3-d
约 `1.2`，与 A 相同。虽然同一轮读写同一位置，但相邻轮访问不同元素，不形成 B 那样的跨迭代写／读依赖。
