### 6.3 过程调用和栈帧（8 分）

考虑以下两个 C 语言函数：

```c
long increase(long *p, long delta) {
    long old = *p;
    *p = old + delta;
    return old;
}

long run(long x, long y) {
    long local = 2 * x;
    long old = increase(&local, y);
    return old + local + x;
}
```

假设运算不发生有符号整数溢出。下面是一种实现函数 `run` 的 x86-64、AT&T 汇编代码。参数 `x`、`y` 分别存放在 `%rdi`、`%rsi`，返回值存放在 `%rax`。

```asm
run:
    pushq %rbx
    subq $16, %rsp
    movq %rdi, %rbx
    leaq (%rdi,%rdi), %rax
    movq %rax, 8(%rsp)
    {{blank:address}}   # (1) 传递 &local
    call increase
    {{blank:local}}     # (2) 将更新后的 local 加入返回值
    {{blank:x}}         # (3) 将原参数 x 加入返回值
    addq $16, %rsp
    popq %rbx
    ret
```

1. 根据已有代码和注释，在（1）至（3）处各填入一条完整指令，每空 2 分。含义明确时可省略 `%` 和 `q` 后缀，空格差异不影响核对。
2. 调用 `run(4, 3)` 时，函数返回值为（十进制）：{{blank:value}}（2 分）
%%% reference
各空实际填入内容：

| 空位 | 内容 |
| --- | --- |
| （1） | `leaq 8(%rsp), %rdi` |
| （2） | `addq 8(%rsp), %rax` |
| （3） | `addq %rbx, %rax` |
| 返回值 | `23` |

`run` 将 `x` 保存在 `%rbx` 中；`local = 2*x` 位于 `8(%rsp)` 指向的 8 字节空间。第一空传递 `&local`，第二个参数 `y` 仍在 `%rsi`。

`increase` 修改 `local`，但返回修改前的值。调用 `run(4, 3)` 时：

| 数据 | 值 |
| --- | --- |
| `local` 初始值 | `8` |
| `increase` 返回的 `old` | `8` |
| 更新后的 `local` | `11` |
| 原参数 `x` | `4` |
| 最终结果 | `8 + 11 + 4 = 23` |

第三空也可用 `leaq` 对 `%rax`、`%rbx` 直接求和，这里后续不依赖条件码。
