### 6.2 过程调用（4 分）

考虑以下 C 语言函数：

```c
long twice(long a) {
    return 2 * a;
}

long combine(long x, long y) {
    long t = x;
    long v = twice(y);
    return t + v;
}
```

假设运算不发生有符号溢出。在 x86-64 Linux 参数传递规则下，前 6 个整数或指针参数依次通过 `%rdi`、`%rsi`、`%rdx`、`%rcx`、`%r8`、`%r9` 传递，第 7 个及之后的参数通过栈传递。

下面是一种对应的 AT&T 汇编实现，补全两条完整指令，每空 2 分：

```asm
combine:
    pushq %rbx
    movq %rdi, %rbx
    {{blank:argument}}
    call twice
    {{blank:result}}
    popq %rbx
    ret
```

按原卷批卷说明，含义明确时可省略寄存器前的 `%` 和指令的 `q` 后缀；空格差异不影响核对。
%%% reference
各空实际填入的完整指令为：

```asm
    movq %rsi, %rdi
    addq %rbx, %rax
```

调用 `twice(y)` 前，将 `y` 从 `%rsi` 移到第一个参数寄存器 `%rdi`。原参数 `x` 已保存在被调用者保存寄存器 `%rbx` 中，跨过 `twice` 调用仍可使用。`twice` 的返回值在 `%rax`，加上 `%rbx` 即得最终结果。

`combine` 自身使用了 `%rbx`，因此用 `pushq`、`popq` 为自己的调用者保存并恢复它。第二空也接受直接用 `leaq` 计算这两个寄存器之和；这里后续不依赖加法的条件码。
