### 2.3 整数（4 分）

考虑以下 C 语言代码，假设 `int` 和 `unsigned int` 均为 32 位：

```c
unsigned int count = 3U;
int change = -5;

int a = (change < count);
unsigned int next = count + change;
int b = (next > count);
```

1. `a` 的值为（十进制）：{{blank:a}}（2 分）
2. `b` 的值为（十进制）：{{blank:b}}（2 分）
%%% reference
各空依次为 `0`、`1`。

比较时，`change` 转换为 32 位无符号整数，值为 $2^{32}-5$，大于 `3`，因此 `a = 0`。

无符号加法按模 $2^{32}$ 计算，`count + change` 的结果为 $2^{32}-2$，大于 `count`，因此 `b = 1`。
