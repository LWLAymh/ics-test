### 3.5 浮点运算（4 分）

考虑以下 C 语言代码。假设 `float` 使用 IEEE 754 单精度格式，采用默认的向偶数舍入规则，每次浮点运算都按单精度舍入，不采用额外精度，也不改变表达式中的运算顺序。

```c
float x = 16777216.0f;  // 2^24
float y = 1.0f;
float a = x + y;
float b = (x + y) - x;
float c = (x - x) + y;
```

1. `b` 的值为：{{blank:b}}（2 分）
2. `c` 的值为：{{blank:c}}（2 分）
%%% reference
各空依次为 `0.0`、`1.0`。

在 $2^{24}$ 附近，单精度可表示数的间隔为 `2`；`x + 1.0f` 恰在中点，向偶数舍入回 `x`，因此 `b = 0.0f`。`x - x` 先得到 `0.0f`，再加 `y` 得到 `c = 1.0f`。这体现浮点加法不满足结合律。
