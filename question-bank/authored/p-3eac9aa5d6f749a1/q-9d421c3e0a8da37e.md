### 5.3 循环结构（4 分）

考虑以下 x86-64、AT&T 汇编代码。函数参数 `x` 存放在 `%rdi`，返回值存放在 `%rax`。

```asm
sum_pairs:
    movl $0, %eax
    jmp .Ltest
.Lbody:
    movq %rdi, %rdx
    andq $3, %rdx
    addq %rdx, %rax
    shrq $2, %rdi
.Ltest:
    testq %rdi, %rdi
    jne .Lbody
    ret
```

该代码与下面的 C 语言函数对应。原卷只要求填写 **（b）** 并计算指定参数下的返回值；（a）、（c）不是本题的作答项。

```c
long sum_pairs(unsigned long x) {
    long result = 0;
    while (______________) {        // (a)，本题不要求填写
        result += {{blank:b}};      // (b)
        x = _______________;        // (c)，本题不要求填写
    }
    return result;
}
```

1. 在（b）处只填缺失的右侧表达式，不重复 `result +=` 或分号。（2 分）
2. 当参数 `x = 0x1B` 时，函数返回值为（十进制）：{{blank:value}}（2 分）
%%% reference
两空依次为 `x & 3`、`6`。

每轮提取 `x` 的最低两位（`0` 到 `3`），累加后将 `x` 逻辑右移两位，直到为 `0`。`0x1B` 从低到高每两位的数值依次是 `3`、`2`、`1`，总和为 `6`。

下面是补齐后的完整 C 代码，仅供对照；输入框只要求（b）的表达式。

```c
long sum_pairs(unsigned long x) {
    long result = 0;
    while (x != 0) {
        result += x & 3;
        x = x >> 2;
    }
    return result;
}
```
