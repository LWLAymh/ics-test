### 8.1 结构与联合（3 分）

采用原卷默认的 x86-64 Linux 环境及默认对齐规则。考虑以下类型定义：

```c
struct S {
    char c;
    long x;
};

union U {
    char c;
    long x;
};
```

以下说法哪些正确？（不定项选择）

原卷计分：全对得 3 分，少选得 1 分，错选或不选得 0 分。网站练习按现有多选规则核对：选项集合完全一致才算正确，不模拟原卷的少选部分分。
%%% reference
正确选项：A、B、D。

`struct S` 中，`c` 在偏移 `0`，`x` 在偏移 `8`，整体为 `16` 字节，二者不共享存储空间。`union U` 的成员从同一地址开始，整体大小为最大成员的大小 `8` 字节。
%%% option: A
`sizeof(struct S)` 的值为 `16`。
%%% option: B
`sizeof(union U)` 的值为 `8`。
%%% option: C
`struct S` 的成员 `c` 和 `x` 占用相同的存储空间。
%%% option: D
`union U` 的成员 `c` 和 `x` 具有相同的起始地址。
