%%% stem
19. 在以下基于线程的并发Echo服务器代码中，哪一个代码片段会潜在引发
不正确的程序执行结果？
%%% reference
答案：C（来源：2019、2020期末-答案解析）
解析：`connfd` 是主线程的局部变量，把 &connfd 传给对等线程会在「主线程下一次 accept 赋值」与「线程读取 *vargp」之间引入竞争，可能读到错误的描述符。
%%% option: A
```c
int main(int argc, char **argv)
{                              /*假设有配对的”}”
        int listenfd, connfd;
        socklen_t clientlen;
        struct sockaddr_storage clientaddr;
        pthread_t tid;
```
%%% option: B
`listenfd = Open_listenfd(argv[1]);`
%%% option: C
```c
while (1) {
      connfd = Accept(listenfd, (SA *) &clientaddr,
&clientlen);
      Pthread_create(&tid, NULL, thread, &connfd);
    }
```
%%% option: D
```c
void *thread(void *vargp)
{
      int connfd = *((int *)vargp);
      Pthread_detach(pthread_self());
      echo(connfd);
      Close(connfd);
      return NULL;
}
```
