%%% stem
1.  已知浮点运算表达式：

```c
t = a + b; x = t + c; y = d + t;
```

各操作数及结果均有限，每次运算按相同浮点格式舍入，不使用重结合优化。下列改写中，哪一项不能保证对任意输入同时得到与原程序相同的 x、y？
%%% reference
答案：A（来源：2019、2020期末-答案解析）
解析：A 的 y 按左结合先算 `d+a`，再加 b，改变了原来的 `d+(a+b)` 的舍入位置；并非原解析括号中所说的先算 b+d。它对某些输入可能相同，但不能保证所有输入相同。其余保持同一对数先相加，只交换有限操作数的加法顺序。
%%% option: A
`x = a + b + c; y = d + a + b;`
%%% option: B
`x = a + b + c; y = d + (a + b);`
%%% option: C
`x = c + (a + b); y = a + b + d;`
%%% option: D
`x = (a + b) + c; y = d + (a + b);`
