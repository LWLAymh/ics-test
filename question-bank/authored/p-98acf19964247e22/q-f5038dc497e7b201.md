第五题（10分）
某32位机器有24位地址空间，采用二级页表，一级页表中有64个`PTE`，二
级页表中有1024个`PTE`，一级页表4KB对齐，`PTE`最高一位是有效位，没有
TLB和Cache。惠楚思程序员在该机器上执行了如下代码。
```
1. int* a=calloc(10000, sizeof(int));
2. int* b = a+5000;
3. fork();
4. *b=0x80C3F110;
```
（1）  假设编译后 `b` 的值保存在寄存器中，请问该机器页面大小为{{blank:page-size}}字
节，`VPN1`长度为{{blank:vpn1-length}}，`VPN2`长度为{{blank:vpn2-length}}。

（2）  由于该执行结果不符合预期，惠楚思需要对程序执行过程进行还原。
程序执行过程中硬件记录了部分内存访问记录，但访问记录并不完整。目前已
知在父进程执行第四行的时候，进行了若干次物理内存的读写操作，其中第一
次读内存操作从地址 `0x67F0E8` 读出 `0x80AA32C4`，另外有两次将
`0x80C3F110`写入内存的操作，写入的地址分别是`0xC3F50D`和`0xAA3AD0`，
但写入顺序并不清楚。程序结束后变量`b`中保存的值是{{blank:b-value}}。在
解析“*b”的过程中，一级页表的起始地址为{{blank:l1-address}}；二级页表
的起始地址为{{blank:l2-address}}；物理页面的起始地址为{{blank:page-address}}。
（地址均用16进制表示）
%%% reference
答案：（1）页面大小为 4096 字节，VPN1 长 6 位，VPN2 长 10 位。
（2）`b` 中保存的值为 `0xEAB450D`；一级页表起始地址 `0x67F000`；二级页表起始地址 `0xAA3000`；物理页面起始地址 `0xC3F000`。
解析：一级页表 64 个 `PTE → VPN1=6` 位，二级页表 1024 个 `PTE → VPN2=10` 位，`VPO=12` 位，共 28 位虚拟地址。`VPO=0x50D`，`VPN2=(0xAA3AD0-0xAA3000)/4=0x2B4`，`VPN1=(0x67F0E8-0x67F000)/4=0x3A`，拼出的虚拟页号为 `0xEAB4`，故 `b=0xEAB450D`。
勘误：题面写「32 位机器有 24 位地址空间」，解析按 Arthals 勘误取 28 位虚拟地址。
