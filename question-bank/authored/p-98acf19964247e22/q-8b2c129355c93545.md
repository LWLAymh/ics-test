%%% stem
14. 采用迭代的Echo 服务器服务多个客户端，假设client1 先完成连接，
并且没有结束，那么 client2 向服务器发出连接请求后，会被阻塞在下
列哪个函数上？
%%% reference
答案：B（来源：2019、2020期末-答案解析）
解析：connect 在服务端 accept 之前就已返回（三次握手完成、连接进入已连接队列）；迭代服务器还在服务 client1，client2 的连接只能排队，随后阻塞在 read 上等服务器回应。
%%% option: A
connect
%%% option: B
read
%%% option: C
write

socket
