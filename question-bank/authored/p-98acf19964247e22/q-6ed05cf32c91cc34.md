3.

```c
int x = -2019;
int a = (x / 8) * 8;
int b = ((x + 7) >> 3) << 3;
int c = -(((~x)+1) >> 3) << 3;
```
a, b, c大小关系是什么？
%%% reference
答案：A（来源：2019、2020期末-答案解析）
解析：`a = (-2019/8)*8 = -2016`；`b = ((-2019+7)>>3)<<3 = -2016`；`c = -(((~x)+1)>>3)<<3 = -2016`，故 `a=b=c`。
%%% option: A
`a=b, b=c`
