第二题（10分）
现有如下汇编代码段，相关寄存器的初始值也在右侧表格中给出:
```
.L2:
    movq    (%rdi), %rbx
    addq    %rbx, %rax
    addq    $8, %rdi
    addq    $1, %rcx
    cmpq    $8, %rcx
    jl     .L2
```
初始寄存器值：`%rdi = 0x8008`，`%rax = 0`，`%rbx = 0`，`%rcx = 0`。

（1）  请在下面C代码中，补充缺失的部分。
```
  for(i=0; i<_____ ; i++)
  {
    sum=sum+a[i];
  }
```
%%% part-reference: q-57ec38ee956f34b3
答案：8（来源：2019、2020期末-答案解析）
解析：循环体每轮 `rdi` 加 8、`rcx` 加 1，`rcx<8` 时继续，故数组下标上界为 8。
%%% part-stem: q-384c822e93f6ad37
（2）  现有一个类似课上SEQ的处理器来运行上述汇编代码，在理想情况下，其
每个周期可以处理完一条汇编代码，请计算：理想情况下，执行完上述代码段
（即结束循环）一共需要 {{blank:cycles}} 个周期？
%%% part-reference: q-384c822e93f6ad37
答案：48 个周期（来源：2019、2020期末-答案解析）
解析：8 次循环 × 6 条指令 = 48 个周期。
%%% part-stem: q-7ebc4d63395e862f
（3）  现在考虑数据缓存（data cache）对该处理器的影响。
该处理器配置了一个简单的直接映射（direct-mapped，`E=1`）数据缓存，
总容量32KB，每个缓存块的大小是64Byte。对于`movq`指令，如果被访问
的数据在该缓存中，则1个周期可以处理完成。否则，则需要2个周期才能完
成。在运行上述汇编代码之前，数据缓存初始状态为空，其他设置同上一问。
请再次计算：完成上述汇编代码段一共需要 {{blank:cycles-cache}} 个周期？
%%% part-reference: q-7ebc4d63395e862f
答案：50 个周期（来源：2019、2020期末-答案解析）
解析：直接映射数据缓存块 64B，可放 8 个长整数；起始地址 `0x8008` 不是 64 字节对齐，所以 8 次访存中有 2 次不命中，额外付 `2×(2-1)=2` 个周期 `→ 48+2 = 50`。
%%% part-stem: q-3569c67504ccc569
（4）  为了提升处理器的性能，增加了一个加法器。因此，在没有数据依赖、并
且不改变指令顺序的情况下，新的处理器可以同时处理两个`addq`指令、或者
一个`addq`加一个compq指令。注意：`movq`和跳转指令仍旧需要单独执行，
其他设置同上一问。请再次计算：完成上述汇编代码段一共需要 {{blank:cycles-two-adders}} 个周期？
%%% part-reference: q-3569c67504ccc569
答案：42 个周期（来源：2019、2020期末-答案解析）
解析：增加的加法器只能让前两个 `addq` 一次执行完，这样能节省 8 个周期，`50-8 = 42`。
%%% part-stem: q-97ee53783d7536e8
（5）  为了进一步减少处理时间，程序员将代码进行循环展开，新的代码如下：
```asm
.L2:
    movq    (%rdi), %rbx
    movq    8 (%rdi), %rdx
    addq    %rbx, %rax
    addq    %rdx, %rax
    addq    $16, %rdi
    addq    $2, %rcx
    cmpq    $8, %rcx
    jl     .L2
```
假设在不影响程序正确性的情况下，可以调整上述指令的顺序，请问最
短需要 {{blank:cycles-unrolled}} 个周期可以完成该代码段（注：其他设置和上一问相同）？
%%% part-reference: q-97ee53783d7536e8
答案：26 个周期（来源：2019、2020期末-答案解析）
解析：重排为 `movq(%rdi)→%rbx；movq 8(%rdi)→%rdx；addq %rbx,%rax；addq $16,%rdi；addq $2,%rcx；addq %rdx,%rax；cmpq $8,%rcx；jl .L2`，每轮 6 周期共 4 轮 = 24 周期，再加 2 次 miss 的惩罚 = 26 周期。
