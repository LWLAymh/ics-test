%%% stem
`iaddq V, rB` 是把 8 字节立即数 V 加到寄存器 rB 的 Y86-64 指令，其编码为 1 字节指令码、1 字节寄存器字节（rA 字段为 RNONE）以及 8 字节立即数，共 10 字节。描述实现该指令在取指、译码、执行、访存、写回以及更新 PC 阶段所执行的计算。可参考 `irmovq` 的立即数取指方式和 `OPq` 的加法执行方式。
%%% reference
| 阶段 | 计算 |
| --- | --- |
| 取指 | 从 `M1[PC]` 得到 `icode:ifun`；从 `M1[PC+1]` 得到 `rA:rB`；`valC = M8[PC+2]`；`valP = PC+10` |
| 译码 | `valB = R[rB]` |
| 执行 | `valE = valB + valC`，按加法结果设置 ZF、SF、OF |
| 访存 | 无数据内存访问 |
| 写回 | `R[rB] = valE` |
| 更新 PC | `PC = valP` |

它结合了 `irmovq` 的立即数布局与 `OPq` 的寄存器加法；不读取 rA，也不写内存。
