%%% stem
3.  在`int` 类型值为32 位、用补码表示、采用算术右移，`unsigned` 类型值也为32 位的机器上，声明

```c
int x, y;
unsigned ux = (unsigned)x;
unsigned uy = (unsigned)y;
```

则下列表达式中，当`x` 与`y` 取遍所有可能值时，可能为假的是
%%% reference
答案：A（来源：2019、2020期末-答案解析）
解析：取 `x=INT_MIN` 时 -x 溢出，故 `(x<y)==(-x>-y)` 可能为假；B、C、D 恒真。
%%% option: A
`(x<y)==(-x>-y)`
%%% option: B
`~x+~y+1==~(x+y)`
%%% option: C
`(ux-uy)==-(unsigned)(y-x)`
%%% option: D
`((x>>3)<<3)<=x`
