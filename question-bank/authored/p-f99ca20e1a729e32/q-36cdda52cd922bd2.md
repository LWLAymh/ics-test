第五题（10分）
考虑一对 `n * n` 矩阵相乘问题：`C=AB`。矩阵乘法函数通常用 3 个嵌套循环实现，分别用索引 `i`、`j` 和 `k` 标识。改变循环次序可以得到以下 6 个功能等价的版本：

1）ijk 版本

```
for (i = 0; i < n; i++) {
    for (j = 0; j < n; j++) {
        sum = 0.0;
        for (k = 0; k < n; k++)
            sum += A[i][k] * B[k][j];
        C[i][j] += sum;
    }
}
```

2）jik 版本

```
for (j = 0; j < n; j++) {
    for (i = 0; i < n; i++) {
        sum = 0.0;
        for (k = 0; k < n; k++)
            sum += A[i][k] * B[k][j];
        C[i][j] += sum;
    }
}
```

3）jki 版本

```
for (j = 0; j < n; j++) {
    for (k = 0; k < n; k++) {
        r = B[k][j];
        for (i = 0; i < n; i++)
            C[i][j] += A[i][k] * r;
    }
}
```

4）kji 版本

```
for (k = 0; k < n; k++) {
    for (j = 0; j < n; j++) {
        r = B[k][j];
        for (i = 0; i < n; i++)
            C[i][j] += A[i][k] * r;
    }
}
```

5）kij 版本

```
for (k = 0; k < n; k++) {
    for (i = 0; i < n; i++) {
        r = A[i][k];
        for (j = 0; j < n; j++)
            C[i][j] += r * B[k][j];
    }
}
```

6）ikj 版本

```
for (i = 0; i < n; i++) {
    for (k = 0; k < n; k++) {
        r = A[i][k];
        for (j = 0; j < n; j++)
            C[i][j] += r * B[k][j];
    }
}
```
本题目具有以下假设：

- 每个数组都是 `double` 类型的 `n * n` 数组，`sizeof(double) == 8`。
- 虚拟存储分页管理，页大小为 4 KB，且 `A` 的起始地址为页对齐，`A`、`B`、`C` 连续存放。
- TLB 为全相联结构。
- 初始时 TLB 为空，数据全部在硬盘中。
- 一级 dTLB 有 64 个表项，采用 LRU（Least-Recently-Used）置换策略。
- 分析过程只考虑矩阵操作本身的数据空间，且 `i`、`j`、`k`、`n`、`r`、`sum` 等变量都存放在寄存器中。
- 分析过程不考虑进程切换和异常处理程序的影响。
- 不考虑对页表本身的访问。

明确计算模型：有足够物理内存容纳三矩阵，页面首次载入后不换出；忽略写时复制等额外异常，每个矩阵数组访问都按源码执行，不进行编译器寄存器提升、循环变换或预取。C初始为0，三矩阵不重叠且有效，不讨论浮点结果差异。每个表达式按以下抽象访存流计TLB：

- ijk/jik：每个k先读A[i][k]，再读B[k][j]；完成内层循环后读写C[i][j]。
- jki/kji：进入内层i循环前读B[k][j]一次；每个i依次读A[i][k]、读写C[i][j]。
- kij/ikj：进入内层j循环前读A[i][k]一次；每个j依次读B[k][j]、读写C[i][j]。

同一C元素的相邻读写对应同一虚拟页，可合并为一次LRU触碰；这不增加额外失效。每个版本分别从空TLB和未驻留的数组页开始。原二次答案解析的n=512六个大数与该LRU/源码访问模型不符，下面参考给出分项勘误。

`n` 的取值：8、16、64、512；请填写缺页次数和一级 dTLB 失效次数：

| `n` | 缺页次数 | 1-ijk | 2-jik | 3-jki | 4-kji | 5-kij | 6-ikj |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 8 | {{blank:b8-r1-c1}} | {{blank:b8-r1-c2}} | {{blank:b8-r1-c3}} | {{blank:b8-r1-c4}} | {{blank:b8-r1-c5}} | {{blank:b8-r1-c6}} | {{blank:b8-r1-c7}} |
| 16 | {{blank:b16-r2-c1}} | {{blank:b16-r2-c2}} | {{blank:b16-r2-c3}} | {{blank:b16-r2-c4}} | {{blank:b16-r2-c5}} | {{blank:b16-r2-c6}} | {{blank:b16-r2-c7}} |
| 64 | {{blank:b64-r3-c1}} | {{blank:b64-r3-c2}} | {{blank:b64-r3-c3}} | {{blank:b64-r3-c4}} | {{blank:b64-r3-c5}} | {{blank:b64-r3-c6}} | {{blank:b64-r3-c7}} |
| 512 | {{blank:b512-r4-c1}} | {{blank:b512-r4-c2}} | {{blank:b512-r4-c3}} | {{blank:b512-r4-c4}} | {{blank:b512-r4-c5}} | {{blank:b512-r4-c6}} | {{blank:b512-r4-c7}} |

答案：缺页次数依次为 1、2、24、1536；dTLB 失效次数见下表。
| `n` | 缺页次数 | dTLB 失效次数 1-ijk | 2-jik | 3-jki | 4-kji | 5-kij | 6-ikj |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 8 | 1 | 1 | 1 | 1 | 1 | 1 | 1 |
| 16 | 2 | 2 | 2 | 2 | 2 | 2 | 2 |
| 64 | 24 | 24 | 24 | 24 | 24 | 24 | 24 |
| 512 | 1536 | 134480384 | 134742016 | 268697600 | 268697600 | 524800 | 263168 |
解析：缺页次数只与矩阵占用的页数有关，为 ceil(3n²×8/2¹²)，即 1、2、24、1536；TLB 失效次数等价于一个「块 4KB、64 行、全相联」高速缓存的 miss 次数，前三行因为 TLB 未满而恰好等于页面数。
当n=512，每个矩阵恰占512页，每页恰好一整行；64项TLB无法同时容纳512个行页。令n=512，各版本分项如下：

| 版本 | A失效 | B失效 | C失效 | 合计 |
| --- | --- | --- | --- | --- |
| ijk | n | n³ | n² | 134480384 |
| jik | n² | n³ | n² | 134742016 |
| jki/kji | n³ | n² | n³ | 268697600 |
| kij | n² | n | n² | 524800 |
| ikj | n | n² | n | 263168 |

ijk每轮k不断复用同一A行，B跨512行每次失效，C每个j结束时才访问、下轮k遍历会驱逐它。jik还使A行随每个i变化。jki/kji内层i同时跨A/C行，两者逐次失效，B每次外层组合才读一次。kij在固定k下B行始终热驻；ikj固定i下A/C行始终热驻。

原二次解析给出的六值依次为266436157、268661500、252182591、252182591、235241284、521528；保留此出处备查，不沿用不符合明确模型的数值。新值由逐次页访问的全相联LRU模拟和上述闭式分别核对；验证源码保存在 `question-bank/backups/2020-final-tlb-validation.cpp`，仅验证数值，不用于生成或改写题面。
