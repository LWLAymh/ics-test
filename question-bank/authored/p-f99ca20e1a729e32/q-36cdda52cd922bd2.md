第五题（10分）
考虑一对 n*n 矩阵相乘问题：`C=AB`。矩阵乘法函数通常用 3 个嵌套循环实现，分别用索引 `i`、`j` 和 `k` 标识。改变循环次序可以得到以下 6 个功能等价的版本：

1）ijk 版本

```
for (i = 0; i < n; i++) {
    for (j = 0; j < n; j++) {
        sum = 0.0;
        for (k = 0; k < n; k++)
            sum += A[i][k] * B[k][j];
        C[i][j] += sum;
    }
}
```

2）jik 版本

```
for (j = 0; j < n; j++) {
    for (i = 0; i < n; i++) {
        sum = 0.0;
        for (k = 0; k < n; k++)
            sum += A[i][k] * B[k][j];
        C[i][j] += sum;
    }
}
```

3）jki 版本

```
for (j = 0; j < n; j++) {
    for (k = 0; k < n; k++) {
        r = B[k][j];
        for (i = 0; i < n; i++)
            C[i][j] += A[i][k] * r;
    }
}
```

4）kji 版本

```
for (k = 0; k < n; k++) {
    for (j = 0; j < n; j++) {
        r = B[k][j];
        for (i = 0; i < n; i++)
            C[i][j] += A[i][k] * r;
    }
}
```

5）kij 版本

```
for (k = 0; k < n; k++) {
    for (i = 0; i < n; i++) {
        r = A[i][k];
        for (j = 0; j < n; j++)
            C[i][j] += r * B[k][j];
    }
}
```

6）ikj 版本

```
for (i = 0; i < n; i++) {
    for (k = 0; k < n; k++) {
        r = A[i][k];
        for (j = 0; j < n; j++)
            C[i][j] += r * B[k][j];
    }
}
```
本题目具有以下假设：
  每个数组都是一个`double`类型的n*n的数组，`sizeof(double)==8`
  虚拟存储分页管理，页大小为4K字节，且A的起始地址为页对齐，ABC连续存放
  TLB为全相联结构
  初始时TLB为空，数据全部在硬盘中
  一级dTLB有64表项，采用LRU（Least-Recently-Used）置换策略
  分析过程只考虑矩阵操作本身的数据空间，且i/j/k/n/r/sum等变量都存放在寄存器中
  分析过程不考虑进程切换和异常处理程序的影响
  不考虑对页表本身的访问
`n` 的取值：8、16、64、512；请填写缺页次数和一级 dTLB 失效次数：

| `n` | 缺页次数 | 1-ijk | 2-jik | 3-jki | 4-kji | 5-kij | 6-ikj |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 8 | {{blank:b8-r1-c1}} | {{blank:b8-r1-c2}} | {{blank:b8-r1-c3}} | {{blank:b8-r1-c4}} | {{blank:b8-r1-c5}} | {{blank:b8-r1-c6}} | {{blank:b8-r1-c7}} |
| 16 | {{blank:b16-r2-c1}} | {{blank:b16-r2-c2}} | {{blank:b16-r2-c3}} | {{blank:b16-r2-c4}} | {{blank:b16-r2-c5}} | {{blank:b16-r2-c6}} | {{blank:b16-r2-c7}} |
| 64 | {{blank:b64-r3-c1}} | {{blank:b64-r3-c2}} | {{blank:b64-r3-c3}} | {{blank:b64-r3-c4}} | {{blank:b64-r3-c5}} | {{blank:b64-r3-c6}} | {{blank:b64-r3-c7}} |
| 512 | {{blank:b512-r4-c1}} | {{blank:b512-r4-c2}} | {{blank:b512-r4-c3}} | {{blank:b512-r4-c4}} | {{blank:b512-r4-c5}} | {{blank:b512-r4-c6}} | {{blank:b512-r4-c7}} |
%%% reference
答案：缺页次数依次为 1、2、24、1536；dTLB 失效次数见下表。
| `n` | 缺页次数 | dTLB 失效次数 1-ijk | 2-jik | 3-jki | 4-kji | 5-kij | 6-ikj |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 8 | 1 | 1 | 1 | 1 | 1 | 1 | 1 |
| 16 | 2 | 2 | 2 | 2 | 2 | 2 | 2 |
| 64 | 24 | 24 | 24 | 24 | 24 | 24 | 24 |
| 512 | 1536 | 266436157 | 268661500 | 252182591 | 252182591 | 235241284 | 521528 |
解析：缺页次数只与矩阵占用的页数有关，为 ceil(3n²×8/2¹²)，即 1、2、24、1536；TLB 失效次数等价于一个「块 4KB、64 行、全相联」高速缓存的 miss 次数，前三行因为 TLB 未满而恰好等于页面数。
（来源：2019、2020期末-答案解析）
