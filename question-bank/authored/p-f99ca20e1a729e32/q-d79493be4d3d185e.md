%%% stem
24.  以下程序在输出有限行之后就终止了，请问最有可能的原因是（假定所有函数都正常执
行）
```
#include "csapp.h"
void *thread(void *dummy){
    while (1){
        printf("hello, world!\n");
        Sleep(1);
    }
}
int main(){
    pthread_t tid;
    Pthread_create(&tid, NULL, thread, NULL);
    Sleep(3);
}
```
%%% reference
答案：B（来源：2019、2020期末-答案解析）
解析：`main` 返回会结束整个进程，对等线程随之终止；A 错（pthread_exit 才只结束本线程），C、D 描述的内核行为并不存在。原卷选项 B 写作“调用 _exit”，但 `main` 返回通常等效于调用 exit；选项措辞与机制不完全对应，答案暂按所引参考答案保留。
%%% option: A
主线程结束必然引发所有对等线程结束
%%% option: B
主线程结束时调用了_exit导致进程结束
%%% option: C
主线程结束后，内核发送SIGKILL杀死进程
%%% option: D
主线程结束后，内核观察到对等线程运行时间过长，将其杀死
