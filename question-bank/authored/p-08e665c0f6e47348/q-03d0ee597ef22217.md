%%% stem
17. 按课程介绍的常见动态网页访问方式，哪些 HTTP 方法分别用于获取页面，或提交表单数据以获得动态响应正文？（多选；不讨论将资源写入方法额外扩展为网页查询接口。）
%%% reference
答案：B、C。GET 可获取动态生成的页面；POST 常用于提交表单数据并获得动态响应。HEAD 不返回响应正文，PUT 的主要语义是创建或替换目标资源。本题限定常见页面/表单用途，不能推广为任何服务端实现下只有 GET/POST 才能执行动态代码。
%%% option: A
HEAD
%%% option: B
GET
%%% option: C
POST
%%% option: D
PUT
