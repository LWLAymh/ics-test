第四题（10分）链接
在x86_64环境下，考虑如下2个文件：`main.c`和`foo.c`：
按课程 ELF 小端机器级模型分析，`int` 为 4 字节、`long long` 为 8 字节；编译使用 `-fcommon`、不使用 LTO 或跨文件类型优化，允许 x86 非对齐访问。以下程序故意让两个文件对 `a` 使用不一致类型，用来观察传统链接和字节覆盖现象，不把它作为可移植 C 程序范例。命令行参数有效。

```c
/* main.c */
#include <stdio.h>
long long /*（A）*/;
const char* foo(int);
int main(int argc, char **argv){
  int n = 0;
  sscanf(argv[1], "%d", &n);
  printf(foo(n));
  printf("%llx\n", a);
}
/* foo.c */
#include <stdio.h>
int a[2];
static void swapper(int num){
  int swapper;
  if (num % 2){
    swapper = a[0];
    a[0] = a[1];
    a[1] = swapper;
  }
}
const char* foo(int num){
  static char out_buf[50];
  swapper(num);
  sprintf(out_buf, "%x\n", /*（B）*/);
  return out_buf;
}
```
