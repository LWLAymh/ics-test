第五题（10分）异常
以下程序运行时所有 `fork` 等调用成功，`waitpid` 只在没有子进程可等待时返回 -1，每个发送的 SIGUSR1 都被对应父进程处理。按字符输出立即可见的教学模型分析，不讨论 `printf` 的异步信号安全与缓冲问题。请给出父、子、孙进程全部退出后所有可能的字符输出。

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <signal.h>
#include <sys/wait.h>
int c = 1;
void handler1(int sig) {
  c++;
  printf("%d", c);
}
int main() {
  signal(SIGUSR1, handler1);
  sigset_t s;
  sigemptyset(&s);
  sigaddset(&s, SIGUSR1);
  sigprocmask(SIG_BLOCK, &s, 0);
  int pid = fork() ? fork() : fork();
  if (pid == 0) {
    kill(getppid(), SIGUSR1);
    printf("S");
    sigprocmask(SIG_UNBLOCK, &s, 0);
    exit(0);
  } else {
    while (waitpid(-1, NULL, 0) != -1);
    sigprocmask(SIG_UNBLOCK, &s, 0);
    printf("P");
  }
  return 0;
}
```
答：
%%% reference
答案：共 3 种：
```text
S2PS2P
SS2P2P
S2SP2P
```

把最初进程记为 R，它第一次 fork 的孩子记为 A。R 的第二次 fork 创建 B，A 的 fork 创建 C。只有 B、C 进入 `pid == 0` 分支，各输出 S；A 先等待 C 完成，随后处理信号输出 2，再输出 P；R 等待 A、B 都完成后，才处理信号并输出最后的 2P。

所以最后一个 2 必在 A 的 P 之后；B 的 S 可以插在 C 的 S 之前、A 的 2 之前、2 与 P 之间或 P 之后，去重后恰为以上三个字符串。

原卷列出的 `S2S2PP`、`SS22PP` 违反 R 必须先等 A 退出的约束，予以勘误。本题仍要求分析全部输出并保留简答自评。
