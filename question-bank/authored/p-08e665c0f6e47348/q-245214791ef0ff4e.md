%%% stem
11. 下面是一段 C 程序代码。假设 `stdout` 采用缓冲输出，`printf` 在本题没有换行，不会在显式 `fflush` 前自动刷新；`Write` 一次完整写出，所有调用成功。下列哪个输出是可能的？
```c
#include <stdio.h>
#include "csapp.h"
int main()
{
  printf("2");
  if (Fork())
  {
    printf("33");
    Write(STDOUT_FILENO, "lol", 3);
  }
  else
  {
    Sleep(1);
    printf("233");
    Write(STDOUT_FILENO, "hhhh", 4);
  }
  fflush(stdout);
  return 0;
}
```
统计父、子进程都正常退出后的输出。
%%% reference
答案：B。
`fork` 复制尚未刷新的 `2`。若父进程先完成，它先直接写出 `lol`，再刷新 `233`；子进程随后写出 `hhhh`，再刷新 `2233`，得到 B。`Sleep(1)` 不保证特定调度顺序，所以本题问“可能”，不把 B 当成唯一运行轨迹。换行只会在行缓冲模式触发刷新，并非所有缓冲模式都如此。
%%% option: A
233lol233hhhh
%%% option: B
lol233hhhh2233
%%% option: C
233lol2233hhhh
%%% option: D
2lol33hhhh233
