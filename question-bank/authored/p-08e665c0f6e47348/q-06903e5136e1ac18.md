第八题（10 分）并发

三个线程 PA、PB、PC 协作完成文件打印：

- PA 每次从磁盘读入一条记录，放入内存缓冲区 `Buff1`。
- PB 每次从 `Buff1` 取出一条记录，复制到 `Buff2`。
- PC 每次从 `Buff2` 取出一条记录并打印。
- `Buff1` 可容纳 4 条记录，`Buff2` 可容纳 8 条记录，初始均为空。

请用信号量及 P、V 操作实现同步，保证文件正确打印。

```text
PA() {
    while (1) {
        /* ① */
        从磁盘读入一条记录
        /* ② */
        将记录放入 Buff1
        /* ③ */
    }
}

PB() {
    while (1) {
        /* ④ */
        从 Buff1 中取出一条记录
        /* ⑤ */
        将记录放入 Buff2
        /* ⑥ */
    }
}

PC() {
    while (1) {
        /* ⑦ */
        从 Buff2 中取出一条记录
        /* ⑧ */
        打印
    }
}
```

1. 设计所需信号量，说明各自的作用和初值。
2. 给出 ①～⑧ 处的 P、V 操作。每处可填写一条或多条语句；不需要操作时记为 `X`。

信号量可以自由命名，同步方案也不唯一。本题对照参考解自评，不按固定变量名自动判错。取出的记录可保存在对应线程的局部变量中。
%%% reference
下面是一种正确方案，不要求使用相同的信号量名称。

| 信号量 | 作用 | 初值 |
| --- | --- | --- |
| `empty1` | `Buff1` 空闲位置数 | `4` |
| `full1` | `Buff1` 可取出的记录数 | `0` |
| `empty2` | `Buff2` 空闲位置数 | `8` |
| `full2` | `Buff2` 可取出的记录数 | `0` |
| `mutex1` | 互斥访问 `Buff1` | `1` |
| `mutex2` | 互斥访问 `Buff2` | `1` |

| 标号 | 对应操作 |
| --- | --- |
| ① | `X` |
| ② | `P(&empty1); P(&mutex1);` |
| ③ | `V(&mutex1); V(&full1);` |
| ④ | `P(&full1); P(&mutex1);` |
| ⑤ | `V(&mutex1); V(&empty1); P(&empty2); P(&mutex2);` |
| ⑥ | `V(&mutex2); V(&full2);` |
| ⑦ | `P(&full2); P(&mutex2);` |
| ⑧ | `V(&mutex2); V(&empty2);` |

PB 取出记录并存入自己的局部变量后，先释放 `Buff1` 的锁和空位，再等待 `Buff2` 的空位；PC 同理，取出后即可释放 `Buff2`，打印不需要占着缓冲区锁。等待空位或记录应在获取相应互斥锁之前，避免占锁等待对方推进。

自评时检查：初始容量正确、空时不取、满时不放、每次 P/V 配对，且没有丢失记录、重复打印或死锁。等价方案应认可。

校订说明：题源原参考将 `mutex2` 初值写为 `2`，且 PB 取出 `Buff1` 记录后漏写释放 `mutex1` 和归还 `empty1` 的操作。本参考解修正这两处，不沿用原来的字面答案。
