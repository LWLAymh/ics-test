Part B：分析下列利用信号处理函数输出数列的程序。

```c
#include "csapp.h"
#define N 10

int flag = 0;

void handler1() {
    for (int i = 0; i < N; i += 2) {
        printf("%d ", i);
        fflush(stdout);
    }
    flag++;
}

void handler2() {
    for (int i = 1; i < N; i += 2) {
        printf("%d ", i);
        fflush(stdout);
    }
    flag++;
}

int main() {
    pid_t pid = fork();
    if (pid == 0) {
        signal(SIGUSR1, handler1);
        signal(SIGUSR2, handler2);
        while (flag < 2)
            sleep(1);
    } else {
        kill(pid, SIGUSR1);
        kill(pid, SIGUSR2);
        wait(NULL);
    }
    return 0;
}
```

1. 运行后发现程序没有输出，且陷入死循环。请简要指出原因，并给出解决方案。（2分）
%%% part-reference: q-1aa9bebc1b718737
参考要点：

- `flag` 会被异步信号处理函数修改，应声明为 `volatile sig_atomic_t flag = 0;`，避免主流程反复读取到编译器缓存的旧值。
- 还应避免父进程在子进程安装处理函数前发送信号；可在 `fork` 前阻塞 `SIGUSR1`、`SIGUSR2`，子进程安装好处理函数后再解除阻塞，或使用可靠的父子同步机制。

请根据是否指出关键原因并给出可行的同步/可见性修复自评。
%%% part-stem: q-5d199a2b3087a536
2. 解决上一问的问题后，一次运行得到 `1 3 5 7 9 0 2 4 6 8`，另一次却得到 `1 3 0 2 4 6 8 5 7 9`。请补全 `handler1`，使其在执行期间阻塞其他信号，并在返回前恢复原信号掩码。（3分）

```c
void handler1() {
    sigset_t mask, prev_mask;
    {{blank:A}}({{blank:B}});
    {{blank:C}}({{blank:D}}, &mask, &prev_mask);
    for (int i = 0; i < N; i += 2) {
        printf("%d ", i);
        fflush(stdout);
    }
    flag++;
    {{blank:E}}({{blank:F}}, &prev_mask, NULL);
}
```

请从下列选项中选择名称或序号填写：

1. `Sigfillset`
2. `Sigprocmask`
3. `Sigemptyset`
4. `SIG_BLOCK`
5. `SIG_UNBLOCK`
6. `SIG_SETMASK`
7. `&mask`
8. `&prev_mask`
9. `NULL`
%%% part-reference: q-5d199a2b3087a536
答案：A=1（`Sigfillset`），B=7（`&mask`），C=2（`Sigprocmask`），D=4（`SIG_BLOCK`），E=2（`Sigprocmask`），F=6（`SIG_SETMASK`）。

恢复信号掩码时，完整调用为 `Sigprocmask(SIG_SETMASK, &prev_mask, NULL)`。
