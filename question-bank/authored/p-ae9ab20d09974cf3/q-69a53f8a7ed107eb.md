### Part B：动态内存分配（9分）

小明实现了一个简单的动态内存分配器：仅使用无脚部的隐式空闲链表，不使用额外数据结构；内存块按 8 字节对齐，块大小采用小端法存储，分配采用首次适配，堆空间足够大。

图1的布局改用偏移表表示。头部占 4 B：A 标记头部起点处的低位字节，B 标记头部位字段中 bit 3 与 bit 2 的分界（不是地址位置）；C 是头部之后的载荷起点，D 是载荷后的边界。

| 相对块起点的偏移 | 内容 | 图中标记 |
| ---: | --- | --- |
| 0 | 头部起点；大小/分配字最低地址字节 | A |
| 0–3 | 4 B 头部（最高地址处为偏移 3） | B 标记 bit 3/bit 2 分界 |
| 4 | 有效载荷起点 | C |
| 4 + 申请字节数 | 有效载荷结束、可选填充开始的边界（不一定是块末尾） | D |

头部 bit 31–3 保存块大小，bit 2–1 为 0，bit 0 为分配位 `a`（1 表示已分配，0 表示空闲）。块总长度包含头部、载荷及填充；图2还包含脚部。

图2的布局为：

| 顺序（低地址到高地址） | 内容 |
| --- | --- |
| 1 | 4 B 头部：块大小与分配位 |
| 2 | 有效载荷 |
| 3 | 可选填充 |
| 4 | 4 B 脚部：与头部相同的块大小与分配位 |

#### 1）

初始堆为空，执行 `void *p = malloc(5);` 后，`p` 实际指向图1中的 {{blank:pointer-position}}。此时 A 处 1 个字节的内容为 {{blank:header-byte}}（十六进制，如 `0xFF`）。（每空 1 分）

#### 2）

若某次合并前堆中有 n 个独立内存块，该合并过程的时间复杂度至少为 {{blank:deferred-combine}}。（1 分）

| 选项 | 复杂度 |
| --- | --- |
| A | O(1) |
| B | O(log n) |
| C | O(n) |
| D | O(n²) |

#### 3）

若每个块末尾均添加脚部，并改用立即合并，释放一个已分配块后堆中有 n 个独立内存块，此时合并操作的时间复杂度至少为 {{blank:immediate-combine}}。此时调用 `malloc` 时，单块内存利用率最低为 {{blank:utilization}}（最简分数；利用率 = 申请块大小 / 实际分配块大小）。（每空 1 分）

| 选项 | 复杂度 |
| --- | --- |
| A | O(1) |
| B | O(log n) |
| C | O(n) |
| D | O(n²) |

#### 4）

为提高利用率，小明只给空闲块添加脚部，不给已分配块添加脚部。此时释放已分配块时，{{blank:footer-space}} 有足够空间存放脚部。（1 分）

| 选项 | 判断 |
| --- | --- |
| A | 一定 |
| B | 不一定 |

#### 5）

改进后的合并算法：释放一个内存块时，取出该块头部之前 4 B 的数据；若最低位为 0，则从这些数据的其余位读出块大小，并据此找到候选块头。若找到的头部与取出的 4 B 完全相同，就合并该块。

原题写作 `calloc(28)`，但标准 C 的 `calloc` 需要两个参数；这里改为 `calloc(1, 28)`（32 B 分配同理），保留分配并清零指定字节数的原意。下面代码用于构造错误合并情形。


```c
#include <stdlib.h>
int main() {
    void *p1 = calloc(1, 28);
    void *p2 = calloc(1, 32);
    *((char *)p1 + 24) = 0x10;
    *((char *)p1 + {{blank:attack-write-offset}}) = {{blank:attack-write-value}};
    free(p2);
}
```

执行完 `free(p2)` 后，分配器会错误地认为从 `((char *)p1 + {{blank:false-free-offset}})` 开始的堆内存都是空闲的。（3 分：前两空都正确得 1 分，最后一空得 2 分）

1）C；`0x11`。申请 5 B 载荷，加 4 B 头部后按 8 B 对齐，块总长为 16 B，头部大小/分配字为 `0x11`，小端存储后 A 字节为 `0x11`，载荷从偏移 4 开始。

2）C（`O(n)`）。推迟合并需扫描堆中的空闲块以找到可合并块。

3）A（`O(1)`）；`1/16`。脚部使释放块可在常数时间定位相邻块；最小块总长为 16 B，最小非零申请为 1 B。

4）A（一定）。释放前的载荷空间足以写入脚部。

5）① `12`；② `0x10`（或 `16`）。伪造块头位于相对 `p1` 偏移 12 的位置；其大小为 16 B，故错误合并范围从偏移 12 起。若末空按题面所指的错误块头起点填写 `12`；按错误块中载荷起点填写 `16`，与原答案注明的等价填法一致。
