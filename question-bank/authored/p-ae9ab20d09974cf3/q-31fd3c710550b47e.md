%%% stem
1. 假想一类“半字节数”（4-bit）的数据类型，包括有符号整数（`int4`）以及浮点数（`float4`）。`int4` 采用补码表示；`float4` 基于 IEEE 浮点格式，有 1 个符号位、2 个阶码位（`k = 2`）和 1 个小数位（`n = 1`）。

有两种函数 `f2b(f)` 和 `f2i(f)`，代码实现如下：

```c
int4 f2b(float4 f) {
  union {
    int4 d;
    float4 f;
  } temp;
  temp.f = f;
  return temp.d;
}

int4 f2i(float4 f) {
  return (int4) f;
}
```

`f2b` 函数返回 `f` 的二进制表示按 `int4` 解读的值。例如，`f` 的二进制表示为 `0100` 时返回 4。`f2i` 函数返回 `f` 的值向零舍入的结果。

执行下面的伪代码，从 `0000` 到 `1111` 枚举所有 `float4` 位模式，跳过 NaN 及正负无穷，并进行比较：

```c
void fun() {
  for (float4 f from 4'b0000 to 4'b1111) {
    if (isnan(f) || isinf(f)) continue;
    if (f2b(f) == f2i(f)) printf("Success!\n");
  }
}
```
请问 `f2b` 和 `f2i` 相等时，`f` 的二进制表示是：

① `0000`　② `0001`　③ `1000`　④ `1101`
%%% reference
答案：D（①④）。

阶码偏置为 $2^{k-1}-1 = 1$。下表中 `dif = f2b(f) - f2i(f)`；只有 `0000` 和 `1101` 两行的差为 0。

| 二进制表示 | `f` | `f2b(f)` | `f2i(f)` | `dif` |
| --- | --- | --- | --- | --- |
| `0000` | 0 | 0 | 0 | 0 |
| `0001` | 1/2 | 1 | 0 | 1 |
| `0010` | 1 | 2 | 1 | 1 |
| `0011` | 3/2 | 3 | 1 | 2 |
| `0100` | 2 | 4 | 2 | 2 |
| `0101` | 3 | 5 | 3 | 2 |
| `0110` | +∞ | — | — | — |
| `0111` | NaN | — | — | — |
| `1000` | −0 | −8 | 0 | −8 |
| `1001` | −1/2 | −7 | 0 | −7 |
| `1010` | −1 | −6 | −1 | −5 |
| `1011` | −3/2 | −5 | −1 | −4 |
| `1100` | −2 | −4 | −2 | −2 |
| `1101` | −3 | −3 | −3 | 0 |
| `1110` | −∞ | — | — | — |
| `1111` | NaN | — | — | — |

维护说明：原参考表将全 1 阶码下的小数字段 0/1 对应的无穷和 NaN 写反，此处按 IEEE 格式更正；不影响答案 D。
