第五题（10分）
代码如下：（仅为示例代码，答题时不考虑任何出错的情况）
```
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <fcntl.h>
#include <sys/types.h>
#include <sys/wait.h>
int counter1 = 1;
int counter2 = 1;
void handler(int sig) {
    if (sig == SIGUSR1) counter1++;
    if (sig == SIGUSR2) counter2++;
}
int main(int argc, char **argv) {
    int i;
    pid_t ppid, cpid;
    int fd1, fd2;
    unsigned char buf1[64], buf2[64];
    signal(SIGUSR1, handler);
    signal(SIGUSR2, handler);
    fd1 = open("number.txt", O_RDWR);
    for (i = 0; i < N; i++) {
        ppid = getpid();
        cpid = fork();
        if (cpid) {
            kill(cpid, A);
            while (sleep(4)) ;
        } else {
            kill(ppid, B);
            while (sleep(2)) ;
        }
        fd2 = open("letter.txt", O_RDWR);
        read(fd1, buf1, counter1);
        read(fd2, buf2, counter2);
        buf1[counter1] = '\0';
        buf2[counter2] = '\0';
        printf("%s %s\n", buf1, buf2);
        if (cpid) {
            waitpid(cpid, 0, 0);
        } else {
            E;
        }
    }
}
```
其中，`number.txt`文件内容为：
123456789012345678901234567890
其中，`letter.txt`文件内容为：
abcdefghijklmnopqrstuvwxyz

a) A 为 `SIGUSR1`、B 为 `SIGUSR1` 时，最后一行输出为 {{blank:n2-aa}}
b) A 为 `SIGUSR1`、B 为 `SIGUSR2` 时，最后一行输出为 {{blank:n2-ab}}
c) A 为 `SIGUSR2`、B 为 `SIGUSR1` 时，最后一行输出为 {{blank:n2-ba}}
d) A 为 `SIGUSR2`、B 为 `SIGUSR2` 时，最后一行输出为 {{blank:n2-bb}}
2. 当 `N=3` 时，A/B 为 `SIGUSR1` 或 `SIGUSR2`，E 为 exit(0) 时，共有 {{blank:n3-lines}} 行输出。
a) A 为 `SIGUSR1`、B 为 `SIGUSR1` 时，最后一行输出为 {{blank:n3-aa}}
b) A 为 `SIGUSR1`、B 为 `SIGUSR2` 时，最后一行输出为 {{blank:n3-ab}}
c) A 为 `SIGUSR2`、B 为 `SIGUSR1` 时，最后一行输出为 {{blank:n3-ba}}
d) A 为 `SIGUSR2`、B 为 `SIGUSR2` 时，最后一行输出为 {{blank:n3-bb}}

答案：
1. 程序不终止，输出行数无穷多，因此不存在“最后一行”。A/B 的信号类型不改变这一点。
2. 共 6 行（父进程每轮输出一行，子进程每轮输出一行后由 `exit(0)` 结束）。最后一行不能由题面唯一确定：父进程在 `waitpid` 之前先打印；父子进程也共享 `fd1` 的打开文件描述及文件偏移，读取先后受调度影响。

解析：`handler` 只递增本进程的 `counter1` 或 `counter2`，没有再次调用 `kill`。`A` 是父进程发给子进程的信号，`B` 是子进程发给父进程的信号。第一问中 `E` 为空，子进程不会退出；它继续执行循环，并在每次循环再次 `fork`，因此进程树不断扩展，题目要求的有限行数和最后一行都不存在。第二问中子进程执行 `exit(0)` 后每轮只留下父、子各一行，但 `waitpid` 位于父进程打印之后，且 `fd1` 的偏移由共享描述符上的读操作共同推进，无法保证一个唯一的末行内容。
