第五题（10分）

代码如下（示例代码，不考虑任何调用出错的情况）。本题补充以下教学模型：

- 每个可运行进程最终都能继续运行；所有调用成功，`read` 读满请求的字节数，`waitpid` 确实等待指定子进程结束。
- 每轮父子互发的用户信号恰好各处理一次，且各自在本轮第一次 `read` 前处理完。处理函数对本进程计数器的递增视为有效的抽象操作，不讨论严格C中异步访问普通 `int` 的问题。
- 每次 `printf` 完整输出并立即刷新一行，之后的 `fork` 不复制尚未刷新的输出。共享文件偏移的每次 `read` 视为不可分割的操作。
- 除程序顺序、信号发送/处理及 `waitpid` 的因果约束外，允许在语句间任意调度，尤其允许在 `read` 与 `printf` 之间暂停。`sleep(2)` 不保证子进程先于 `sleep(4)` 的父进程读取或打印；若 `sleep` 被信号打断，仍按代码重新调用相同的时长。

原卷没有这些完整约定，不能将某次运行的末行当作唯一答案。以下末行小问均为多选，要求选出该模型下所有可能的完整行。

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <fcntl.h>
#include <sys/types.h>
#include <sys/wait.h>
#include <signal.h>
int counter1 = 1;
int counter2 = 1;
void handler(int sig) {
    if (sig == SIGUSR1) counter1++;
    if (sig == SIGUSR2) counter2++;
}
int main(int argc, char **argv) {
    int i;
    pid_t ppid, cpid;
    int fd1, fd2;
    unsigned char buf1[64], buf2[64];
    signal(SIGUSR1, handler);
    signal(SIGUSR2, handler);
    fd1 = open("number.txt", O_RDWR);
    for (i = 0; i < N; i++) {
        ppid = getpid();
        cpid = fork();
        if (cpid) {
            kill(cpid, A);
            while (sleep(4)) ;
        } else {
            kill(ppid, B);
            while (sleep(2)) ;
        }
        fd2 = open("letter.txt", O_RDWR);
        read(fd1, buf1, counter1);
        read(fd2, buf2, counter2);
        buf1[counter1] = '\0';
        buf2[counter2] = '\0';
        printf("%s %s\n", buf1, buf2);
        if (cpid) {
            waitpid(cpid, 0, 0);
        } else {
            E;
        }
    }
}
```

`number.txt` 的内容为：

```text
123456789012345678901234567890
```

`letter.txt` 的内容为：

```text
abcdefghijklmnopqrstuvwxyz
```

两问均有 **6行**输出。各末行集合如下；每个反引号中的内容是一整行，数字与字母间有一个空格。

| 小问 | N=2，E为空 | N=3，E为exit(0) |
| --- | --- | --- |
| a，A=USR1、B=USR1 | `123 a`、`456 a` | `1234 a`、`5678 a` |
| b，A=USR1、B=USR2 | `9 abc`、`1 abc`、`90 ab`、`01 ab` | `7 abcd`、`9 abcd`、`78 abc`、`89 abc` |
| c，A=USR2、B=USR1 | `789 a`、`901 a`、`78 ab`、`01 ab` | `9012 a`、`2345 a`、`901 ab`、`345 ab` |
| d，A=USR2、B=USR2 | `5 abc`、`6 abc` | `5 abcd`、`6 abcd` |

**有限进程树。** 第一问从原进程P开始：i=0时P创建C，P和C各打印一次；C执行空的E后把自己的i加到1，再创建D，C/D各打印一次，随后都因i达到2退出。P等待C结束后才进入i=1，创建F，P/F各打印一次，然后退出。总计2+2+2=6行、4个进程、3次fork。`fork` 复制i，不把它重置为0，因此不是无限循环。第二问每个新子进程打印后立即exit，P连续执行3轮，每轮2行，也是6行、4个进程、3次fork。

**计数器与文件偏移。** 令向量u=(1,1)，a表示信号A递增的单位向量，b表示信号B递增的单位向量。A发给子进程，B发给父进程；子进程继承fork时已有的计数器。第一问六次输出的计数器向量分别为：P第0轮u+b，C第0轮u+a，C第1轮u+a+b，D为u+2a，P第1轮u+2b，F为u+a+b。所有进程共享在循环前打开的fd1及其文件偏移；每次重新open得到的fd2则从字母a开始，故字母串只由本次counter2决定。

**缩减到最后一对父子。** 第一问中P开始第1轮前，C及D均已退出，P的第0轮也已经打印。故末行只能来自P第1轮或F；它们的计数器分别为u+2b、u+a+b。设a1、b1是a、b的第一分量，在最后一对读之前fd1偏移为4+4a1+2b1。第二问中每轮末P等待本轮子进程退出，末行只能来自第2轮P或新子进程；两者计数器分别为u+3b、u+2b+a，之前fd1偏移为4+2a1+4b1。这些偏移与前面各次读取的顺序无关，因为累计读取长度固定，且没有读至文件末尾。

**穷尽末行。** 对最后一对父子，先读的取得从上述偏移开始的一段数字，后读的取得紧随其后的一段。数字读取和打印是不同语句，所以即使某进程先读，也可以延后到另一进程打印后才打印。分别考虑“父先读/子先读”及“父最后打印/子最后打印”，恰得表中的全部集合；相同长度/字母串时重复内容合并。所有组合均可通过在两次read/printf之间暂停对应进程实现，休眠时间不形成额外先后关系。

例如第一问b：最后一对读取前偏移为8，P的计数器是(1,3)，F是(2,2)。P先读时得到 `9 abc`，F得到 `01 ab`；F先读时得到 `90 ab`，P得到 `1 abc`。在两种读取顺序下均可选择哪个进程最后打印，所以四行全可达。第一问c的P计数器为(3,1)，F为(2,2)，不能误把P的字母串写成ab，或把F写成abc。

不能只把“最后读到的字符串”当作最后一行，也不能用2秒/4秒休眠推导固定父子顺序。上述集合只适用于题面明确的教学模型；若允许本轮信号延迟到读取之后、输出全缓冲后再fork等，需重新分析。`sleep` 自身不是信号处理完成或父子执行顺序的同步屏障。
