第八题（12分）第2问：已声明三个信号量 s1、s2、s3，初值分别为 1、0、0。请将对应的 P() 和 V() 操作填入标号处（每空至多填写 1 个操作），要求三个线程并发执行的结果只能是 `x = 10`。
```c
x = 1;
void thread1(void) {
    {{blank:slot-1}}
    x = x * 5;
    {{blank:slot-2}}
}
void thread2(void) {
    {{blank:slot-3}}
    x = x + 3;
    {{blank:slot-4}}
}
void thread3(void) {
    {{blank:slot-5}}
    x = x / 2;
    {{blank:slot-6}}
}
```
%%% reference
答案：① P(&s2)，② V(&s3)，③ P(&s1)，④ V(&s2)，⑤ P(&s3)，⑥ 空。

执行顺序必须为线程 2 → 线程 1 → 线程 3：`1 + 3 = 4`，`4 × 5 = 20`，`20 ÷ 2 = 10`。线程 2 的 P(&s1) 由初值 1 放行，随后 V(&s2) 放行线程 1，最后 V(&s3) 放行线程 3。
