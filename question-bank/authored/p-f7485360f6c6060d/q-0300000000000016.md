%%% stem
练习题 3.16 已知下列 C 代码：

```c
void cond(long a, long *p)
{
    if (p && a > *p)
        *p = a;
}
```

GCC 会产生下面的汇编代码：

```text
void cond(long a, long *p)
a in %rdi, p in %rsi

cond:
    testq %rsi, %rsi
    je    .L1
    cmpq  %rdi, (%rsi)
    jge   .L1
    movq  %rdi, (%rsi)
.L1:
    rep; ret
```
%%% reference
A、B 两问的答案如下。
%%% part-stem: q-0300000000000016-A
A. 用 C 语言写一个 goto 版本，执行同样的计算并模拟汇编代码的控制流。给汇编代码加注释可能有帮助。
%%% part-reference: q-0300000000000016-A
```c
void goto_cond(long a, long *p) {
    if (p == 0)
        goto done;
    if (*p >= a)
        goto done;
    *p = a;
done:
    return;
}
```

对应的注释：`testq %rsi,%rsi` / `je .L1` 判断 `p == 0`，成立就跳到 `done`；`cmpq %rdi,(%rsi)` / `jge .L1` 判断 `*p >= a`，成立也跳到 `done`；只有两个测试都不成立才执行 `*p = a`。
%%% part-stem: q-0300000000000016-B
B. 请说明为什么 C 语言代码中只有一个 `if` 语句，而汇编代码包含两个条件分支。
%%% part-reference: q-0300000000000016-B
第一个条件分支是 `&&` 表达式实现的一部分。如果对 `p` 为非空的测试失败，代码就跳过对 `a > *p` 的测试，因此短路求值把一个 `if` 拆成了两个条件分支。
