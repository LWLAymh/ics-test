练习题 3.17 将 `if` 语句翻译成 goto 代码的另一种可行的规则如下：

```text
t = test-expr;
if (t)
    goto true;
else-statement
goto done;
true:
    then-statement
done:
```

参照的原始函数 `absdiff_se` 如下（它会增加全局计数器 `lt_cnt` 或 `ge_cnt` 之一）：

```c
long lt_cnt = 0;
long ge_cnt = 0;

long absdiff_se(long x, long y)
{
    long result;
    if (x < y) {
        lt_cnt++;
        result = y - x;
    }
    else {
        ge_cnt++;
        result = x - y;
    }
    return result;
}
```

与之对应的旧翻译规则给出的 goto 版本是：先测试 `x >= y`，成立则 `goto x_ge_y`，否则执行 `if` 部分后返回，随后是标号 `x_ge_y` 与 `else` 部分。
%%% reference
A、B 两问的答案如下。
%%% part-stem: q-0300000000000017-A
A. 基于上面给出的替代规则，重写 `absdiff_se` 的 goto 版本。
%%% part-reference: q-0300000000000017-A
按“测试成立就跳到 then 分支”的规则翻译，只需调换原来的几行代码：

```c
long gotodiff_se_alt(long x, long y) {
    long result;
    if (x < y)
        goto x_lt_y;
    ge_cnt++;
    result = x - y;
    return result;
x_lt_y:
    lt_cnt++;
    result = y - x;
    return result;
}
```

即原来“测试 `x >= y` 成立则跳到 else”改成“测试 `x < y` 成立则跳到 then”，两个分支的位置随之互换。
%%% part-stem: q-0300000000000017-B
B. 你能想出选用一种规则而不选用另一种规则的理由吗？
%%% part-reference: q-0300000000000017-B
大多数情况下两种方式可以任意选择。但原来的规则对“没有 `else` 语句”这种常见情况更好：此时只要把规则简化为

```text
t = test-expr;
if (!t)
    goto done;
then-statement
done:
```

即可。用替代规则去处理同样的情况反而更麻烦。
