练习题 3.27 先把 `fact_for` 转换成 `while` 循环，再进行 guarded-do 变换，写出 `fact_for` 的 goto 代码。

题中的 `fact_for` 是本章正文给出的 `for` 循环示例，定义如下：

```c
long fact_for(long n)
{
    long i;
    long result = 1;
    for (i = 2; i <= n; i++)
        result *= i;
    return result;
}
```
%%% reference
这道练习题意在加强你对如何实现循环的理解。

```c
long fact_for_gd_goto(long n)
{
    long i = 2;
    long result = 1;
    if (n <= 1)
        goto done;
loop:
    result *= i;
    i++;
    if (i <= n)
        goto loop;
done:
    return result;
}
```
