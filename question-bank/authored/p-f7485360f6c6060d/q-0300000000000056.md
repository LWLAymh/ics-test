%%% stem
练习题 3.56 考虑下面的 C 函数，其中 `EXPR` 是用 `#define` 定义的宏：

```c
double simplefun(double x) {
    return EXPR(x);
}
```

下面，我们给出了为不同的 `EXPR` 定义生成的 AVX2 代码，其中，`x` 的值保存在 `%xmm0` 中。这些代码都对应于某些对浮点数值有用的操作。确定这些操作都是什么。要理解从内存中取出的常数字的位模式才能找出答案。
%%% reference
各小问答案与推理分别列在对应小问的参考区。
%%% part-stem: q-0300000000000056-A
A. `EXPR(x)` 对应什么运算？写出对应的 C 表达式。

```text
1  vmovsd .LC1(%rip), %xmm1
2  vandpd %xmm1, %xmm0, %xmm0
3  .LC1:
4      .long 4294967295
5      .long 2147483647
6      .long 0
7      .long 0
```

`EXPR(x)` = {{blank:exprA}}
%%% part-reference: q-0300000000000056-A
在此可以看到从地址 `.LC1` 开始的 16 个字节是一个掩码，它的低 8 个字节是全 1，除了最高位，这是双精度值的符号位。计算这个掩码和 `%xmm0` 的 AND 值时，会清除 x 的符号位，得到绝对值。实际上，定义 `EXPR(x)` 为 `fabs(x)` 就能得到这段代码，`fabs` 是在 `<math.h>` 中定义的。

掩码的两个 `.long` 值分别对应 0xFFFFFFFF（低 4 字节）与 0x7FFFFFFF（高 4 字节），合起来是 0x7FFFFFFFFFFFFFFF：除最高位（符号位）外全为 1，因此 `vandpd` 只保留 x 的其余各位，即 $|x|$。
%%% part-stem: q-0300000000000056-B
B. `EXPR(x)` 产生什么？

```text
1  vxorpd %xmm0, %xmm0, %xmm0
```

`EXPR(x)` = {{blank:exprB}}
%%% part-reference: q-0300000000000056-B
可以看到 `vxorpd` 指令将整个寄存器设置为 0，所以这是一种产生浮点常数 0.0 的方法。
%%% part-stem: q-0300000000000056-C
C. `EXPR(x)` 计算什么表达式？

```text
1  vmovsd .LC2(%rip), %xmm1
2  vxorpd %xmm1, %xmm0, %xmm0
3  .LC2:
4      .long 0
5      .long -2147483648
6      .long 0
7      .long 0
```

`EXPR(x)` = {{blank:exprC}}
%%% part-reference: q-0300000000000056-C
可以看到从地址 `.LC2` 开始的 16 个字节是一个掩码，它只有一个 1 位，位于 XMM 寄存器中低位数值的符号位。计算这个掩码与 `%xmm0` 的 EXCLUSIVE-OR 值时，会改变 x 符号的值，计算出表达式 `-x`。

掩码的两个 `.long` 值为 0 与 -2147483648（即 0x80000000），合起来是 0x8000000000000000，正好只有符号位为 1，因此 `vxorpd` 只翻转符号位。
