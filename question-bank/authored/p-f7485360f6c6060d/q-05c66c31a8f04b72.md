练习题 3.30 下面给出 `switch2` 的初始汇编和跳转表。跳转表索引为调整后的 x 值；越界时跳到默认情况 `.L2`。

```c
void switch2(long x, long *dest) {
    long val = 0;
    switch (x) { /* 主体省略 */ }
    *dest = val;
}
```

```text
1 switch2:
2     addq $1, %rdi
3     cmpq $8, %rdi
4     ja   .L2
5     jmp  *.L4(,%rdi,8)

1 .L4:
2     .quad .L9
3     .quad .L5
4     .quad .L6
5     .quad .L7
6     .quad .L2
7     .quad .L7
8     .quad .L8
9     .quad .L2
10    .quad .L5
```

%%% part-stem: q-05c66c31a8f04b72-A
A. `switch` 语句中各个情况标号的值分别是多少？
%%% part-reference: q-05c66c31a8f04b72-A
情况标号为 −1、0、1、2、4、5、7。因为 x 加 1 后作为索引，越界门槛对应最大标号 7，最小标号为 −1；默认目标的表项对应缺失标签 3、6。
%%% part-stem: q-05c66c31a8f04b72-B
B. 哪些情况标号会共享同一段代码（即有多个标号）？
%%% part-reference: q-05c66c31a8f04b72-B
目标 `.L5` 对应标号 0 和 7；目标 `.L7` 对应标号 2 和 4。
