练习题 3.40 下面的 C 代码将定长数组的对角线上的元素设置为 `val`：

```c
/* Set all diagonal elements to val */
void fix_set_diag(fix_matrix A, int val) {
    long i;
    for (i = 0; i < N; i++)
        A[i][i] = val;
}
```

当以优化等级 -O1 编译时，GCC 产生如下汇编代码：

```text
void fix_set_diag(fix_matrix A, int val)
A in %rdi, val in %rsi

1  fix_set_diag:
2      movl $0, %eax
3  .L13:
4      movl %esi, (%rdi,%rax)
5      addq $68, %rax
6      cmpq $1088, %rax
7      jne .L13
8      rep; ret
```

创建一个 C 代码程序 `fix_set_diag_opt`，它使用类似于这段汇编代码中所使用的优化，风格与图 3-37b 中的代码一致。使用含有参数 N 的表达式，而不是整数常量，使得如果重新定义了 N，你的代码仍能够正确地工作。

`int` 占 4 字节，`A[i][i]` 就是线性序列中下标为 $i(N+1)$ 的那个元素，所以对角线相邻元素在线性序列中相隔 $N+1$ 个元素。

由 `addq $68, %rax` 得 $4(N+1)=68$，即 $N+1=17$、$N=16$；由 `cmpq $1088, %rax` 得终止字节量 1088，换算成元素个数为 $1088/4=272=N(N+1)=16\times 17$，与 $N=16$ 自洽。

%%% part-reference: q-0300000000000040-B
```c
/* Set all diagonal elements to val */
void fix_set_diag_opt(fix_matrix A, int val) {
    int *Abase = &A[0][0];
    long i = 0;
    long iend = N*(N+1);
    do {
        Abase[i] = val;
        i += (N+1);
    } while (i != iend);
}
```

这个函数引入了一个变量 `Abase`，`int *` 类型，指向数组 A 的起始位置。这个指针指向一个 4 字节整数序列，这个序列由按照行优先顺序存放的 A 的元素组成。我们引入一个整数变量 index（即代码中的 `i`），它一步一步经过 A 的对角线：对角线元素 i 和 i + 1 在序列中相隔 N + 1 个元素，而且一旦我们到达对角线元素 N（索引为 $N(N+1)$），我们就超出了边界。

`iend` 也可写成等价的 `N*N+N`，`i += (N+1)` 与 `i += N+1` 等价；循环条件与汇编中的 `jne` 一致，必须用 `!=` 而不是 `<`。

C. 逐条说明这段汇编代码中 1～8 行各指令的作用，并说明编译器相比原始 C 代码做了哪些优化。
%%% part-reference: q-0300000000000040-C
这个练习要求你能够研究编译产生的汇编代码，了解执行了哪些优化。在这个情况中，编译器做一些聪明的优化。

实际的汇编代码遵循这样的通用格式，但是现在指针的增加必须乘以因子 4。我们将寄存器 `%rax` 标记为存放值 index4，等于 C 版本中的 index，但是使用因子 4 进行伸缩。

```text
1 fix_set_diag:
  void fix_set_diag(fix_matrix A, int val)
  A in %rdi, val in %rsi
2     movl $0, %eax                 Set index4 = 0
3 .L13:                        loop:
4     movl %esi, (%rdi,%rax)        Set Abase[index4/4] to val
5     addq $68, %rax                Increment index4 += 4(N+1)
6     cmpq $1088, %rax              Compare index4: 4N(N+1)
7     jne  .L13                    If !=, goto loop
8     rep; ret                      Return
```

要点：原 C 代码的 `for` 循环被改写成先执行循环体、再判断的 `do`-`while` 形式；对角线元素的下标 `i*N+i` 的复杂地址计算被强度削弱为对线性下标的一次加法（每次加 $N+1$），地址由 `(%rdi,%rax)` 这种基址加变址的方式给出；循环边界由变量比较变成与常量 1088 比较，且当 $N=16$ 时 index4 的停止点正是 $4\times 16\times(16+1)=1088$。
