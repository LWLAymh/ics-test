%%% stem
R、S、T 是用 `#define` 声明的常数，`long` 为 8 字节。

```c
long A[R][S][T];
long store_ele(long i, long j, long k, long *dest) {
    *dest = A[i][j][k];
    return sizeof(A);
}
```

GCC 生成（i、j、k、dest 分别在 `%rdi`、`%rsi`、`%rdx`、`%rcx`）：

```asm
store_ele:
    leaq    (%rsi,%rsi,2), %rax
    leaq    (%rsi,%rax,4), %rax
    movq    %rdi, %rsi
    salq    $6, %rsi
    addq    %rsi, %rdi
    addq    %rax, %rdi
    addq    %rdi, %rdx
    movq    A(,%rdx,8), %rax
    movq    %rax, (%rcx)
    movl    $3640, %eax
    ret
```
%%% reference
数组采用行优先存储。
%%% part-stem: q-386987c9307bd84b-A
把二维数组的位置公式扩展到三维，给出 `A[i][j][k]` 的地址公式。
%%% part-reference: q-386987c9307bd84b-A
$\operatorname{addr}(A[i][j][k])=\operatorname{addr}(A)+8((iS+j)T+k)$。每增加一个 i 跨过 ST 个 long，每增加一个 j 跨过 T 个 long。
%%% part-stem: q-386987c9307bd84b-B
根据汇编确定：R = {{blank:R}}，S = {{blank:S}}，T = {{blank:T}}。
%%% part-reference: q-386987c9307bd84b-B
前两条 `leaq` 得到 13j，移位和加法得到 65i，所以 T=13、ST=65、S=5。总字节数为 3640，故 R=3640/(8×5×13)=7。
