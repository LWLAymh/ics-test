%%% stem
练习题 3.54 函数 `funct2` 具有如下原型：

```c
double funct2(double w, int x, float y, long z);
```

GCC 为该函数产生如下代码：

```text
double funct2(double w, int x, float y, long z)
w in %xmm0, x in %edi, y in %xmm1, z in %rsi

1  funct2:
2      vcvtsi2ss  %edi, %xmm2, %xmm2
3      vmulss     %xmm1, %xmm2, %xmm1
4      vunpcklps  %xmm1, %xmm1, %xmm1
5      vcvtps2pd  %xmm1, %xmm2
6      vcvtsi2sdq %rsi, %xmm1, %xmm1
7      vdivsd     %xmm1, %xmm0, %xmm0
8      vsubsd     %xmm0, %xmm2, %xmm0
9      ret
```
%%% reference
各小问答案与推理分别列在对应小问的参考区。
%%% part-stem: q-0300000000000054-A
A. 逐行分析汇编，填出每一步计算或转换得到的值（表达式中用 w、x、y、z 表示参数）：

| 行 | 指令 | 该处得到的值 |
|---|---|---|
| 2 | `vcvtsi2ss %edi, %xmm2, %xmm2` | 把 x 转换为 {{blank:ty1}} |
| 3～5 | `vmulss`、`vunpcklps`、`vcvtps2pd` | `%xmm2` 中得到 {{blank:e1}} |
| 6 | `vcvtsi2sdq %rsi, %xmm1, %xmm1` | 把 z 转换为 {{blank:ty2}} |
| 7 | `vdivsd %xmm1, %xmm0, %xmm0` | `%xmm0` 中得到 {{blank:e2}} |
| 8 | `vsubsd %xmm0, %xmm2, %xmm0` | 返回 {{blank:e3}} |
%%% part-reference: q-0300000000000054-A
一步步梳理汇编代码，确定每一步计算什么，就很容易找到这道题的答案，如下面的注释所示：

```text
double funct2(double w, int x, float y, long z)
w in %xmm0, x in %edi, y in %xmm1, z in %rsi
1 funct2:
2     vcvtsi2ss  %edi, %xmm2, %xmm2     Convert x to float
3     vmulss     %xmm1, %xmm2, %xmm1    Multiply by y
4     vunpcklps  %xmm1, %xmm1, %xmm1
5     vcvtps2pd  %xmm1, %xmm2          Convert x*y to double
6     vcvtsi2sdq %rsi, %xmm1, %xmm1     Convert z to double
7     vdivsd     %xmm1, %xmm0, %xmm0    Compute w/z
8     vsubsd     %xmm0, %xmm2, %xmm0    Subtract from x*y
9     ret                              Return
```

对照各行：第 2 行把 x 转换为 `float`；第 3 行把 `%xmm2` 与 y 相乘，第 3～5 行之后 `%xmm2` 中是 `x*y` 的 double 值（`vmulss` 是单精度乘、`vcvtps2pd` 再转成双精度）；第 6 行把 z 转换为 `double`；第 7 行算出 `w/z`；第 8 行用 `%xmm2` 中的 `x*y` 减去 `%xmm0` 中的 `w/z`，返回 `x*y - w/z`。

乘法满足交换律，`x*y` 与 `y*x` 是同一个值，故答案中两种写法都接受。
%%% part-stem: q-0300000000000054-B
B. 写出 `funct2` 的 C 语言版本。
%%% part-reference: q-0300000000000054-B
可以从分析得出结论，该函数计算 `y*x-w/z`。按原型写成 C 函数即：

```c
double funct2(double w, int x, float y, long z)
{
    return y*x - w/z;
}
```
