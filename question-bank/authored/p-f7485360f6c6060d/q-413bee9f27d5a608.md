练习题 3.38 考虑下面的数组：

```c
long P[M][N];
long Q[N][M];
long sum_element(long i, long j) { return P[i][j] + Q[j][i]; }
```

GCC 生成：

```asm
sum_element:
    leaq 0(,%rdi,8), %rdx
    subq %rdi, %rdx
    addq %rsi, %rdx
    leaq (%rsi,%rsi,4), %rax
    addq %rax, %rdi
    movq Q(,%rdi,8), %rax
    addq P(,%rdx,8), %rax
    ret
```

根据汇编代码和二维数组行优先布局，确定 M、N：M={{blank:M}}，N={{blank:N}}。
%%% reference
M=5，N=7。对 P 的偏移为 `8(7i+j)`，说明 P 每行 7 列；对 Q 的偏移为 `8(5j+i)`，说明 Q 每行 5 列。
