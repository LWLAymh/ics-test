%%% stem
以下 C 代码计算两个 64 位有符号值的 128 位乘积并保存到内存：

```c
typedef __int128 int128_t;
void store_prod(int128_t *dest, int64_t x, int64_t y) {
    *dest = x * (int128_t)y;
}
```

参数 dest、x、y 分别在 `%rdi`、`%rsi`、`%rdx`。GCC 产生：

```asm
store_prod:
    movq    %rdx, %rax
    cqto
    movq    %rsi, %rcx
    sarq    $63, %rcx
    imulq   %rax, %rcx
    imulq   %rsi, %rdx
    addq    %rdx, %rcx
    mulq    %rsi
    addq    %rcx, %rdx
    movq    %rax, (%rdi)
    movq    %rdx, 8(%rdi)
    ret
```

描述三个乘法所实现的算法，并逐条注释汇编如何实现它。提示：将符号扩展后的 x、y 写成 $x=2^{64}x_h+x_l$、$y=2^{64}y_h+y_l$，乘积写成 $p=2^{64}p_h+p_l$。解释如何从各高、低部分得到 $p_h$、$p_l$。
%%% reference
以模 $2^{128}$ 运算，有

$$
p=x_ly_l+2^{64}(x_hy_l+y_hx_l).
$$

符号扩展高字 xh、yh 分别为 0 或全 1（即 −1）。高字乘高字项乘以 $2^{128}$，不影响结果。

```asm
    movq    %rdx, %rax        # rax = yl
    cqto                     # rdx = yh（y的符号扩展）
    movq    %rsi, %rcx        # rcx = xl
    sarq    $63, %rcx         # rcx = xh
    imulq   %rax, %rcx        # rcx = xh*yl 的低64位
    imulq   %rsi, %rdx        # rdx = yh*xl 的低64位
    addq    %rdx, %rcx        # rcx = 两个交叉项之和
    mulq    %rsi              # rdx:rax = 无符号 xl*yl
    addq    %rcx, %rdx        # 高字加上交叉项，得到 ph
    movq    %rax, (%rdi)      # 保存 pl
    movq    %rdx, 8(%rdi)     # 保存 ph
```

交叉项只需低 64 位，因此双操作数 `imulq` 足够；`mulq` 提供无符号低字乘积的完整 128 位结果。
