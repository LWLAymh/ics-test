%%% stem
A、B 是正整数常数。使用 x86-64 常规布局：char/short/int/long 分别为 1/2/4/8 字节，按自然边界对齐。

```c
typedef struct {
    int x[A][B];
    long y;
} str1;

typedef struct {
    char array[B];
    int t;
    short s[A];
    long u;
} str2;

void setVal(str1 *p, str2 *q) {
    long v1 = q->t;
    long v2 = q->u;
    p->y = v1 + v2;
}
```

p 在 `%rdi`、q 在 `%rsi`，GCC 生成：

```asm
setVal:
    movslq  8(%rsi), %rax
    addq    32(%rsi), %rax
    movq    %rax, 184(%rdi)
    ret
```

A = {{blank:a}}，B = {{blank:b}}。（答案唯一。）
%%% reference
A=9，B=5。

t 偏移为 8，所以 $5\le B\le8$。u 偏移为 32，s 从偏移 12 开始，因此 $24<12+2A\le32$，即 $7\le A\le10$。y 偏移为 184，故 $176<4AB\le184$，即 $44<AB\le46$。这些条件的唯一整数解为 A=9、B=5；此时 x 占180字节，对齐后 y 从184开始，s占18字节，对齐后u从32开始。
