练习题 3.15 在下面这些反汇编二进制代码节选中，有些信息被 X 代替了。回答下列关于这些指令的问题。反汇编中列出的字节编码是跳转指令的目标偏移量。

A. 下面 `je` 指令的目标是什么？（在此，你不需要知道任何有关 `callq` 指令的信息。）

```asm
4003fa: 74 02       je    XXXXXX
4003fc: ff d0       callq *%rax
```

目标地址 = {{blank:a}}

B. 下面 `je` 指令的目标是什么？

```asm
40042f: 74 f4       je    XXXXXX
400431: 5d          pop   %rbp
```

目标地址 = {{blank:b}}

C. `ja` 和 `pop` 指令的地址是多少？

```asm
XXXXXX: 77 02       ja    400547
XXXXXX: 5d          pop   %rbp
```

`ja` 的地址 = {{blank:c-ja}}，`pop` 的地址 = {{blank:c-pop}}

D. 在下面的代码中，跳转目标的编码是 PC 相对的，且是一个 4 字节补码数。字节按照从最低位到最高位的顺序列出，反映出 x86-64 的小端法字节顺序。跳转目标的地址是什么？

```asm
4005e8: e9 73 ff ff ff    jmpq XXXXXXX
4005ed: 90                nop
```

目标地址 = {{blank:d}}
%%% reference
这个练习要求仔细检查反汇编代码并推理跳转目标的编码，同时练习十六进制运算。

A. `je` 是 2 字节指令，目标偏移量 0x02 相对于下一条指令的地址计算：0x4003fc + 0x02 = **0x4003fe**。

```asm
4003fa: 74 02                 je     4003fe
4003fc: ff d0                 callq  *%rax
```

B. 0xf4 是 -12 的单字节补码表示，所以目标是 0x400431 - 12 = **0x400425**。

```asm
40042f: 74 f4                 je     400425
400431: 5d                    pop    %rbp
```

C. 跳转目标是绝对地址 0x400547，而字节编码表明目标在距离 `pop` 指令 0x2 处，所以 `pop` 位于 0x400547 - 0x2 = **0x400545**；`ja` 的编码需要 2 个字节，因此位于 **0x400543**。

```asm
400543: 77 02                 ja     400547
400545: 5d                    pop    %rbp
```

D. 按相反顺序读这 4 个字节，得到目标偏移量 0xffffff73，即十进制 -141。加上下一条指令（`nop`）的地址 0x4005ed，得到 **0x400560**。

```asm
4005e8: e9 73 ff ff ff        jmpq   400560
4005ed: 90                    nop
```
