练习题 3.9。为下面的C函数填出缺失的两条汇编指令。参数`x`、`n`分别在`%rdi`、`%rsi`中，要求右移使用算术右移：

```c
long shift_left4_rightn(long x, long n) {
    x <<= 4;
    x >>= n;
    return x;
}
```

```asm
shift_left4_rightn:
    movq %rdi, %rax
    {{blank:sal}}    # x <<= 4
    movl %esi, %ecx
    {{blank:sar}}    # x >>= n
```

salq $4, %rax
sarq %cl, %rax
