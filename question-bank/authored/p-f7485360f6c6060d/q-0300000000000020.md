练习题 3.20 在下面的 C 函数中，我们对 `OP` 操作的定义是不完整的：

```c
#define OP              /* Unknown operator */

long arith(long x) {
    return x OP 8;
}
```

当编译时，GCC 会产生如下汇编代码：

```asm
long arith(long x)
x in %rdi

arith:
    leaq   7(%rdi), %rax
    testq  %rdi, %rdi
    cmovns %rdi, %rax
    sarq   $3, %rax
    ret
```
%%% reference
这道题提供了研究条件传送使用的机会。各小问的答案与推理分别列在对应小问的参考区。
%%% part-stem: q-0300000000000020-A
A. `OP` 进行的是什么操作？`x OP 8` 里的 `OP` 是 {{blank:op}}。
%%% part-reference: q-0300000000000020-A
运算符是 `/`。可以看到这是一个通过右移实现除以 $2^3$ 的例子（见 2.3.7 节）。在移位 $k = 3$ 之前，如果被除数是负数的话，必须加上偏移量 $2^k - 1 = 7$。
%%% part-stem: q-0300000000000020-B
B. 给代码添加注释，解释它是如何工作的。
%%% part-reference: q-0300000000000020-B
下面是该汇编代码加上注释的一个版本：

```asm
long arith(long x)
x in %rdi
arith:
    leaq   7(%rdi), %rax    temp = x+7
    testq  %rdi, %rdi       Test x
    cmovns %rdi, %rax       If x >= 0, temp = x
    sarq   $3, %rax         result = temp >> 3 (= x/8)
    ret
```

这个程序创建一个临时值等于 $x + 7$，预期 x 为负、需要加偏移量时使用。`cmovns` 指令在当 $x \ge 0$ 条件成立时把这个值修改为 x，然后再移动 3 位，得到 $x/8$。
