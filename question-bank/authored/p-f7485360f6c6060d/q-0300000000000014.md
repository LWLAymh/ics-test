练习题 3.14 考虑下面的 C 语言代码：

```c
int test(data_t a) {
    return a TEST 0;
}
```

它给出了参数 a 和 0 之间比较的一般形式。`data_t` 通过 `typedef` 设置参数的数据类型，`TEST` 通过 `#define` 设置比较的类型。对于下面 A～D 中每个指令序列，确定哪种数据类型 `data_t` 和哪种比较 `TEST` 会让编译器产生这样的代码（可能有多个正确答案）。

与练习题 3.13 不同的是，这里用的是 `TEST` 指令而不是 `CMP` 指令。
%%% reference
`TEST` 指令把两个操作数按位与后设置条件码，这里两个操作数相同，因此相当于用自身值设置条件码，再配合 `SET` 指令把比较结果写入 `%al`。

A. 后缀 `q` 表明是 64 位操作数，`setge` 是对补码的 `>=`，一定是有符号数，所以 `data_t` 一定是 `long`。

B. 后缀 `w` 表明是 16 位操作数，`sete` 是 `==`，对有符号和无符号都一样，所以 `data_t` 是 `short` 或者 `unsigned short`。

C. 后缀 `b` 表明是 8 位操作数，`seta` 是对无符号数的 `>`，所以 `data_t` 一定是 `unsigned char`。

D. 后缀 `l` 表明是 32 位操作数，`setne` 判断的是不等于，所以 `TEST` 是 `!=`；`data_t` 取 `int`。

> 题源《练习题答案.md》在 D 处写作“比较是 `<=`”，但该处的指令是 `setne`（不相等时置位），与 `<=` 不符，属于题源笔误。这里按指令语义记为 `!=`，并保留说明以便复核。另外 `a != 0` 对 `unsigned int` 会产生同样的代码，题源只列 `int`。
