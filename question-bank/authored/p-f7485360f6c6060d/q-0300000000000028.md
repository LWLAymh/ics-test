练习题 3.28 函数 `fun_b` 有如下整体结构：

```c
long fun_b(unsigned long x) {
    long val = 0;
    long i;
    for (...; ...; ...) {
        ...
    }
    return val;
}
```

```text

x in %rdi

1  fun_b:
2      movl  $64, %edx
```

%%% part-reference: q-0300000000000028-A
以下是原始的 C 代码：

```c
long fun_b(unsigned long x) {
    long val = 0;
    long i;
    for (i = 64; i != 0; i--) {
        val = (val << 1) | (x & 0x1);
        x >>= 1;
    }
    return val;
}
```
%%% part-stem: q-0300000000000028-B
B. 解释循环前为什么没有初始测试也没有初始跳转到循环内部的测试部分。
%%% part-reference: q-0300000000000028-B
这段代码是用 guarded-do 变换生成的，但是编译器发现因为 i 初始化成了 64，所以一定会满足测试 i ≠ 0，因此初始的测试是没必要的。

C. 用自然语言描述这个函数是计算什么的。
%%% part-reference: q-0300000000000028-C
这段代码把 x 中的位反过来，创造一个镜像。实现的方法是：将 x 的位从左往右移，然后再填入这些位，就像是把 val 从右往左移。
