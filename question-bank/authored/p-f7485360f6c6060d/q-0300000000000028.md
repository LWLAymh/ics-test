```c
long fun_b(unsigned long x) {

    long i;

        ...
    }

}
```

```asm
fun_b:

.L10:
```

%%% part-reference: q-0300000000000028-A
以下是原始的 C 代码：

```c
long fun_b(unsigned long x) {
    long val = 0;
    long i;
    for (i = 64; i != 0; i--) {
        val = (val << 1) | (x & 0x1);
        x >>= 1;
    }
    return val;
}
```

解释循环前为什么没有初始测试，也没有初始跳转到循环内部的测试部分。
%%% part-reference: q-0300000000000028-B
这段代码采用 guarded-do 形式：编译器已知 `i` 初始化为 `64`，第一次执行循环前必定满足 `i != 0`，因此可以省略初始测试，直接进入循环体。每次执行循环体后再递减计数器并判断是否继续。

%%% part-reference: q-0300000000000028-C
函数将 `x` 的 64 位位模式逐位反转，得到其镜像：原来的最低位变成结果的最高位，原来的最高位变成结果的最低位。

每次迭代取 `x` 的最低位，把 `val` **左移**一位后将该位放入 `val` 的最低位，再将无符号的 `x` **逻辑右移**一位。共迭代 64 次，完成全部位的反转。这里讨论返回结果的位模式。
