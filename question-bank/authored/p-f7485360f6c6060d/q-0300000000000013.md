练习题 3.13 考虑下列的 C 语言代码：

```c
int comp(data_t a, data_t b) {
    return a COMP b;
}
```

它给出了参数 a 和 b 之间比较的一般形式。参数的数据类型 `data_t`（通过 `typedef`）是表 3-1 中列出的某种整数类型，可以是有符号的也可以是无符号的，`COMP` 通过 `#define` 定义。

假设 a 在 `%rdi` 中某个部分，b 在 `%rsi` 中某个部分。对于 A～C 中每个指令序列，确定哪种数据类型 `data_t` 和哪种比较 `COMP` 会让编译器产生这样的代码；D 可能有多个正确答案，请列出所有正确答案。
%%% reference
汇编代码不记录程序值的类型，而是由指令决定操作数的大小以及是有符号还是无符号。从指令序列反推 C 代码时，必须根据后缀和寄存器指示符做推断。

A. 后缀 `l` 和寄存器指示符表明是 32 位操作数，比较是对补码的 `<`，所以 `data_t` 一定是 `int`。

B. 后缀 `w` 表明是 16 位操作数，比较是对补码的 `>=`，所以 `data_t` 一定是 `short`。

C. 后缀 `b` 表明是 8 位操作数，比较是对无符号数的 `<=`，所以 `data_t` 一定是 `unsigned char`。

D. 后缀 `q` 表明是 64 位操作数，比较是 `!=`；有符号、无符号和指针参数在这一比较上行为相同，所以 `data_t` 可以是 `long`、`unsigned long` 或者某种形式的指针。
