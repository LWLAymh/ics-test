练习题 3.1 给定 `%rax = 0x100`、`%rdx = 0x3`，且内存地址 `0x10C` 处的值为 `0x11`。AT&T 寻址表达式 `9(%rax,%rdx)` 的值是多少？
%%% reference
有效地址为 `9 + %rax + %rdx = 0x10C`，该地址存放的值是 `0x11`。
%%% option: A
`0x10C`
%%% option: B
`0x13`
%%% option: C
`0x11`
%%% option: D
`0x100`
