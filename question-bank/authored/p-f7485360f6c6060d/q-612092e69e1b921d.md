%%% reference
循环中 x 为 `%rdi`，n 从 `%esi` 复制到 `%ecx`（移位使用 `%cl`），result 为 `%rax`，mask 为 `%rdx`。骨架依次填 `0`、`1`、`!= 0`、`mask << n`、`x & mask`。

`mask` 从最低位 1 开始，每轮左移 n 位；把 x 中被 mask 选出的位按位或入 result。当 mask 变成零时结束。机器对 64 位移位使用 n 的低 6 位；移位量有效为零时，mask 不变，循环不终止。C 骨架沿用教材机器运算解释，不能据此保证任意 n 下的严格 ISO C 有符号移位行为。
