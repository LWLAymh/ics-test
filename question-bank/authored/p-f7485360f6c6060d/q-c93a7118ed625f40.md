练习题 3.33 函数 `procprob` 有 4 个参数 `u`、`a`、`v` 和 `b`，每个参数要么是有符号整数，要么是指向有符号整数的指针，且整数类型可以不同。函数体为：

```c
*u += a;
*v += b;
return sizeof(a) + sizeof(b);
```

给定汇编：

```asm
procprob:
    movslq %edi, %rdi
    addq   %rdi, (%rdx)
    addb   %sil, (%rcx)
    movl   $6, %eax
    ret
```

确定四个参数的一种合法顺序和类型。还存在另一种合法答案。
%%% reference
一种合法原型为 `int procprob(int a, short b, long *u, char *v)`：`a` 在 `%edi`，`b` 在 `%si`，`u` 在 `%rdx`，`v` 在 `%rcx`。另一种是 `int procprob(int b, short a, long *v, char *u)`，即把 `a/b` 以及 `u/v` 成对交换。`sizeof(a)+sizeof(b)=4+2=6`。
