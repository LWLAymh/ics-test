%%% stem
练习题 3.42 下面的代码给出了类型 ELE 的结构声明以及函数 `fun` 的原型：

```c
struct ELE {
    long v;
    struct ELE *p;
};

long fun(struct ELE *ptr);
```

当编译 `fun` 的代码时，GCC 会产生如下汇编代码：

```text
long fun(struct ELE *ptr)
ptr in %rdi

1  fun:
2      movl $0, %eax
3      jmp .L2
4  .L3:
5      addq (%rdi), %rax
6      movq 8(%rdi), %rdi
7  .L2:
8      testq %rdi, %rdi
9      jne .L3
10     rep; ret
```

%%% part-stem: q-0300000000000042-A
A. 利用逆向工程技巧写出 `fun` 的 C 代码。
%%% part-reference: q-0300000000000042-A
这道题说明了一个非常普通的数据结构和对它的操作时如何在机器代码中实现。要解答这些问题，还是先对汇编代码加注释，确认出该结构的两个字段分别在偏移量 0（字段 `v`）和 8（字段 `p`）处。

```text
long fun(struct ELE *ptr)
ptr in %rdi
 1 fun:
 2     movl  $0, %eax         result = 0
 3     jmp   .L2             Goto middle
 4 .L3:                   loop:
 5     addq  (%rdi), %rax     result += ptr->v
 6     movq  8(%rdi), %rdi    ptr = ptr->p
 7 .L2:                   middle:
 8     testq %rdi, %rdi      Test ptr
 9     jne   .L3             If != NULL, goto loop
10     rep; ret
```

根据加了注释的代码，可以得到 C 语言：

```c
long fun(struct ELE *ptr) {
    long val = 0;
    while (ptr) {
        val += ptr->v;
        ptr = ptr->p;
    }
    return val;
}
```
%%% part-stem: q-0300000000000042-B
B. 描述这个结构实现的数据结构以及 `fun` 执行的操作。
%%% part-reference: q-0300000000000042-B
可以看到每个结构都是一个单链表中的元素，字段 `v` 是元素的值，字段 `p` 是指向下一个元素的指针。函数 `fun` 计算列表中元素值的和。

`fun` 先把 `%rax`（累加器 result）清零，再跳到条件判断处，属于先判断后执行的循环：每轮把当前结点的 `v` 累加到 result，再让 `ptr` 前进到 `ptr->p`，直到 `ptr` 为空指针（`testq` 加 `jne`）为止；返回时 `%rax` 就是整条链上所有 `v` 之和。`ELE` 的两个字段按偏移 0 和 8 排放，正是一个 8 字节长整型加一个 8 字节指针的链表结点。
