%%% stem
练习题 3.12。把有符号除法版本改为无符号除法，完成以下函数。参数`x`、`y`、`qp`、`rp`分别在`%rdi`、`%rsi`、`%rdx`、`%rcx`中；`%rdx:%rax`组成128位被除数，商放在`%rax`、余数放在`%rdx`。

```c
void uremdiv(unsigned long x, unsigned long y,
             unsigned long *qp, unsigned long *rp) {
    unsigned long q = x / y;
    unsigned long r = x % y;
    *qp = q;
    *rp = r;
}
```

```asm
uremdiv:
    movq %rdx, %r8
    movq %rdi, %rax
    {{blank:zero-high}}
    {{blank:unsigned-div}}
    movq %rax, (%r8)
    movq %rdx, (%rcx)
    ret
```
%%% reference
先把被除数 `%rdx:%rax` 的高 64 位清零，再用无符号除法指令：`movl $0,%edx`；`divq %rsi`。
