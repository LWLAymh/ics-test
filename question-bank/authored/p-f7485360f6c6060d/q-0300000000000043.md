练习题 3.43 假设给你一个任务，检查一下 C 编译器为结构和联合的访问产生正确的代码。你写了下面的结构声明：

```c
typedef union {
    struct {
        long u;
        short v;
        char w;
    } t1;
    struct {
        int a[2];
        char *p;
    } t2;
} u_type;
```

你写了一组具有下面这种形式的函数：

```c
void get(u_type *up, type *dest) {
    *dest = expr;
}
```

这组函数有不一样的访问表达式 `expr`，而且根据 `expr` 的类型来设置目的数据类型 `type`。然后再检查编译这些函数时产生的代码，看看它们是否与你预期的一样。

假设在这些函数中，`up` 和 `dest` 分别被加载到寄存器 `%rdi` 和 `%rsi` 中。填写下表中的数据类型 `type`，并用 1～3 条指令序列来计算表达式，并将结果存储到 `dest` 中。

| expr | type | 代码 |
| --- | --- | --- |
| `up->t1.u` | `long` | `movq (%rdi), %rax`；`movq %rax, (%rsi)` |
| `up->t1.v` |  |  |
| `&up->t1.w` |  |  |
| `up->t2.a` |  |  |
| `up->t2.a[up->t1.u]` |  |  |
| `*up->t2.p` |  |  |

A. 填写下表中每个表达式的类型 `type`（按 C 语言类型名的常规写法填写，指针类型写成 `long *` 这种形式）。

| --- | --- |

%%% part-reference: q-0300000000000043-A
联合的布局：`t1` 中 `long u` 占偏移 0～7，`short v` 占 8～9，`char w` 占 10；`t2` 中 `int a[2]` 占偏移 0～7，`char *p` 需要 8 字节对齐，占偏移 8～15。联合的总大小为 16 字节。

| 表达式 | type |
| --- | --- |
| `up->t1.v` | `short` |
| `&up->t1.w` | `char *` |
| `up->t2.a` | `int *` |
| `up->t2.a[up->t1.u]` | `int` |
| `*up->t2.p` | `char` |

`up->t2.a` 是数组名，作为右值时退化为指向首元素的指针，因此类型是 `int *`；`&up->t1.w` 取的是 `char` 字段的地址，因此类型是 `char *`。
%%% part-stem: q-0300000000000043-B
B. 对下表中的每个表达式，写出 1～3 条指令来计算它并把结果存入 `dest`（`up` 在 `%rdi`，`dest` 在 `%rsi`）。一行里有多条指令时用分号隔开。

| 表达式 | 代码 |
| --- | --- |
| `up->t1.v` | {{blank:cv}} |
| `&up->t1.w` | {{blank:cw}} |
| `up->t2.a` | {{blank:ca}} |
| `up->t2.a[up->t1.u]` | {{blank:caidx}} |
| `*up->t2.p` | {{blank:cp}} |
%%% part-reference: q-0300000000000043-B
| 表达式 | 代码 |
| --- | --- |
| `up->t1.u` | `movq (%rdi),%rax`；`movq %rax,(%rsi)` |
| `up->t1.v` | `movw 8(%rdi),%ax`；`movw %ax,(%rsi)` |
| `&up->t1.w` | `addq $10,%rdi`；`movq %rdi,(%rsi)` |
| `up->t2.a` | `movq %rdi,(%rsi)` |
| `up->t2.a[up->t1.u]` | `movq (%rdi),%rax`；`movl (%rdi,%rax,4),%eax`；`movl %eax,(%rsi)` |
| `*up->t2.p` | `movq 8(%rdi),%rax`；`movb (%rax),%al`；`movb %al,(%rsi)` |

对照上表的偏移量：`t1.v` 在偏移 8 且宽 2 字节，所以用 `movw`；`t1.w` 在偏移 10，取地址只要给 `%rdi` 加 10；`t2.a` 的地址就是 `up` 本身；`t2.a[up->t1.u]` 先用 `t1.u`（偏移 0 的 `long`）当下标，再用比例因子 4 寻址 `int` 数组；`t2.p` 在偏移 8，解引用后取 1 字节的 `char`。
