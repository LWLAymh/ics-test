练习题 3.26 函数 `fun_a` 有如下整体结构：

```c
long fun_a(unsigned long x) {
    long val = 0;
    while (...) {
        ...
    }
    return ...;
}
```

GCC C 编译器产生如下汇编代码：

```text
long fun_a(unsigned long x)
x in %rdi

1  fun_a:
2      movl  $0, %eax
3      jmp   .L5
4  .L6:
5      xorq  %rdi, %rax
6      shrq  %rdi             Shift right by 1
7  .L5:
8      testq %rdi, %rdi
9      jne   .L6
10     andl  $1, %eax
11     ret
```

下面是原始的 C 代码：

```c
long fun_a(unsigned long x) {
    long val = 0;
    while (x) {
        val ^= x;
        x >>= 1;
    }
    return val & 0x1;
}
```
