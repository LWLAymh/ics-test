ISO C99 使用 `complex` 修饰浮点类型。示例函数及其GCC代码如下：

```c
#include <complex.h>
double c_imag(double complex x) { return cimag(x); }
double c_real(double complex x) { return creal(x); }
double complex c_sub(double complex x, double complex y) {
    return x - y;
}
```

```asm
c_imag:
    movapd  %xmm1, %xmm0
    ret
c_real:
    rep; ret
c_sub:
    subsd   %xmm2, %xmm0
    subsd   %xmm3, %xmm1
    ret
```

%%% reference
A. 在所示调用约定中，一个 `double complex` 使用两个连续XMM寄存器，实部在前、虚部在后。x 的实部、虚部分别在 `%xmm0`、`%xmm1`，第二个参数 y 分别在 `%xmm2`、`%xmm3`。

B. 返回的复数实部在 `%xmm0`、虚部在 `%xmm1`。普通double返回值只用 `%xmm0`，所以 `c_imag` 把虚部移到该寄存器，而 `c_real` 无需移动。
