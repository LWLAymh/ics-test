练习题 3.7。考虑下面的C代码，它缺少被计算的表达式：

```c
long scale2(long x, long y, long z) {
    long t = {{blank:expr}};
    return t;
}
```

用GCC编译该函数得到：

```asm
scale2:
    leaq (%rdi,%rdi,4), %rax
    leaq (%rax,%rsi,2), %rax
    leaq (%rax,%rdx,8), %rax
    ret
```

参数`x`、`y`、`z`分别在`%rdi`、`%rsi`、`%rdx`中。填写缺失表达式。
%%% reference
```c
5 * x + 2 * y + 8 * z
```
