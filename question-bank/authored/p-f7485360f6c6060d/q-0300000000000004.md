练习题 3.4。`src_t`、`dest_t`是用`typedef`声明的数据类型，指针`sp`和`dp`的值分别在`%rdi`和`%rsi`中。为每行给出实现`*dp = (dest_t) *sp;`的两条数据传送指令：第一条从内存读取并完成必要的扩展/截断，写入`%rax`适当部分；第二条把适当部分存到目的内存。大小变化与符号变化同时出现时，先按C类型转换规则处理大小变化。

| `src_t` | `dest_t` | 两条指令 |
| --- | --- | --- |
| `long` | `long` | `movq (%rdi), %rax`；`movq %rax, (%rsi)` |
| `char` | `int` |  |
| `char` | `unsigned` |  |
| `unsigned char` | `long` |  |
| `int` | `char` |  |
| `unsigned` | `unsigned char` |  |
| `char` | `short` |  |
