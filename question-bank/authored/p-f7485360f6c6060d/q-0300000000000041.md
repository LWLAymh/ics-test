练习题 3.41 考虑下面的结构声明：

```c
struct prob {
    int *p;
    struct {
        int x;
        int y;
    } s;
    struct prob *next;
};
```

这个声明说明一个结构可以嵌套在另一个结构中，就像数组可以嵌套在结构中、数组可以嵌套在数组中一样。

下面的过程（省略了某些表达式）对这个结构进行操作：

```c
void sp_init(struct prob *sp) {
    sp->s.x = ________;
    sp->p = ________;
    sp->next = ________;
}
```

```text
偏移 0               8       12      16              24
     +---------------+-------+-------+---------------+
内容 |       p       |  s.x  |  s.y  |     next      |
```

偏移量依次为 0、8、12、16：指针 `p` 占 0～7；内层结构 `s` 紧接其后，`s.x` 在 8～11，`s.y` 在 12～15（两者本来就自然对齐，不需要填充）；指针 `next` 需要 8 字节对齐，因此放在 16～23。该练习表明嵌套的结构的分配是将内层结构嵌入到外层结构之中。

C. 编译器为 `sp_init` 的主体产生的汇编代码如下：

```text
void sp_init(struct prob *sp)
sp in %rdi

1  sp_init:
2      movl 12(%rdi), %eax
3      movl %eax, 8(%rdi)
4      leaq 8(%rdi), %rax
5      movq %rax, (%rdi)
6      movq %rdi, 16(%rdi)
7      ret
```

根据这些信息，填写 `sp_init` 代码中缺失的表达式，并逐条说明这些指令的作用。
%%% part-reference: q-0300000000000041-C
同平时一样，我们从给汇编代码加注释开始：

```text
void sp_init(struct prob *sp)
sp in %rdi
1 sp_init:
2     movl 12(%rdi), %eax    Get sp->s.y
3     movl %eax, 8(%rdi)     Save in sp->s.x
4     leaq 8(%rdi), %rax     Compute &(sp->s.x)
5     movq %rax, (%rdi)      Store in sp->p
6     movq %rdi, 16(%rdi)    Store sp in sp->next
7     ret
```

由此可以产生如下 C 代码：

```c
void sp_init(struct prob *sp)
{
    sp->s.x  = sp->s.y;
    sp->p    = &(sp->s.x);
    sp->next = sp;
}
```

即三个缺失的表达式依次为 `sp->s.y`、`&(sp->s.x)`、`sp`。第 2 行按偏移 12 取出 `s.y`，第 3 行把它写到偏移 8 的 `s.x`；第 4、5 行用 `leaq` 算出 `s.x` 的地址并存进偏移 0 的 `p`；第 6 行把参数 `sp` 本身存进偏移 16 的 `next`。
