练习题 11.1：完成 IPv4 地址转换表。十六进制地址按网络字节顺序写出；十六进制答案需带 `0x` 前缀。

| 十六进制地址 | 点分十进制地址 |
|---|---|
| `0x0` | {{blank:d0}} |
| `0xffffffff` | {{blank:d1}} |
| `0x7f000001` | {{blank:d2}} |
| {{blank:h3}} | `205.188.160.121` |
| {{blank:h4}} | `64.12.149.13` |
| {{blank:h5}} | `205.188.146.23` |
%%% reference
`0x0 ↔ 0.0.0.0`；`0xffffffff ↔ 255.255.255.255`；`0x7f000001 ↔ 127.0.0.1`；`205.188.160.121 ↔ 0xcdbca079`；`64.12.149.13 ↔ 0x400c950d`；`205.188.146.23 ↔ 0xcdbc9217`。每组将地址按四个字节转换即可。
