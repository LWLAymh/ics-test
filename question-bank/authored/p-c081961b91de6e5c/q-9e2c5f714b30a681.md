%%% stem
练习题 10.1 中，程序启动时只有描述符 `0`、`1`、`2` 打开。程序先调用 `Open` 打开第一个文件，调用成功后关闭返回的描述符，再调用 `Open` 打开第二个文件；两次 `Open` 和 `Close` 均成功。第二次 `Open` 返回哪个描述符？
%%% reference
`open` 总是返回最低的未打开描述符。第一次打开得到 3，关闭后 3 被释放，所以第二次打开仍返回 3。
%%% option: A
`3`
%%% option: B
`4`
%%% option: C
`0`
%%% option: D
`1`
