以下程序输出什么？假定初始只有标准输入、输出和错误（描述符 0、1、2）打开，所有文件操作成功。输出为 `fd2 = `{{fd}}。

```c
#include "csapp.h"

int main()
{
    int fd1, fd2;

    fd1 = Open("foo.txt", O_RDONLY, 0);
    fd2 = Open("bar.txt", O_RDONLY, 0);
    Close(fd2);
    fd2 = Open("baz.txt", O_RDONLY, 0);
    printf("fd2 = %d\n", fd2);
    exit(0);
}
```
%%% reference
`fd2 = 4`。`open` 返回当前可用的最小描述符，先得到 3、4；关闭 4 后再次打开会重用 4。
