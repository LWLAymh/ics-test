%%% stem
练习题 10.2 中，`foobar.txt` 的内容为 `foobar`。程序独立打开该文件两次，分别读一次：

```c
fd1 = Open("foobar.txt", O_RDONLY, 0);
fd2 = Open("foobar.txt", O_RDONLY, 0);
Read(fd1, &c, 1);
Read(fd2, &c, 1);
printf("c = %c\n", c);
```

输出是什么？
%%% reference
两个描述符对应不同的打开文件表项，各有独立文件位置。两次读取都读取首字节，最后 `c` 为 `f`。
%%% option: A
`c = o`
%%% option: B
`c = b`
%%% option: C
`c = f`
%%% option: D
输出不确定，因为两个描述符共享同一文件位置。
