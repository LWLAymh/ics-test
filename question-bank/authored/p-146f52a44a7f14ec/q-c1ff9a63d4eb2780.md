练习题 8.2：假设 `Fork()` 成功，分别写出子进程和父进程打印的所有行，按执行顺序用分号分隔。

```c
int main() {
int x = 1;
if (Fork() == 0)
    printf("p1: x=%d\n", ++x);
printf("p2: x=%d\n", --x);
exit(0);
}
```
