%%% stem
练习题 8.2 的程序片段如下。假设 `Fork()` 成功，问子进程中第一条 `printf` 打印什么？

```c
int x = 1;
if (Fork() == 0)
    printf("p1: x=%d\n", ++x);
printf("p2: x=%d\n", --x);
```
%%% reference
子进程中的 `x` 从 1 自增为 2，所以第一行输出 `p1: x=2`。`fork` 后父子进程有各自的地址空间。
%%% option: A
`p1: x=1`
%%% option: B
`p1: x=2`
%%% option: C
`p1: x=0`
%%% option: D
子进程不执行该分支。
