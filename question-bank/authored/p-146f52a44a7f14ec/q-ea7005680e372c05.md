下面程序输出多少行 `hello`？假定所有 `Fork` 调用成功。行数：{{n}}。

```c
#include "csapp.h"

int main()
{
    int i;

    for (i = 0; i < 2; i++)
        Fork();
    printf("hello\n");
    exit(0);
}
```
%%% reference
4 行。每轮中所有已有进程都执行一次 `Fork`，两轮后共有 `2^2 = 4` 个进程，各打印一行。
