以下函数打印多少行？用 n 的函数表示，假定 `n ≥ 1` 且所有 `Fork` 成功。可用 `^` 表示指数。行数：{{n}}。

```c
void foo(int n)
{
    int i;

    for (i = 0; i < n; i++)
        Fork();
    printf("hello\n");
    exit(0);
}
```
%%% reference
`2^n` 行。每轮令进程数翻倍，n 轮后每个进程各输出一次。
