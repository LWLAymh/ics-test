列出下面程序所有可能的输出序列。假定 `fork`、`waitpid` 成功，每个刷新后的单字符按教材模型作为一个输出事件。

```c
int main()
{
    if (fork() == 0) {
        printf("a");
        fflush(stdout);
        exit(0);
    }
    else {
        printf("b");
        fflush(stdout);
        waitpid(-1, NULL, 0);
    }
    printf("c");
    fflush(stdout);
    exit(0);
}
```
%%% reference
只有 `abc` 与 `bac`。`a` 与 `b` 无先后约束；父进程必须等子进程打印 `a` 并终止，才会输出 `c`，且父进程本身先输出 `b` 再输出 `c`。
