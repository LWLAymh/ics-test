下面程序输出多少行 `hello`？假定所有 `Fork` 调用成功。行数：{{n}}。

```c
#include "csapp.h"

void doit()
{
    Fork();
    Fork();
    printf("hello\n");
    return;
}

int main()
{
    doit();
    printf("hello\n");
    exit(0);
}
```
%%% reference
8 行。两次 `Fork` 产生 4 个进程，每个在 `doit` 中打印一次，再返回 `main` 打印一次。
