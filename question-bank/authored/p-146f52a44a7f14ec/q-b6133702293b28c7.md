%%% stem
为每个函数匹配调用/返回行为，填 A、B 或 C。按教材假设 `fork` 和 `execve` 成功。

A. 调用一次，返回两次。

B. 调用一次，从不返回。

C. 调用一次，返回一次或者多次。

| 函数 | 行为 |
| --- | --- |
| `setjmp` | {{setjmp}} |
| `longjmp` | {{longjmp}} |
| `execve` | {{execve}} |
| `fork` | {{fork}} |
%%% reference
依次 C、B、B、A。`setjmp` 直接返回一次，还可由 `longjmp` 多次回到保存点；`longjmp` 不回到自己的调用者；成功的 `execve` 替换当前程序；成功的 `fork` 在父、子进程各返回一次。失败的系统调用不满足后两项的教材简化描述。
