%%% stem
列举以下程序（练习 8.4 中的程序）所有可能的输出。假定 `Fork`、`waitpid` 成功，标准输出接到行缓冲终端，按完整输出行分析。

```c
#include "csapp.h"

int main()
{
    int status;
    pid_t pid;

    printf("Hello\n");
    pid = Fork();
    printf("%d\n", !pid);
    if (pid != 0) {
        if (waitpid(-1, &status, 0) > 0) {
            if (WIFEXITED(status) != 0)
                printf("%d\n", WEXITSTATUS(status));
        }
    }
    printf("Bye\n");
    exit(2);
}
```
%%% reference
共有三种（每列从上到下读）：

| 顺序 | 输出一 | 输出二 | 输出三 |
| --- | --- | --- | --- |
| 1 | Hello | Hello | Hello |
| 2 | 0 | 1 | 1 |
| 3 | 1 | 0 | Bye |
| 4 | Bye | Bye | 0 |
| 5 | 2 | 2 | 2 |
| 6 | Bye | Bye | Bye |

子进程输出 `1`、`Bye` 后以状态 2 退出。父进程输出 `0`，等待子进程结束，再输出 `2`、`Bye`。`Hello` 在创建子进程前已输出并刷新。
