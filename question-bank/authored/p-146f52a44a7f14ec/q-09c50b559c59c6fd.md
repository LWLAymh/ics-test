程序输出多少行 `hello`？假定所有 `Fork` 成功，标准输出接到行缓冲终端。行数：{{n}}。

```c
#include "csapp.h"

void doit()
{
    if (Fork() == 0) {
        Fork();
        printf("hello\n");
        return;
    }
    return;
}

int main()
{
    doit();
    printf("hello\n");
    exit(0);
}
```
%%% reference
5 行。原父进程只在 `main` 打印一次，另外两个进程各在 `doit` 和 `main` 打印一次，所以 `1 + 2×2 = 5`。
