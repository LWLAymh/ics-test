下面程序输出什么？假定 `fork` 成功。输出为 `counter = `{{counter}}。

```c
#include "csapp.h"
int counter = 1;

int main()
{
    if (fork() == 0) {
        counter--;
        exit(0);
    }
    else {
        Wait(NULL);
        printf("counter = %d\n", ++counter);
    }
    exit(0);
}
```
%%% reference
输出 `counter = 2`。子进程将自己的副本减到 0，不影响父进程副本。父进程等待后把自己的 1 加到 2。
