给出下面程序的一种可能输出。假定 `Fork` 成功，标准输出连接到行缓冲终端，按完整输出行分析。

```c
#include "csapp.h"

int main()
{
    int x = 3;

    if (Fork() != 0)
        printf("x=%d\n", ++x);
    printf("x=%d\n", --x);
    exit(0);
}
```
%%% reference
一种可能输出：

```text
x=4
x=3
x=2
```

父进程输出 4 再输出 3，子进程拥有独立的 x 副本，只输出 2。子进程的行也可以出现在父进程两行之前或之间，但父进程的 4 总在其 3 之前。
