%%% stem
练习题 8.3：列出以下程序可能产生的所有输出序列。`waitpid` 保证父进程在打印 `b` 后、打印 `c` 前等到子进程结束；勾选全部可行序列：{{blank:sequences}}

```c
if (Fork() == 0) {
    printf("a"); fflush(stdout);
} else {
    printf("b"); fflush(stdout);
    waitpid(-1, NULL, 0);
}
printf("c"); fflush(stdout);
```
%%% reference
可能的序列有 `acbc`、`abcc` 和 `bacc`。子进程的 `a` 必须先于它的 `c`，父进程的 `b` 必须先于父进程的 `c`，而父进程的 `c` 必须在子进程结束之后输出。
