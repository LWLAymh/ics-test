%%% stem
3.对于`float`类型的变量a，b，下列说法正确的是：
%%% reference
答案：B
考察浮点数的位级表示和运算规则。
A 错误。比如a为1e20，b为1.0，a + b会舍入到1e20,(a + b) – a的
结果是0.0。
B 正确。`float`的位级表示有1个符号位，8位阶码(偏移为127)，23位小数。
所以最小的可精确表达的正数是 $2^{-23} \times 2^{1-127} = 2^{-149}$。
C 错误。可能会发生溢出。
D 错误。a的值为无穷大时，不存在这样的b（因为正负无穷相加结果为NaN）。
%%% option: A
假设a，b不是NaN，则`(a + b) - a == b`总为真
%%% option: B
a的小数字段长度为23位，所以它能精确表示的最小正数是2-149
%%% option: C
假设a表示的是一个整数，那么`(int)a == a`总为真
%%% option: D
假设a不是NaN，则存在b的取值使得`a + b == 0`为真
