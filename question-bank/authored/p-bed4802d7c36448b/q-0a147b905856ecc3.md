%%% stem
3. 对于 IEEE 754 单精度 `float` 类型的变量 `a`、`b`，下列说法正确的是：
%%% reference
答案：B。

- A 错误。例如 `a = 1e20f`、`b = 1.0f` 时，`a + b` 舍入到 `a`，所以 `(a + b) - a` 的结果为 `0.0f`。
- B 正确。单精度浮点数有 1 个符号位、8 个阶码位（偏置为 127）和 23 个小数位。最小正非规格化数为 $2^{-23} \times 2^{1-127} = 2^{-149}$。
- C 错误。即使 `a` 是整数，也可能超出 `int` 的表示范围。
- D 错误。若 `a` 为无穷大，与反号无穷大相加得到 NaN，不能得到 0。
%%% option: A
假设 `a`、`b` 不是 NaN，则 `(a + b) - a == b` 总为真
%%% option: B
`a` 的小数字段长度为 23 位，所以它能精确表示的最小正数是 $2^{-149}$
%%% option: C
假设 `a` 表示的是一个整数，那么 `(int)a == a` 总为真
%%% option: D
假设 `a` 不是 NaN，则存在 `b` 的取值使得 `a + b == 0` 为真
