%%% stem
11. 采用下列的四选一（MUX4）实现HCL表达式：out=（`A || C`）`&&` （`B ||`
C），连接正确的是：
```
Word out = [
    !s1 && !s0: I0;
    !s1:        I1;
    !s0:        I2;
    1:          I3;
];
```
%%% reference
答案：C
%%% option: A
`S1=A, S0=C, I0= 0, I1= 1`，`I2=B`，`I3=0`；
%%% option: B
`S1=B, S0=C, I0= 0, I1= 0`，`I2=A`，`I3=1`；
%%% option: C
`S1=A, S0=B, I0= C, I1= C`，`I2=C`，`I3=1`；
%%% option: D
`S1=A, S0=B, I0= C, I1= C`，`I2=C`，`I3=0`。
