%%% stem
15. 已知`sizeof`操作返回`unsigned`类型，在某按按字节编址、大端法存储的
机器上运行下面代码，得到的输出为：
```c
char s[16] = "I love ICS2023!";
for (int i = sizeof(s); i - sizeof(char) >= 0; i -= sizeof(char)) {
    printf("%c", s[i - 1]);
}
```
%%% reference
答案：D. 主要考察数据类型的隐式转换（sizeof 返回 unsigned，int 和
`unsigned`的比较和转换是写代码时经常会忽略的），大小端表示方法（干扰考察
点）
