9. 在 x86-64 架构、Linux 操作系统下，有如下 C 定义：

```c
int (*A[2])[3];
```

那么 `sizeof A + sizeof *A + sizeof **A + sizeof ***A` 的值为？
%%% reference

`16 + 8 + 12 + 4 = 40`。
