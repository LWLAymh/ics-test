```
0xC  fn  Offset
```
请为该指令补全下面的HCL描述语句，以正确选择可能的PC来源（2分）。
```
word new_pc = [
    icode == ICALL :      略            ;
    icode == IJxx && Cnd :      略     ;
    icode == IBxx && Cnd : (1) __________     ;
    icode == IRET :      略            ;
    1  :       略            ;
];
```

```
0xD  fn  rA  0xF
```

word new_pc = [
