### 16.5（2 分）

阅读下列程序，必要头文件已包含，`env` 和 `x` 均为全局变量。下列程序正常运行，最后 `printf` 输出的十进制数为 {{blank:output}}。

```c
jmp_buf env;
int x = 0;

void f(void)
{
    x = 7;
    longjmp(env, 2);
    x = 9;
}

int main(void)
{
    switch (setjmp(env)) {
    case 0:
        x = 1;
        f();
        x = 3;
        break;
    case 2:
        x += 4;
        break;
    }
    printf("%d\n", x);
    return 0;
}
```
%%% reference
答案：`11`。

第一次 `setjmp` 返回 `0`，`f` 将全局 `x` 改为 `7`；`longjmp(env, 2)` 使 `setjmp` 再次返回 `2`，于是执行 `x += 4`。`longjmp` 后面的 `x = 9` 和原调用路径上的 `x = 3` 均不会执行。这里使用全局 `x`，不涉及被修改的非 `volatile` 自动变量问题。
