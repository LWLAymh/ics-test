### 13.5（4 分）

某直接映射数据 Cache 容量为 64 字节、块大小为 16 字节。数组 `int a[4][K]` 按行优先存储，起始地址为 `0x1000`，`sizeof(int) = 4`。分别取 `K = 8` 与 `K = 12` 进行两次独立实验；每次数组均已初始化，开始测量时 Cache 为空，不计初始化过程的访问。

只统计下列循环对 `a` 的读取，`sum`、`i`、`j` 均放在寄存器中；不考虑预取、其他数据或指令访问，也不改变所列访问顺序。

```c
long sum = 0;
for (int j = 0; j < 4; j++)
    for (int i = 0; i < 4; i++)
        sum += a[i][j];
```

1. `K = 8` 时，16 次数组读取共发生 {{blank:eight}} 次未命中。（2 分）
2. `K = 12` 时，16 次数组读取共发生 {{blank:twelve}} 次未命中。（2 分）
%%% reference
两空为 `16`、`4`。

本题只访问每行前 4 个 `int`，它们恰好位于一个块内。`K = 8` 时相邻行相距 32 字节，4 行依次映射到组 `0、2、0、2`，反复冲突，16 次读取均未命中。`K = 12` 时相邻行相距 48 字节，依次映射到组 `0、3、2、1`，首次读入后均可命中，共 4 次未命中。数组总空间更大，不等于此次访问的工作集更大。
