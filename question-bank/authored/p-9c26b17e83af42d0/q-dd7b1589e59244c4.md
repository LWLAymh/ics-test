### 12.3（3 分，不定项选择）

数组 `a` 按 C 语言的行优先方式连续存储，`sizeof(int) = 4`。只讨论下列代码规定的访问次序，不考虑编译器改变循环。

```c
int a[32][32]; /* initialized */
long sum = 0;
for (int i = 0; i < 32; i++)
    for (int j = 0; j < 32; j++)
        sum += a[j][i];
```

下列说法哪些正确？原卷多选允许少选部分分；网站须集合完全一致才算正确。
%%% option: A
内层循环相邻两次数组访问的地址相差 32 字节。
%%% option: B
交换 `i`、`j` 两层循环且保持 `a[j][i]` 不变，可改善空间局部性。
%%% option: C
循环体中同一组指令被反复执行，体现时间局部性。
%%% option: D
按行连续读取不同数组元素，主要利用数组的时间局部性。
%%% reference
正确选项：B、C。

原内层循环跨行访问，步长为 `32 * 4 = 128` 字节。交换两层循环后 `i` 在内层变化，数组按行连续访问，改善空间局部性。重复执行循环指令体现时间局部性。
