### 14.3（2 分）

有以下两个函数。每次试验都独立地从 `long x = 3` 开始，且计算不溢出。填写相应调用结束后的 `x` 值，均为十进制。

```c
void f(long *p, long *q)
{
    *p += *q;
    *p += *q;
}

void g(long *p, long *q)
{
    *p += 2 * (*q);
}
```

1. `f(&x, &x)` 之后，`x =` {{blank:f}}。（1 分）
2. `g(&x, &x)` 之后，`x =` {{blank:g}}。（1 分）
%%% reference
两空为 `12`、`9`。

`p` 与 `q` 都指向 `x` 时，`f` 先把 `x` 改为 `6`，第二次读取 `*q` 也得到 `6`，结果为 `12`。`g` 的同一条赋值读取原 `x = 3`，得到 `3 + 2 * 3 = 9`，因此不能不加条件地把 `f` 替换为 `g`。
