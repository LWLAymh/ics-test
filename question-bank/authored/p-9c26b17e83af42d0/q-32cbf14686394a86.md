### 16.4（4 分）

阅读以下程序，必要头文件已包含。所有 `fork` 成功，`waitpid` 均正常等待指定子进程；未安装 `SIGCHLD` 处理函数。每次 `printf` 返回前已完成一整行输出，行与行不会交错，忽略输出缓冲的复制或延迟。

```c
int main(void)
{
    int x = 1;
    pid_t p = fork();
    if (p == 0) {
        x += 2;
        printf("A%d\n", x);
    } else {
        pid_t q = fork();
        if (q == 0) {
            x += 4;
            printf("B%d\n", x);
        } else {
            waitpid(p, NULL, 0);
            printf("C%d\n", x);
            waitpid(q, NULL, 0);
            printf("D%d\n", x);
        }
    }
    return 0;
}
```
