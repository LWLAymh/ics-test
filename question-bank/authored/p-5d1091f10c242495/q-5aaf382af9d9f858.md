%%% stem
练习题 9.1 中，若虚拟地址数为 `64K`（`K = 2^10`），虚拟地址位数 `n` 应为多少？该地址空间的最大可能地址是多少？
%%% reference
`64K = 2^16` 个地址，因此 `n = 16`；最大地址为 `2^16 − 1 = 64K − 1`。
%%% option: A
`n = 10`，最大地址 `64K`
%%% option: B
`n = 16`，最大地址 `64K − 1`
%%% option: C
`n = 16`，最大地址 `64K`
%%% option: D
`n = 64`，最大地址 `2^64 − 1`
