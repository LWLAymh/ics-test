```c
union ELE {
  struct {

  }e2;
};
```

3.下面两段清单有故意设置的错误，请逐处定位并给出修正，不预设只有几处错误。（6分）参数n位于 `8(%ebp)`，满足 `n>=1`；参数up位于 `12(%ebp)`，类型为 `union ELE *`。以 `*up` 为第0个节点，按 `e2.next` 连接，链表足够长。要求把第n个节点的 `e1.x` 放入 `%eax`。

```

    movl 8(%edx),%ebp
    movl 12(%ebp),%eax

    jne LOOP

```

%%% part-reference: q-4284650c2063ef72
参考修正如下。按错误指令出现位置计四处；原参考只列三处，漏掉了x86的循环判定错误。
- `movl 8(%edx),%ebp` 应为 `movl 8(%ebp),%edx`（X86 代码）
- x86的 `test %ecx,%edx` 应为 `cmpl %ecx,%edx`（或交换比较操作数），才能在计数到n时结束；按位与的零标志不能代替相等比较。
- `mrmovl 8(%edx),%ebp` 应为 `mrmovl 8(%ebp),%edx`（Y86 代码）
- `test %ecx,%edx` 应为 `subl %ecx,%edx`（Y86 代码）

x86使用递增计数器ecx，Y86使用edx递减计数和常量ecx=1；不能把两套终止条件混用。两段错误清单是本问要找错的对象，题库保留错误语句供作答，不把它们误当可执行的正确参考实现。
