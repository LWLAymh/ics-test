%%% stem
20. 以下哪些转换在给定条件下保持语义，允许编译器进行？（多选）`int i, j, A[N], B[N]` 和 `float m` 均为非volatile局部变量；`N>0` 是常量，A/B为两个独立数组，不是可能别名的指针。索引合法、读值已初始化，整数中间结果均可表示；浮点按binary32最近偶数逐步计算，不使用改变浮点结合性的fast-math。`foo` 是可能有副作用的普通函数。
A.

优化前：
```c
for (j = 0; j < N; j++)
    m += i * N * j;
```

优化后：
```c
int temp = i * N;
for (j = 0; j < N; j++)
    m += temp * j;
```
B.

优化前：
```c
for (j = 0; j < N; j++)
    B[i] *= A[j];
```

优化后：
```c
int temp = B[i];
for (j = 0; j < N; j++)
    temp *= A[j];
B[i] = temp;
```

C.

优化前：
```c
for (j = 0; j < N; j++)
    m = (m + A[j]) + B[j];
```

优化后：
```c
for (j = 0; j < N; j++)
    m = m + (A[j] + B[j]);
```

D.

优化前：
```c
for (j = 0; j < foo(N); j++)
    m++;
```

优化后：
```c
int temp = foo(N);
for (j = 0; j < temp; j++)
    m++;
```
%%% reference
答案：A、B。

A提取循环不变量，保持整数乘法与浮点累加顺序。B中的A/B为两个独立数组，B[i]的中间值无外部观察者，可由temp累积并最终回写；不能套用指针可能别名来排除它。C改变浮点加法顺序，例如 `m=1, A[j]=16777216, B[j]=-16777216` 时，原式舍入后为0，而改写后为1。D可能改变foo调用次数、副作用与返回值。

原卷给A，旧解析虽承认B也安全仍判错；题库已按明确数组声明更正为多选AB。这里只判断语义允许，并不保证任何编译器/优化级别必然选择某种改写。
