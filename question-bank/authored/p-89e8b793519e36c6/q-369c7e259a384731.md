%%% stem
8.  假设某条C语言`switch`语句编译后产生了如下的汇编代码及跳转表：
```
    movl 8(%ebp), %eax
    subl $48, %eax
    cmpl $8, %eax
    ja .L2
    jmp *.L7(, %eax, 4)
```

跳转表：
```
.L7:
.long .L3
.long .L2
.long .L2
.long .L5
.long .L4
.long .L5
.long .L6
.long .L2
.long .L3
```
以 `.L2` 为default目标，字符常量使用ASCII编码。下面哪个值会通过该跳转表进入非default分支？
%%% reference
答案：C
跳转表中字符 `'0'`、`'3'`、`'4'`、`'5'`、`'6'`、`'8'` 对应非default目标，`'1'`、`'2'`、`'7'` 对应default目标。整数1和5小于48，会走越界分支到default。因此只有C的字符 `'3'` 满足。

原题问“源码中哪些case标号出现过”，但显式case也可能与default共用代码，不能由相同目标证明该case从未写过。题库改问汇编能确定的分支行为，不把逆向无法唯一确定的源码细节当唯一答案。
%%% option: A
‘2’, ‘7’
%%% option: B
1
%%% option: C
‘3’
%%% option: D
5
