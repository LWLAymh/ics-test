8.  假设某条C语言`switch`语句编译后产生了如下的汇编代码及跳转表：
```
    movl 8(%ebp), %eax
    subl $48, %eax
    cmpl $8, %eax
    ja .L2
    jmp *.L7(, %eax, 4)
```

跳转表：
```
.L7:
.long .L3
.long .L2
.long .L2
.long .L5
.long .L4
.long .L5
.long .L6
.long .L2
.long .L3
```
