4. 阅读下列代码，回答后面的问题。`A`、`B` 为正整数，采用 32 位 x86 的通常布局：`char` 为 1 字节、`short` 为 2 字节、`int` 和指针为 4 字节，成员自然对齐，未启用结构体压缩打包。

```c
typedef struct {
    short x[A][B];
    int y;
} str1;

typedef struct {
    char array[B];
    int t;
    short s[B];
    int u;
} str2;

void setVal(str1 *p, str2 *q) {
    int v1 = q->t;
    int v2 = q->u;
    p->y = v1 + v2;
}
```

GCC 为 `setVal` 函数主体生成了以下代码：

```asm
    movl 12(%ebp), %eax
    movl 28(%eax), %edx
    addl 8(%eax), %edx
    movl 8(%ebp), %eax
    movl %edx, 44(%eax)
```
请写出 `A` 和 `B` 的值。（6 分）

A = {{blank:value-a}}，B = {{blank:value-b}}
%%% reference
答案：A = 3，B = 7。

汇编先读取 `q` 的地址，取偏移 `28` 和偏移 `8` 处的两个 `int` 相加，再写到 `p` 的偏移 `44` 处。因此 `t`、`u` 的偏移依次为 `8`、`28`，`y` 的偏移为 `44`。

1. `array[B]` 后的 `t` 按 4 字节对齐且偏移为 `8`，所以 `B` 只能是 `5`、`6`、`7`、`8`。
2. `t` 占 4 字节，`s[B]` 从偏移 `12` 开始，占 `2 * B` 字节。之后的 `u` 向上对齐到偏移 `28`，进一步得到 `B` 只能是 `7` 或 `8`。
3. `x[A][B]` 占 `2 * A * B` 字节，之后的 `y` 向上对齐到 `44`。因此 `A * B` 只能是 `21` 或 `22`；结合 `B` 为 `7` 或 `8` 及正整数条件，唯一解为 `A = 3`、`B = 7`。
