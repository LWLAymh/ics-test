%%% stem
4.  关于浮点数，以下说法正确的是
%%% reference
答案：D。A 不成立，例如取 a = +Inf、b = 1、x = −Inf，则 a > b 为真，但 a + x 和 b + x 分别为 NaN 和 −Inf，比较结果不满足 A。IEEE 浮点加法保持单调性；当 a > b 不成立时，给两边加上同一个 x 不会使比较反转为 a + x > b + x。涉及 NaN 时，比较结果为假。关于 B、C，高精度运算也不保证对特定精确结果的舍入误差总小于低精度运算。
%%% option: A
给定任意浮点数a，b和x，如果`a>b`成立（求值为`1`），则一定`a+x>b+x`
成立
%%% option: B
不考虑结果为NaN、Inf或运算过程发生溢出的情况，高精度浮点数一定
得到比低精度浮点数更精确或相同的结果
%%% option: C
不考虑输入为NaN、Inf的情况，高精度浮点数一定得到比低精度浮点数
更精确或相同的结果
%%% option: D
给定任意浮点数a, b和x，如果`a>b`不成立（求值为`0`），则一定`a+x>b+x`
不成立。
