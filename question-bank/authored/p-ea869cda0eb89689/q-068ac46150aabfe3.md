%%% stem
2. For which values can `X` not be equal to `Z` in the code below (circle all that apply)?

Assume 32-bit `int`, IEEE 754 binary32 `float`, and round-to-nearest-even. Consider values for which the conversion back to `int` is representable. “Can” asks whether a range contains values that lose precision, not whether every value in that range does.

> 选项勘误：原卷 B、D 的 large/small 描述与数值示例相反。下列选项以原示例的数值范围为准，明确改写；原卷答案 AD 保留。

```c
int X = CONSTANT;
float Y = X;
int Z = Y;
```
%%% reference
答案：AD
（原卷标注：A&D。）x 为大正数时 int→float 丢精度，x 为绝对值很大的负数时同样丢精度，故 A、D 两种情况下 X 可能不等于 Z。
原卷 B、D 的 large/small 描述与示例不符，题面已明确为相应数值范围。B、C 范围内的小整数都能被 binary32 精确表示，A、D 范围内存在不能精确表示的整数；不能理解成 A、D 范围内所有整数都改变。
%%% option: A
For large positive values of CONSTANT (e.g.,>1,000,000,000)
%%% option: B
For negative values close to zero (`-100 < CONSTANT < 0`)
%%% option: C
For small positive values of CONSTANT (`0 < CONSTANT < 100`)
%%% option: D
For negative values of large magnitude (`CONSTANT < -1,000,000,000`)
%%% option: E
None of the above (i.e., `X==Z` in all of these cases)
