%%% stem
5. How does x86 assembly store the return value when a function is finished?
%%% reference
**答案：B**
%%% option: A
The `ret` instruction stores it in a special `retval` register.
%%% option: B
By convention, it is always in `%eax`.
%%% option: C
It is stored on the stack just above the `(%ebp)` of the callee.
%%% option: D
It is stored on the stack just above all the arguments to the function
