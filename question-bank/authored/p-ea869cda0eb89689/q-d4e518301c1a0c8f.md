%%% stem
3. Conversion from `float` to `int` is a notoriously expensive operation. Not all processors do this in hardware. A clever technique uses the normalization step in double-precision floats. Imagine if you could normalize a non-negative floating-point number so that the low-order significant bit represents $2^0$. Then the significand would be an integer. **(8 pts)**

Assume a `double` where, after taking the exponent into account, the low-order bit represents $2^0$. The “implied leading 1” of the significand represents {{blank:leading-one}}.

Now assume a `double x` is known to satisfy $0\le x<2^{32}$. To force the low-order bit of `x` to represent $2^0$, add {{blank:add-value}}.

After this operation, store the `double` to memory and read {{blank:word-half}} as an unsigned integer to obtain the integer value of the original `double`（填 `Upper 32 bits` 或 `Lower 32 bits`）。

This algorithm rounds {{blank:rounding}}（从 `toward zero`、`up`、`down`、`to the nearest even` 中选择）。

   ***Hints:***

```
double-precision significant has 52 bits
double-precision exponent has 11 bits
double-precision sign-bit is (of course) 1 bit
```
%%% reference
答案：1) “implied leading 1” 代表 $2^{52}$；2) 应当加 $2^{52}$；3) 取回 **Lower 32 bits（低 32 位）**；4) 按 **to the nearest even（向偶数舍入）** 取整。
