%%% stem
12. Consider an `int *a` and an `int n`. If the value of `%ecx` is `a` and the value of `%edx` is `n`, which of the following assembly snippets best corresponds to the C statement `return a[n]`?
%%% reference
**答案：C**
%%% option: A
```asm
    ret (%ecx,%edx,4)
```
%%% option: B
```asm
    leal (%ecx,%edx,4),%eax
    ret
```
%%% option: C
```asm
    mov (%ecx,%edx,4),%eax
    ret
```
%%% option: D
```asm
    mov (%ecx,%edx,1),%eax
    ret
```
