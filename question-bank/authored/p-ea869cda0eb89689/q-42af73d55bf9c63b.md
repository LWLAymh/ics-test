**Problem F – Linking (12 pts)**

For each of the following code snippets, write down all symbols in the resulting object files from
compilation. Write whether it is a weak global, strong global, or local variable, and what section
of the final compiled ELF binary the variable will go into. Fill in the value if you have enough
information to determine the value.

本题沿用教材旧版的 `-fcommon` 链接模型，以“weak global”表示可被强定义覆盖的暂定公共符号；它不是 ELF 的 `STB_WEAK` 绑定。节归属采用通常的 GCC 零初始化放入 `.bss` 的规则。仅列出两个文件中定义的6个源码符号，排除 `printf` 等未定义引用、调试及编译器辅助符号；每个文件按声明顺序填表。值栏填写该目标文件定义本身的初值，暂定定义及函数填 `-`。

   **A.**

```c
/* main.c */
#include <stdio.h>

int x;
int y;
int z = 0;

int main() {
  printf("%x\n", x);
  printf("%x\n", y);
  x = 0xdeadbeef;
  printf("%x\n", x);
  printf("%x\n", y);
  return 0;
}
```

```c
/* foo.c */
short x = 5;
short y = 2;
```

参考答案（保留原卷的教学强弱模型，并勘误零初始化对象的节归属）：

| File | Symbol | Strength / scope | Value | ELF Section |
| --- | --- | --- | --- | --- |
| `Main.o` | X | Weak global | - | .data |
| `Main.o` | Y | Weak global | - | .data |
| `Main.o` | Z | Strong global | 0 | .bss |
| `Main.o` | `Main` | Strong global | - | .text |
| `foo.o` | X | Strong global | 5 | .data |
| `foo.o` | Y | Strong global | 2 | .data |

原卷将显式初始化为0的 `z` 写作 `.data`；通常 GCC 仍将它放入 `.bss`，与是否是强定义无关。可用 `gcc -fcommon -c main.c` 和 `readelf -s main.o` 验证。链接后的 `x`、`y` 由 `foo.o` 的非零强定义提供，故最终位于 `.data`。现代 GCC 默认 `-fno-common`，会使这两个文件的同名定义链接冲突，不能直接用该默认模型套用原答案。
