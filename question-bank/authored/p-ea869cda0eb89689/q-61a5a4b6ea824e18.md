%%% stem
13. What is the C equivalent of `mov 0x10(%rax,%rcx,4), %rdx`? **(2pts)**
%%% reference
答案：C

解析：源操作数读取地址 `rax + rcx*4 + 0x10` 处的内存，再把读取的值写入 `rdx`。这里的 `*` 是解引用或乘法运算符。
%%% option: A
`rdx = rax + rcx + 4 + 10`
%%% option: B
`*(rax + rcx + 4 + 10) = rdx`
%%% option: C
`rdx = *(rax + rcx*4 + 0x10)`
%%% option: D
`rdx = *(rax + rcx + 4 + 0x10)`
