考虑矩阵转置函数：

```c
typedef int array[4][4];
void transpose2(array dst, array src) {
    int i, j;
    for (i = 0; i < 4; i++) {
        for (j = 0; j < 4; j++) {
            dst[j][i] = src[i][j];
        }
    }
}
```

`sizeof(int)==4`。src起始地址为0，dst为64（十进制）。唯一L1数据缓存直接映射、直写、写分配，块16字节，总数据容量32字节，初始为空。内存访问仅有src读与dst写，按源代码读后写执行。

指明每个数组元素访问为命中h或不命中m。每一空按该数组行的列0、1、2、3顺序输入4个字符（可不加空格）；注意dst按 `dst[row][col]` 坐标填写。例如两个数组的[0][0]均为m。
