%%% stem
分析以下代码的高速缓存行为：

```c
int x[2][128];
int i;
int sum = 0;
for (i = 0; i < 128; i++) {
    sum += x[0][i] * x[1][i];
}
```

`sizeof(int)==4`，x从地址0开始按行优先存储。各情况缓存初始为空。内存访问仅有x数组读取，其他变量在寄存器中。
%%% reference
每行512字节，共256次数组元素读取。
%%% part-stem: q-7851d48fd43fa8c7-ABC
填写各情况下的不命中百分比，只填数值。

A. 512字节直接映射缓存，块16字节：{{blank:a}}%。

B. 容量加倍为1024字节，其余同A：{{blank:b}}%。

C. 512字节2路组相联缓存，LRU替换，块16字节：{{blank:c}}%。
%%% part-reference: q-7851d48fd43fa8c7-ABC
A为100%；两行相隔512字节，映射到相同缓存行，交替读取每次冲突。

B为25%；两个数组行可同时驻留，每个16字节块的4次读取中仅首次不命中。

C为25%；相同组有两路，可同时容纳当前的两个块，每4次元素读取仅一次强制不命中。
%%% part-stem: q-7851d48fd43fa8c7-DE
D. 对情况C，增大缓存容量会降低不命中率吗？为什么？

E. 对情况C，增大块大小会降低不命中率吗？为什么？
%%% part-reference: q-7851d48fd43fa8c7-DE
D. 不会。16字节块下当前25%均为首次读块的强制不命中，没有容量或冲突不命中可消除。

E. 通常会。顺序扫描可利用更大的块，例如块增至32字节后，每8个元素一次不命中，降至12.5%。前提是仍能同时保存两条正在访问的行块；本题512字节、2路结构对常规合法块大小满足这一条件。
