游戏屏幕缓冲区为640×480像素，机器有64KB直接映射缓存，每缓存块4字节，写分配。定义如下：

```c
struct pixel {
    char r;
    char g;
    char b;
    char a;
};
struct pixel buffer[480][640];
int i, j;
char *cptr;
int *iptr;
```

`sizeof(char)==1`、`sizeof(int)==4`，像素占4字节，buffer从地址0开始。缓存初始为空。唯一内存访问为buffer元素，i、j、cptr、iptr均在寄存器。

```c
for (j = 0; j < 640; j++) {
    for (i = 0; i < 480; i++) {
        buffer[i][j].r = 0;
        buffer[i][j].g = 0;
        buffer[i][j].b = 0;
        buffer[i][j].a = 0;
    }
}
```

%%% reference
25%。每个像素正好占一个缓存块，每像素的r写首次访问该块而不命中，随后的g、b、a三次写命中。不同列访问不同像素块，所有像素块只在对应4次字段写中使用，因此每4次写恰有一次不命中，共307200/1228800。
