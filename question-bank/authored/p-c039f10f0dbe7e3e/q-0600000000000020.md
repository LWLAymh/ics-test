%%% stem
练习题 6.20。定义`struct algae_position { int x; int y; }; struct algae_position grid[16][16];`。假设`sizeof(int)==4`、`grid`从地址0开始，缓存初始为空；唯一内存访问是`grid`元素，标量变量在寄存器中。缓存块大小`B=16`字节，总大小1024字节，直接映射。

```c
for (i = 0; i < 16; i++) {
    for (j = 0; j < 16; j++) {
        total_x += grid[i][j].x;
        total_y += grid[i][j].y;
    }
}
```

总读取512次，其中128次为冷不命中；不命中率25%。缓存加倍不改变冷不命中率。
