打印CMYK彩色方格，数据定义如下：

```c
struct point_color {
    int c;
    int m;
    int y;
    int k;
};
struct point_color square[16][16];
int i, j;
```

缓存2048字节，直接映射，块32字节，按写分配处理。`sizeof(int)==4`，结构4字段连续排列，square从地址0开始，缓存初始为空。唯一内存访问为square中的元素，i、j在寄存器。

```c
for (i = 0; i < 16; i++) {
    for (j = 0; j < 16; j++) {
        square[i][j].c = 0;
        square[i][j].m = 0;
        square[i][j].y = 1;
        square[i][j].k = 0;
    }
}
```

%%% reference
共16×16×4=1024次写。每个32字节块包含2个点、8个int，顺序遍历每块只有第一次写不命中。共4096/32=128次不命中，不命中率128/1024=12.5%。
