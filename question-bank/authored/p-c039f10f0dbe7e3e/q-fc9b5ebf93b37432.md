对总数据容量128字节的缓存重复6.34。完整程序与其他条件如下：

```c
typedef int array[4][4];
void transpose2(array dst, array src) {
    int i, j;
    for (i = 0; i < 4; i++) {
        for (j = 0; j < 4; j++) {
            dst[j][i] = src[i][j];
        }
    }
}
```

`sizeof(int)==4`，src从地址0开始，dst从地址64开始。唯一L1数据缓存直接映射、直写、写分配，块16字节，初始为空。唯一内存访问为src读与dst写，每步读后写。

各空填该数组行的列0至3的命中h/不命中m序列，共4个字符，可不加空格；dst按 `dst[row][col]` 坐标填写。
