练习题 6.10：考虑下面 `dotprod` 函数及其缓存。`float` 为4字节，块大小 `B=16` 字节，缓存为直接映射、两个组、总容量32字节；`x` 从地址0开始，`y` 紧跟在 `x` 后（原始地址32）。在 `x` 末尾增加一个块大小的填充（定义为 `float x[12]`），因此 `y` 从地址48开始。假设 `sum` 保存在寄存器中。所有对 `x` 和 `y` 的引用命中率是多少？{{blank:hit-rate}}

```c
float dotprod(float x[8], float y[8])
{
    float sum = 0.0;
    int i;
    for (i = 0; i < 8; i++)
        sum += x[i] * y[i];
    return sum;
}
```
%%% reference
命中率是 `3/4 = 75%`。`x[0]` 的首次访问不命中，载入 `x[0..3]`；之后 `x[1..3]` 命中。填充使 `y[0..3]` 映射到另一组，因此 `y[0]` 首次不命中，`y[1..3]` 命中。第二组元素 `x[4..7]` 与 `y[4..7]` 的访问同理，各有一次不命中和三次命中，总计 12 次命中/16 次引用。
