一个2 MB（$2^{21}$ 字节）文件由512字节逻辑块组成。磁盘特性如下：

| 参数 | 值 |
| --- | --- |
| 转速 | 15000 RPM |
| 平均寻道时间 | 4 ms |
| 平均扇区数/磁道 | 1000 |
| 盘面数 | 8 |
| 扇区大小 | 512 字节 |

程序按逻辑块顺序逐块读取。首次定位时间等于平均寻道时间加平均旋转等待时间。按教材理想估计模型，连续扇区传输忽略额外换头或换道开销。结果填至小数点后3位。

A. 在所有可能的逻辑块到扇区映射中，最好情况下的读取时间为 {{blank:best}} ms。

B. 块随机映射到磁盘扇区时，估计读取时间为 {{blank:random}} ms。
%%% reference
共 $2^{21}/512=4096$ 块。每转4 ms，平均等待2 ms，单扇区传输0.004 ms。

A. 连续布局仅首次付出定位开销，$4+2+4096\times0.004=22.384$ ms。

B. 随机布局每块都付出平均定位开销，$4096(4+2+0.004)=24592.384$ ms。盘面数量不使单个请求的传输率自动乘8。
