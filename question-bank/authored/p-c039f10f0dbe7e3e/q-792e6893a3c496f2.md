分析以下3个求和函数的缓存不命中率。`sizeof(int)==4`，4KB直接映射缓存，块16字节。数组a从地址 `0x08000000` 开始；内存访问仅有数组数据，循环索引与sum在寄存器。各次独立运行按初始空缓存估计。

```c
typedef int array_t[N][N];
int sumA(array_t a) {
    int i, j;
    int sum = 0;
    for (i = 0; i < N; i++)
        for (j = 0; j < N; j++) {
            sum += a[i][j];
        }
    return sum;
}
int sumB(array_t a) {
    int i, j;
    int sum = 0;
    for (j = 0; j < N; j++)
        for (i = 0; i < N; i++) {
            sum += a[i][j];
        }
    return sum;
}
int sumC(array_t a) {
    int i, j;
    int sum = 0;
    for (j = 0; j < N; j += 2)
        for (i = 0; i < N; i += 2) {
            sum += (a[i][j] + a[i+1][j]
                    + a[i][j+1] + a[i+1][j+1]);
        }
    return sum;
}
```

sumA按行连续扫描，每块4个整数，一次不命中。N=64时sumB跨256字节，循环中仅使用16组，64行争用这些组，无法保留到下一列，因此每次不命中；sumC每次读取相邻两列，4个读取有2次不命中。N=60时行跨度240字节（15块），有效分散组索引，列间可保留当前块，三种函数都接近仅强制不命中的25%。按给定逐次访问模型，N=60的三者均为900/3600。
