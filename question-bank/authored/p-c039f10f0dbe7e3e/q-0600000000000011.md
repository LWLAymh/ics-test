%%% stem
练习题 6.11：设想一种缓存用地址的高 `s` 位作为组索引，因此连续内存块片会映射到同一高速缓存组。

A. 每个这样的连续数组片中有多少个块？

B. 考虑如下代码运行在缓存 `(S,E,B,m)=(512,1,32,32)` 的系统中。在任意时刻，存储在缓存中的数组块最大数量是多少？

```c
int array[4096];
for (i = 0; i < 4096; i++)
    sum += array[i];
```
%%% reference
A. 每个连续数组片包含 `2^t` 个块，其中 `t` 是标记位数。

B. `t=18`，所以连续的 `2^18` 个块都会映射到同一组。数组总大小为 `4096×4` 字节，即512个32字节块，全部映射到组0，因此任意时刻缓存至多保存一个数组块。
