练习题 6.18。紧密循环计算256个海藻的位置，定义如下：

```c
struct algae_position { int x; int y; };
struct algae_position grid[16][16];
int total_x = 0, total_y = 0;
int i, j;
```

假设`sizeof(int)==4`，`grid`从地址0开始，缓存初始为空；唯一内存访问是`grid`元素，`i`、`j`、`total_x`、`total_y`均在寄存器中。缓存块大小`B=16`字节，总大小1024字节，直接映射。

```c
for (i = 0; i < 16; i++)
    for (j = 0; j < 16; j++) total_x += grid[i][j].x;
for (i = 0; i < 16; i++)
    for (j = 0; j < 16; j++) total_y += grid[i][j].y;
```
