沿用6.41条件：64KB直接映射缓存，每块4字节，写分配，初始为空。char为1字节，int为4字节；buffer起始地址0，唯一内存访问为buffer，指针在寄存器。

```c
struct pixel {
    char r;
    char g;
    char b;
    char a;
};
struct pixel buffer[480][640];
char *cptr = (char *)buffer;
for (; cptr < (((char *)buffer) + 640 * 480 * 4); cptr++)
    *cptr = 0;
```
