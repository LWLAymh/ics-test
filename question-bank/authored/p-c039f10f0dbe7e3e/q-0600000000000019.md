%%% stem
练习题 6.19。定义`struct algae_position { int x; int y; }; struct algae_position grid[16][16];`。假设`sizeof(int)==4`、`grid`从地址0开始，缓存初始为空；唯一内存访问是`grid`元素，标量变量在寄存器中。缓存块大小`B=16`字节，总大小1024字节，直接映射。

```c
for (i = 0; i < 16; i++) {
    for (j = 0; j < 16; j++) {
        total_x += grid[j][i].x;
        total_y += grid[j][i].y;
    }
}
```
%%% reference
总读取512次，未加倍缓存时命中率50%；缓存加倍至2048字节时工作集可容纳，未命中率为25%。
%%% part-stem: q-0600000000000019-a
A. 读总数是多少？
%%% part-reference: q-0600000000000019-a
512次读取。
%%% part-stem: q-0600000000000019-b
B. 高速缓存不命中的读总数是多少？
%%% part-reference: q-0600000000000019-b
256次不命中。
%%% part-stem: q-0600000000000019-c
C. 不命中率是多少？
%%% part-reference: q-0600000000000019-c
`256/512 = 50%`。
%%% part-stem: q-0600000000000019-d
D. 如果高速缓存有两倍大，不命中率是多少？
%%% part-reference: q-0600000000000019-d
整个`grid`可容纳在缓存中，只有128个冷不命中，因此不命中率`128/512 = 25%`。
