%%% stem
4. 假定所有函数均使用 `%rbp` 寄存器描述栈帧，进入时一定以 `pushq %rbp; movq %rsp, %rbp` 开始，退出前一定以 `leaveq; retq` 结束。

编译器内置函数 `__builtin_return_address(1)` 获取调用当前函数的函数的返回地址。例如：

```c
long foo(void)
{
    return (long)__builtin_return_address(1);
}
```

函数 `bar()` 调用 `foo()` 时，`foo()` 的返回值是 `bar()` 的返回地址，即 `bar()` 调用完成后控制流转向的地址。保证两者都不是内联函数，则编译 `foo()` 生成的汇编指令可能是
%%% reference
答案：D。在 `foo()` 中读取 `0(%rbp)` 可获得函数开头保存的 `%rbp`，也就是外层函数 `bar()` 的栈帧地址；向上偏移 8 字节即可读取 `bar()` 的返回地址。
%%% option: A
```asm
foo:
    pushq %rbp
    movq %rsp, %rbp
    movq 8(%rbp), %rax
    leaveq
    retq
```
%%% option: B
```asm
foo:
    pushq %rbp
    movq %rsp, %rbp
    movq 0(%rbp), %rax
    movq 0(%rax), %rax
    leaveq
    retq
```
%%% option: C
```asm
foo:
    pushq %rbp
    movq %rsp, %rbp
    movq 0(%rbp), %rax
    movq -8(%rax), %rax
    leaveq
    retq
```
%%% option: D
```asm
foo:
    pushq %rbp
    movq %rsp, %rbp
    movq 0(%rbp), %rax
    movq 8(%rax), %rax
    leaveq
    retq
```
