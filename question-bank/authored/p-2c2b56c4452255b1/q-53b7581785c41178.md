第三题. 请结合教材第七章“链接”的有关知识回答问题(10分)
有头文件 `hd.h` 和两个 C 源文件 `f1.c`、`f2.c`，使用 `gcc -O0 -c f1.c f2.c`、`gcc f1.o f2.o` 得到普通、未剥除符号的 ELF 可执行文件 `a.out`。不使用LTO。Part A 指 `.symtab`，按标识符所对应的存储对象判断，允许编译器为静态局部对象生成 `seed.0` 等修饰名；不是要求链接名称必须逐字等于C标识符，也不是查询 `.dynsym`。本题无需运行计算循环。

`hd.h`：

```c
typedef struct {
    double x;
    double y;
} Point;
void rand_point(Point *);
int if_inside(Point *);
```

`f1.c`：

```c
#include "hd.h"
#include <stdio.h>
const int total = 1 << 30;
static int count = 0;
static Point pnt;
int iter;
int main() {
    for (iter = 0; iter < total; ++iter) {
        rand_point(&pnt);
        count += if_inside(&pnt);
    }
    printf("Integral on [0,1] is %lf.\n",
        1.0 * count / total);
}
```

`f2.c`：

```c
#include "hd.h"
#include <stdlib.h>
#include <time.h>
void rand_point(Point *ptr) {
    static int seed = 0;
    if (!seed) {
        srand((unsigned)time(NULL));
        seed = 1;
    }
    ptr->x = 1.0 * rand() / RAND_MAX;
    ptr->y = 1.0 * rand() / RAND_MAX;
}
int if_inside(Point *p) {
    return 1 / (1 + p->x) >= p->y;
}
```

答案：
Part A.
| 符号名 | `iter` | `pnt` | `Point` | `total` | `seed` |
| --- | --- | --- | --- | --- | --- |
| 在符号表中？ | 是 | 是 | 否 | 是 | 是 |
| 定义所在节 | .bss | .bss | / | .rodata | .bss |

勘误：原表把 `seed` 写为没有条目，但它是具有静态存储期的局部对象，在无优化且未strip的模型下可有 `seed.0` 等局部符号，零初始化存储放在 `.bss`。本题明确按“对应对象”而非未修饰的精确名字判断。原纸卷对 `total` 曾宽松接受 `.data`；当前明确的常规 GCC 只读常量布局按 `.rodata` 核对。

Part B. pnt；`0x10`；d1 00 00 00

该重定位用于随后传给 `if_inside` 的 `&pnt`，加数为对象偏移减4，故对象偏移为 `0xc+4=0x10`。另一调用相差函数间距 `0x74`，而调用位置相差 `0x0c`，位移为 `0x69+0x74-0x0c=0xd1`，按小端写入4字节。

Part C. D（_start）；用户态
