%%% stem
6.在Y86-64 PIPE处理器中（不考虑数据前递），以下哪个指令序列会造成数据冒险？
%%% reference
答案：D。答案：D。要想不引起数据冒险，需要改变数据的指令在使用数据的指令进入译码阶段时已经完成写回阶段。因此至少需要插入3个nop指令。

书本P295
%%% option: A
```asm
    irmovq $10, %rdx
    addq %rdx, %rax
```
%%% option: B
```asm
    irmovq $10, %rdx
    nop
    addq %rdx, %rax
```
%%% option: C
```asm
    irmovq $10, %rdx
    nop
    nop
    addq %rdx, %rax
```
%%% option: D
以上三个选项都会引发数据冒险
