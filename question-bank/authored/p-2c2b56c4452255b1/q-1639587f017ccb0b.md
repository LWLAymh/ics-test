4.  下列关于全球IP因特网的说法中，正确的是
%%% reference
答案：D

（原文选项为 Word 自动编号 1.–4.，答案键用字母，故按位置还原为 A–D。）

依据：A 网络字节顺序是大端法；B 由 DNS 负责维护域名集合和 IP 地址集合的映射关系；C 一个域名也可以被映射到多个 IP 地址；D 正确。
%%% option: A
TCP/IP协议规定网络字节顺序取决于不同主机的字节顺序，从而方便主机和网络之间收发数据
%%% option: B
域名集合和IP地址集合的映射关系目前由http来维护
%%% option: C
多个域名可以映射到同一个IP地址，但一个域名不可以映射到多个IP地址
%%% option: D
从内核的角度来看，套接字是通信的一个端点；从用户程序的角度来看，套接字是一个有相应描述符的打开文件
