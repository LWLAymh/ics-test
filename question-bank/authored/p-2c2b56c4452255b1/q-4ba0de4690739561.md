2.现定义了如下变量：

```c
int x, y, z;
float fx, fy, fz;
```

则以下表达式不恒为真的是（其中fx,fy均不为无穷或非数）：
%%% reference
答案：D。大数吃小数。
%%% option: A
`x * y == y * x`
%%% option: B
`(x + y) * z == x * z + y * z`
%%% option: C
`fx + fy == fy + fx`
%%% option: D
`(fx + fy) * fz == fx * fz + fy * fz`
