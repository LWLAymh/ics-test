%%% stem
1. 现定义了如下变量：
```
int x, y, z;
float fx, fy, fz;
```
则以下表达式不恒为真的是：
（其中fx,fy均不为无穷或非数，NaN和`int`类型溢出按照模运算处理）
%%% reference
答案：D
%%% option: A
`x * y == y * x`
%%% option: B
`(x + y) * z == x * z + y * z`
%%% option: C
`fx + fy == fy + fx`
%%% option: D
`(fx + fy) * fz == fx * fz + fy * fz`
