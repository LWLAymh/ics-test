1.请阅读以下代码

```c
int main(){
    int x = 0;
    float y = 0.0;
    while((y - x < 1) && (y - x > -1)){
        x += 1;
        y += 1;
    }
    printf("%d %f\n", x, y);
}
```

问最终的输出为：

（提示1：我们这里认为`int`型变量与`float`型变量运算会把`int`型转化为`float`型再进行运算）

（提示2：$2^{24} = 16777216$）

（提示3：本题中的舍入方式为向偶数舍入）
%%% reference
答案：B。`y` 达到16777216后再加1会按最近偶数规则舍入回原值。`x=16777217` 转成 `float` 仍舍入到16777216，此时差为0；直到 `x=16777218` 时，差才变为-2，循环结束。因此不能简单说成整数 `x` 与 `y` 第一次数学上不相等就结束。
