一 不定项选择题（上）（39分）
1. 观察下面的C程序代码：
```c
int x = -20;
unsigned u = (unsigned)x;
unsigned v = u + 50u;
```
下列说法哪些正确？
%%% reference
答案：A, B, D, E
解析：（`x` 与 `u` 比较时会把 `x` 转成无符号；u+50 发生模 `2^{32}` 回绕）
%%% option: A
`u` 的十六进制表示为 `0xFFFFFFEC`
%%% option: B
`v` 的值为 `30`
%%% option: C
表达式 `(x < u)` 的值为 `1`
%%% option: D
表达式 `(x == u)` 的值为 `1`
%%% option: E
表达式 `(v < u)` 的值为 `1`
