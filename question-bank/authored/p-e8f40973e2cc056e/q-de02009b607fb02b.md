%%% stem
2. 对任意非负 int x，执行：
```c
float f = (float)x;
int y = (int)f;
```
下列说法哪些正确？
（注：`float` 的有效精度为 24 位；$2^{24}=16777216$）
%%% reference
答案：A, B, D
解析：（`float` 只有 24 位有效精度；超过 `2^{24}` 后相邻可表示整数间隔变大，可能向上舍入）
%%% option: A
若 `0 <= x <= 16777216`，则一定有 `y == x`
%%% option: B
若 `x == 16777217`，则一定有 `y == 16777216`
%%% option: C
对任意 `x`，一定有 `y == x`
%%% option: D
存在某个 `x` 使得 `y > x`
%%% option: E
若 `x` 为偶数，则一定有 `y == x`
