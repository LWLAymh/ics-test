%%% stem
5. 观察下面的汇编代码：
```asm
    movq $0x12345678FFFFFFFF, %rax
    movq $0x0000000000000001, %rcx
    addl %ecx, %eax
```
下列哪些说法正确？
%%% reference
答案：ACD
解析：`addl` 是 32 位加法：`%eax=0xFFFFFFFF + 1 -> 0x00000000`（低 32 位回绕）。写 `%eax` 会把 `%rax` 的高 32 位清零，所以 `%rax` 变为全 0。回绕产生进位所以 `CF=1`；结果为 0 所以 `ZF=1`；有符号角度是 `-1 + 1 = 0` 不溢出，`OF=0`。
%%% option: A
执行后 `%rax == 0x0000000000000000`
%%% option: B
执行后 `%rax == 0x1234567800000000`
%%% option: C
执行后 `CF=1`
%%% option: D
执行后 `ZF=1`
%%% option: E
执行后 `OF=1`
