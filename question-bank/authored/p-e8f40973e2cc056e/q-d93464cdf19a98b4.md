%%% stem
19. 观察下面的 C 程序代码。除代码中的两次 `raise` 外，不考虑任何外部 `SIGINT` 或其他信号干扰；所有调用均成功：

```c
volatile sig_atomic_t count = 0;

void h(int sig) {
    count++;
}

int main(void) {
    sigset_t m;
    sigemptyset(&m);
    sigaddset(&m, SIGINT);
    Signal(SIGINT, h);
    sigprocmask(SIG_BLOCK, &m, NULL);
    raise(SIGINT);  // raise() 向当前进程发送指定信号
    raise(SIGINT);
    sigprocmask(SIG_UNBLOCK, &m, NULL);
    printf("%d\n", (int)count);
}
```

该程序正常执行完，下列说法哪些正确？
%%% reference
答案：B

阻塞期间连续两次 `raise(SIGINT)` 只留下一个待处理的标准 `SIGINT`；解除阻塞后处理函数执行一次，故B正确。网页已将“不考虑外部信号”的前提写入题面，而不只把它隐含在答案中。旧题库文字曾称“答案册”，本次没有据此新增官方答案认证。

`count` 一定为 0
%%% option: B
`count` 一定为 1
%%% option: C
`count` 可能为 2

%%% option: E
