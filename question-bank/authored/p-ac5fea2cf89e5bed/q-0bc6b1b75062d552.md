%%% stem
7、将下面两个文件分别编译，再以普通链接方式组成一个可执行文件，会出现什么结果？这里已将原卷弯引号与遗漏的声明修正，讨论正常编译后的符号解析，不考虑允许多重定义的特殊链接选项。
```c
/* main.c */
void foo(void);
int i=0;
int main()
{
  foo();
  return 0;
}
```

```c
/* foo.c */
#include <stdio.h>
int i=1;
void foo()
{
  printf("%d", i);
}
```
%%% reference
答案：B。`int i=0` 和 `int i=1` 都是强定义，即使零初始化对象通常放在 `.bss`，也不会因此变成弱定义。两个目标文件提供同名强定义，普通链接报多重定义错误。原卷因弯引号曾允许A；当前已更正引号和必要声明，不再按排印错误判“编译失败”。
