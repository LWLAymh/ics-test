%%% stem
19、按POSIX线程创建返回约定，允许线程创建失败或发生任意非实时调度延迟，不把 `sleep(1)` 当成等待子线程完成的同步操作。假设标准输出正常，以下代码最终可能产生哪些输出？（多选）
```c
#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>

void *th_f(void *arg) {
    printf("Hello World");
    pthread_exit(NULL);
}
int main(void) {
    pthread_t tid;
    int st = pthread_create(&tid, NULL, th_f, NULL);
    if (st < 0) {  /* 故意保留原题的错误检查，供分析 */
        printf("Oops, I can not create thread\n");
        exit(-1);
    }
    sleep(1);
    exit(0);
}
```
%%% reference
答案：C、D。

`pthread_create` 成功返回0，失败返回错误码，不用 `-1` 表示失败；原程序的 `st < 0` 检查不能捕获通常的创建失败，因此A/B中的错误消息不会由这条分支打印。成功创建且新线程执行完 `printf` 时输出C；创建失败，或新线程尚未运行主线程就 `exit` 时可输出D。

原卷只给C，暗含创建成功且及时调度。题库保持原错误检查作为考点，改为询问所有可能输出；正确的错误检查应为 `st != 0`，等待完成应使用 `pthread_join`。见 [pthread_create返回值与调度说明](https://man7.org/linux/man-pages/man3/pthread_create.3.html)。
