第二题（10分）
在本题中，`int`和`unsigned`均为32位。`int`用补码表示，算术右移。`float`为32位IEEE754标准，`double`为64位IEEE754标准。
1. （2 points）生成任意`int`类型的`x`，然后将它转换为`unsigned`类型：
```c
int x = random();
unsigned ux = (unsigned) x;
```
对于以下每个C语言表达式，判断其值是否恒为1。如果是，圈出Y；否则圈出N。

| 表达式 | 恒为1？ |
| --- | --- |
| `(x >= 0) \|\| (x < ux)` | {{blank:q1a}} |
| `((x >> 1) << 1) <= x` | {{blank:q1b}} |

2. （2 point）补全函数 `nlz`，计算`unsigned`类型数据的二进制表示中的前导零个数（提示：填写数字）：
```c
int nlz(unsigned x) {
    double w = 0.5;
    double y = (double)x + w;
    long long z;
    memcpy(&z, &y, sizeof(y));
    return {{blank:q2a}} - (z >> {{blank:q2b}});
}
```
3. （2 point）上式中`w`的取值并不唯一。判断以下哪个/哪些数字也符合`w`的要求：{{blank:q3}}

(a) 0.2　(b) 0.3　(c) 0.9　(d) 1.2

4. （4 points）下面所示的 `strlen_x` 是字符串求长度函数在大端序电脑中的一种实现，`nlz`函数的意义如前所述：
```c
int func_x(unsigned x) {
    unsigned u = 0x7F7F7F7F;
    unsigned y = (x & u) + u;
    y = ~(y | x | u);
    return nlz(y) >> 3;
}

size_t strlen_x(const char *s) {
    size_t t, n = 0;
    const unsigned *si = (const unsigned *)s;
    while ((t = func_x(*si++)) == 4) {
        n += t;
    }
    return n + t;
}
```
不改变 `strlen_x` 的实现，修改 `func_x` 以使它适用于小端序电脑（仅使用常数、算术/逻辑运算符和已定义变量）：
```c
int func_x(unsigned x) {
    unsigned u = 0x7F7F7F7F;
    unsigned y = (x & u) + u;
    y = ~(y | x | u);
    return ({{blank:q4a}} - nlz(({{blank:q4b}}) & (y - 1))) >> 3;
}
```
%%% reference
答案：
1. 第一项N（例如`x=-1`），第二项Y（算术右移向负无穷取整）。
2. 填1054和52，即 `32 - 1 - ((z >> 52) - 1023)`。
3. `w`的取值范围为[0.5, 1)，因此选择(c) 0.9。
4. 大端实现从最高有效字节到最低有效字节寻找第一个零字节；小端实现应从最低有效字节开始。填入32和`~y`，得到 `return (32 - nlz(~y & (y - 1))) >> 3;`。
