%%% stem
5.  以下代码的输出结果是
```c
union {
    double d;
    struct {
        int i;
        char c[4];
    } s;
} u;
u.d = 1;
printf("%d\n", u.s.c[2]);
```
%%% reference
答案：ABC。

修订说明：A、B、C 均可成立，原题未限定字节序，也未规定 `char` 是否为有符号类型。
  题目未说明大小端，若为大端法，选择A。若为小端法，`u.s.c[2]`为(11110000)2，
由于`char`在不同的编译器上会被实现成signed char或unsigned char，因此扩
展为`int`时-16和240均有可能，B，C均正确。
