%%% stem
2.  在采用小端法存储机器上运行下面的代码，输出的结果将会是？
（`int`，`unsigned` 为32位长，`short`为16位长，0~9的ASCII码分别是`0x30~0x39`）
```c
char *s = "2018";
int *p1 = (int *)s;
short s1 = (*p1)>>12;
unsigned u1 = (unsigned) s1;
printf("0x%x\n",u1);
```
%%% reference
答案：C
本题考查大小端存储，以及整数类型转化。字符串在存储时不区分大小端，前面的
字符存储在低地址，而在被转化成整型的时候低地址被视为低位，因此*p1 为
`0x38313032`，`s1`为`0x8313`。在由`short`转化为`unsigned`的时候，我们要先改变大
小，之后完成有符号到无符号的转换，因此`u1`为`0xffff8313`。
