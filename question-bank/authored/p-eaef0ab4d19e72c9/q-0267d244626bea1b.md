第六题（15分）
在五级 Y86-32 PIPE 教学模型上运行以下代码。统计从首条 F 开始，到最后一条后续 `irmovl` 完成 W 为止；`N >= 1`，访存地址有效。

```asm
.L1:
    mrmovl 0(%eax), %ebx
    addl %ebx, %ecx
    addl %ecx, %eax
    xorl %ecx, %edx
    jne .L1
    irmovl $1, %eax
    irmovl $1, %eax
```
1) 循环执行 N 遍后退出，不采用任何数据前递，包括关闭 W→D 旁路。采用原卷后续勘误的时序：D 读操作看不到该周期末 W 的写入，到下一周期才可读到，因此紧邻 RAW 停顿 3 周期。分支每次预测正确，访存均命中且用 1 周期。请计算总周期数，在每空填一个数字。
N * {{blank:q1a}} + {{blank:q1b}}

2)  假设上述代码一共循环执行了 N 次后跳出循环，采用数据前递（data
forwarding）,分支每次都预测跳转（`taken`），访存每次都命中缓存，命中缓存
时访存需要1个周期。请问共需执行多少个周期？
在下面空格处，各填入一个数字。
N * {{blank:q2a}} + {{blank:q2b}}

3)  假设上述代码一共循环执行了N次后跳出循环（N为偶数），采用数据前递（data
forwarding）,分支每次都预测不跳转（`not taken`），数据访存时缓存命中率为
50%，指令访存全部命中缓存，命中缓存时访存需要1个周期，未命中缓存时访存需要3个周期。请问共需执行多少个周期？
在下面空格处，各填入一个数字。
N * {{blank:q3a}} + {{blank:q3b}}
%%% reference
1) `12 * N + 5`。原答案区保留了 `11 * N + 6` 和后续修订的 `12 * N + 5`；在本题明确的读写时序下采用后者：`4 + (N-1)*(5+3+3+1) + (5+3+3) + 2`。紧邻 load-use 和 ALU RAW 各停 3 周期，循环回边对 `%eax` 的依赖再停 1 周期，最后一轮没有该回边停顿。若采用不同寄存器文件同周期读写约定，不能直接照搬此系数。

2) `6 * N + 8`：`4 + N*(5+1) + 2 + 2`。每轮一次 load-use 停顿，最后一次预测错误罚 2 周期，另有流水线填充及两条后续指令。

3) `9 * N + 4`：`4 + (N/2)*(5+1+2) + (N/2)*(5+3+2) + 2 - 2`。命中/未命中各 N/2 次，load-use 加内存等待分别为 1/3 周期；前 N-1 次分支预测错误各罚 2 周期，最后一次预测正确。
