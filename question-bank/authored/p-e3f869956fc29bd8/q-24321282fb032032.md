### 1. 页表占用空间（2 分）

在进行地址翻译的过程中，操作系统需要借助页表（Page Table）。考虑一个 32 位系统，页大小为 4 KB，页表项（Page Table Entry）大小为 4 字节（Byte）。如果不使用多级页表，常驻内存的页表一共需要 {{blank:single-level-pages}} 页。

### 2. 地址翻译（6 分）

IA-32 体系采用小端法和二级页表。两级页表大小相同，页大小均为 4 KB，结构也相同。TLB 采用直接映射。TLB 和页表项的低 7 位含义如下（位 0 为最低位）；位 7–11 均为 0 且不会改变。低位标志值 `0x27` 表示可读写。

| 位 | 标志 | 含义（值为 1 时） |
| --- | --- | --- |
| 6 | D | 脏页，已写入 |
| 5 | A | 已访问 |
| 4 | CD | 禁用缓存 |
| 3 | WT | 写直达；为 0 时写回 |
| 2 | U | 用户态可访问 |
| 1 | W | 可写 |
| 0 | P | 页存在 |

### 3. 独立地址空间（2 分）

本学期的 fork bomb 作业中，大家曾用 `fork` 逼近系统的进程数量上限。请阅读下面的类似程序并填空。

```c
#include <stdio.h>
#include <sys/wait.h>
#include <unistd.h>
#define N 4
int main() {
    volatile int pid, cnt = 1;
    for (int i = 0; i < N; i++) {
        if ((pid = fork()) > 0) {
            cnt++;
        }
    }
    while (wait(NULL) > 0);
    return 0;
}
```
整个过程中，变量 `cnt` 最大值是 {{blank:max-cnt}}。假设所有数据均已在内存中，且 `pid` 和 `cnt` 位于同一物理页。从第一个进程开始执行 `for` 语句起，此过程对 `cnt` 的操作至少会导致页表中 {{blank:modified-pages}} 个虚拟页对应的物理页被修改。
%%% reference
答案：
1：1024， 5
2：第一次写入地址 `0xD7416560`：TLB 索引 6，写后该项内容为 `0x00A23067`；TLB 命中，因此不访问二级页表，物理地址为 `0x00A23560`。第二次写入地址 `0x0401369B`：TLB 索引 3，写后该项内容为 `0x00BA4067`；二级页表项地址为 `0x29DE404C`，物理地址为 `0x00BA469B`。
3：5，15
