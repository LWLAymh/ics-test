%%% stem
4.  下列关于链接技术的描述，错误的是
%%% reference
答案：A。链接器并不总能发现跨翻译单元的 C 类型不一致等问题，不能保证每种不恰当定义都被报告。

原卷 B 把 COMMON 暂定定义笼统称为“弱符号”；真正的 ELF `STB_WEAK` 定义不存在按对象大小统一选最大者的普遍规则。这里显式把 B 限定为传统 `-fcommon` 下的 COMMON 合并，避免原题另有一个错误项。现代 GCC 默认 `-fno-common` 时不适用此规则。
%%% option: A
在 Linux 系统中，对程序中全局符号的任何不恰当定义，都一定会在链接时报告。
%%% option: B
在启用 `-fcommon` 的传统 ELF 链接模型中，若多个同名 COMMON 暂定定义需要合并且没有强定义，则按其中最大的存储大小分配。
%%% option: C
编译时打桩（interpositioning）需要能够访问程序的源代码，链接时打桩需
要能够访问程序的可重定位对象文件，运行时打桩只需要能够访问可执行目标
文件。
%%% option: D
链接器的两个主要任务是符号解析和重定位。符号解析将目标文件中的全局符
号都绑定到唯一的定义，重定位确定每个符号的最终内存地址，并修改对那些
目标的引用。
