%%% stem
2.  有如下结构定义和程序片段
```
struct A
{
    char c;
    int i;
    double d;
    int array[10];
};
struct B
{
    int array[10];

    double d;
    char c;
    int i;
};
void foo(struct A *pa, struct B *pb, int index)
{
    pb->i = pa->array[index];
}
```
 在Linux下使用GCC编译器，仅采用-O2选项，上述代码对应的汇编语言是：（将
选项依次填入空格内）
```
 movslq %edx, %rdx
 movl __(%rdi,%rdx,__), %eax
 movl %eax, __(%rsi)
```
