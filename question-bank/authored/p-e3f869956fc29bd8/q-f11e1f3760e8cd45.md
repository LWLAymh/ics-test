1.  在如下的代码中，下列关于局部性的说法正确的是：

```c
int add (int *a, int n){
  int sum = 0;
  for (int i = 0; i < n; ++i)
    sum += a[i];
  return sum;
}
```

答案：B.

%%% option: B

%%% option: C

%%% option: D
