6. 在一个 `int` 类型为 32 位补码表示的机器上运行程序。`float` 类型使用 32 位 IEEE 格式，`double` 类型使用 64 位 IEEE 格式，且机器上没有 80 位扩展精度。以下 C 代码产生随机整数 `x`、`y`、`z`，并把它们转换成 `double` 类型：

```c
int x = random();
int y = random();
int z = random();
double dx = (double) x;
double dy = (double) y;
double dz = (double) z;
```

对于下列每个 C 表达式，指出它是否总是为 True。若为“否”，可在查看答案后阅读说明。

**A.** `(float) x == (float) dx`

答案：A
%%% part-option: q-1638b3fc06b77cb0 A
是
%%% part-option: q-1638b3fc06b77cb0 B
否

%%% part-reference: q-87db868e0bfc837e

%%% part-option: q-87db868e0bfc837e A

%%% part-option: q-87db868e0bfc837e B

**C.** `(dx * dy) * dz == dx * (dy * dz)`
%%% part-reference: q-e79ccb5c1591b9f9
答案：B

两个 32 位整数的乘积可能需要超过 53 位有效数字，因而中间乘法会发生舍入；不同结合次序的中间舍入结果不一定相同。

%%% part-option: q-e79ccb5c1591b9f9 B

**D.** `dx / dx == dz / dz`
%%% part-reference: q-c6f39a9fc14b2643
答案：B

当 `x` 或 `z` 为 0 时，对应的 `0.0 / 0.0` 产生 NaN；NaN 与任何值（包括自身）比较都不相等。
