21. 考虑下面的代码，`A` 和 `B` 是用 `#define` 定义的常数：

```c
typedef struct {
    int x[A][B]; /* Unknown constants A and B */
    long y;
} str1;
typedef struct {
    char array[B];
    int t;
    short s[A];
    long u;
} str2;
void setVal(str1 *p, str2 *q) {
    long v1 = q->t;
    long v2 = q->u;
    p->y = v1 + v2;
}
```
GCC 为 `setVal` 产生如下汇编代码（x86-64 System V 调用约定）：
```asm
# p in %rdi, q in %rsi
setVal:
    movslq 8(%rsi), %rax
    addq 32(%rsi), %rax
    movq %rax, 184(%rdi)
    ret
```

求 `A` 和 `B` 的值是多少？
