16. 以下两组对应的 C 语言代码和汇编语言代码：

```c
void multstore(long x, long y, long *dest)
{
    long t = mult2(x, y);
    *dest = t;
}
```

```asm
0000000000400640 <multstore>:
    400640:   push %rbx
    400641:   mov %rdx,%rbx
    400644:   callq 400650 <mult2>
    400649:   mov %rax,(%rbx)
    40064c:   pop %rbx
    40064d:   retq
```

```c
long mult2(long a, long b)
{
    long s = a * b;
    return s;
}
```

```asm
0000000000400650 <mult2>:
    400650: mov %rdi,%rax
    400653: imul %rsi,%rax
    400657: retq
```

（1）假设准备执行 `callq` 指令时，`%rsp` 内容为 `0x110`。执行完 `callq` 指令后，`%rsp` 内容为 {{blank:q16-rsp-after-call}}，`%rsp` 指向的内存中的数值为 {{blank:q16-return-address}}。随后执行完地址 `400657` 处的 `retq` 指令后，`%rsp` 内容为 {{blank:q16-rsp-after-ret}}。（均为十六进制）
%%% part-reference: q-d88a44aeb2ce10d9
答案：`0x108`；`0x400649`；`0x110`
%%% part-stem: q-ec8d099be2077dda
（2）C 代码中的下列变量分别保存在哪个寄存器中：

`x`：{{blank:q16-x}}　`y`：{{blank:q16-y}}　`a`：{{blank:q16-a}}　`b`：{{blank:q16-b}}　`s`：{{blank:q16-s}}
%%% part-reference: q-ec8d099be2077dda
答案：`x`：`%rdi`；`y`：`%rsi`；`a`：`%rdi`；`b`：`%rsi`；`s`：`%rax`。
%%% part-stem: q-f2d08e525678649c
（3）汇编代码中，地址 `400641` 的指令修改了 `%rbx`，地址 `400649` 的指令使用了 `%rbx`，而二者中间有过程调用 `call`。是什么机制保证了 `%rbx` 不会被修改？
%%% part-reference: q-f2d08e525678649c
答案：ABI 规定 `%rbx` 是被调用者保存寄存器；被调用过程若修改 `%rbx`，必须先保存并在返回前恢复。
%%% part-stem: q-ce58933dd5b2fa33
（4）如果把 C 代码中的 `mult2(x, y)` 改为 `mult2(y, x)`，汇编代码会有什么变化？
%%% part-reference: q-ce58933dd5b2fa33
答案：需要在 `call` 指令之前交换 `%rdi` 和 `%rsi` 的内容。
