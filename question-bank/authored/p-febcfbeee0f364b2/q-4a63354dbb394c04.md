11. 下面的 C 语言代码与汇编语言代码对应：

```c
int cmpxy(long x, long y) {
    return x > y;
}
```

```asm
cmpq %rsi, %rdi
setg %al
movzbl %al, %eax
ret
```

（1）修改 C 语言代码如下，相应补全汇编语言代码：

```c
int cmpxy(long x, long y) {
    return x <= y;
}
```

```asm
cmpq %rsi, %rdi
{{blank:q11-set-condition}}
movzbl %al, %eax
ret
```
%%% part-reference: q-0f71738d4b9ce3de
答案：`setle %al`

```asm
setle %al
```
%%% part-stem: q-ca1ea21621239695
（2）`movzbl` 指令本身的功能是什么？
%%% part-reference: q-ca1ea21621239695
答案：从源操作数取出 1 个字节，零扩展为 32 位后存入目的操作数。
%%% part-stem: q-ab06db7b52036584
（3）在 x86-64 中，这条 `movzbl` 指令还隐含了什么操作？
%%% part-reference: q-ab06db7b52036584
答案：写入 32 位目的寄存器时，会将对应 64 位寄存器的高 32 位清零；本题中即 `%rax` 的高 32 位清零。
