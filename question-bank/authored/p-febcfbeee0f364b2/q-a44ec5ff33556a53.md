%%% stem
19. C 语言中传参 $n\times n$ 二维数组时，如果 `n` 是变量，应该如何传递？补全下面的汇编代码。

```asm
# int var_ele(size_t n, int a[n][n], size_t i, size_t j)
# { return a[i][j]; }
# 参数寄存器：%rdi, %rsi, %rdx, %rcx

var_ele:
    movq %rdx, %rax
    {{blank:multiply-index}}
    {{blank:add-column}}
    movl (%rsi,%rax,4), %eax
    ret
```
%%% reference
答案：

1. `imulq %rdi, %rax`
2. `addq %rcx, %rax`

数组按行优先存放，`a[i][j]` 的元素下标为 `i * n + j`。因此先计算 `%rax = i * n`，再加上 `j`；最后用比例因子 4 读取 `int` 元素。
