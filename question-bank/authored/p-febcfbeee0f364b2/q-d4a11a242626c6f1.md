22. 考虑下面的 C 语言代码和对应的汇编语言代码：

```c
double mix_compute(long *a, double *b, float c) {
    double result = *a + *b + c;
    return result;
}
```

```asm
mix_compute:
    movsd (%rsi), %xmm1
    movq (%rdi), %rax
    cvtsi2sd %rax, %xmm2
    addsd %xmm1, %xmm2
    cvtss2sd %xmm0, %xmm0
    addsd %xmm2, %xmm0
    ret
```

C 代码中的下列变量分别位于哪个寄存器中？

`b`：{{blank:q22-b}}　`c`：{{blank:q22-c}}　`result`：{{blank:q22-result}}
%%% reference
答案：`b`：`%rsi`；`c`：`%xmm0`；`result`：`%xmm0`
