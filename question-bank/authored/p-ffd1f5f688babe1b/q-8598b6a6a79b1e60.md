%%% stem
9. 在教材 Y86-64 PIPE 上执行下面的代码，共使用了多少次数据转发？按每条指令最终使用的每个源操作数分别计数；同一条指令暂停期间重复计算的旁路值不重复计数。假设片段前后均执行足够多的 `nop`。
```
    mrmovq 0(%rdx), %rax
    addq  %rbx, %rax
    mrmovq 8(%rdx), %rcx
    addq  %rcx, %rax
    irmovq $10, %rcx
    addq  %rcx, %rax
    rmmovq %rax, 16(%rdx)
```
%%% reference
答案：D
共6次。原解析依赖红色着色标记，文字提取后无法辨别，现逐项写明：

| 使用该值的指令 | 源寄存器 | 前递来源 |
| --- | --- | --- |
| 第2条 `addq` | `%rax` | 第1条加载的 `m_valM` |
| 第4条 `addq` | `%rcx` | 第3条加载的 `m_valM` |
| 第4条 `addq` | `%rax` | 第2条结果的 `W_valE` |
| 第6条 `addq` | `%rcx` | 第5条立即数结果的 `e_valE` |
| 第6条 `addq` | `%rax` | 第4条结果的 `M_valE` |
| 第7条 `rmmovq` | `%rax` | 第6条结果的 `e_valE` |

第2、4条各因前一条加载产生一次load-use暂停；暂停后再用相应加载结果前递。一次指令有两个源操作数通过旁路获取时计两次。
%%% option: A
3
%%% option: B
4
%%% option: C
5
%%% option: D
6
