%%% stem
13. 分析下面的C程序，以下关于局部性(locality)说法错误的是：
```
int i = 0, a = 1, b = 1;
for (;i < 100; i++)  {
a = a + b;
b = a + b;
}
```
%%% reference
答案：D
解析：对于有意义的循环操作，均体现了指令的时间空间局部性。该段程序对a b
的循环访问也体现了数据的时间局部性。
%%% option: A
体现了数据的时间局部性
%%% option: B
体现了指令的时间局部性
%%% option: C
体现了指令的空间局部性
%%% option: D
以上都没有体现
