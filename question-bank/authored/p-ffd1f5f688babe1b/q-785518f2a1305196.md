%%% stem
14. 假设已声明 `int i, j, y`、`float x`、`const int n`、`int a[n], b[n]`、`int *p, *q, *r` 和 `int foo(int)`；各变量已有效初始化，数组下标合法。在补码截断机器模型下讨论整数运算，浮点运算保持标准求值次序、不启用fast-math重结合。以下哪项优化总是可以进行？
%%% reference
答案：D
A. 浮点数运算不具有结合性
B. pqr内存别名引用
C. 函数`foo`可能具有副作用
%%% option: A
原程序：
```
for (i = 0; i < n; i++)
    x = (x + a[j]) + b[j];
```
优化程序：
```
for (i = 0; i < n; i++)
    x = x + (a[j] + b[j]);
```
%%% option: B
原程序：
```
*p += *q;
*p += *r;
```
优化程序：
```
int tmp;
tmp = *q + *r;
*p += tmp;
```
%%% option: C
原程序：
```
for(i = 0; i < foo(n); i++)
    sum += i;
```
优化程序：
```
int tmp = foo(n);
for(i = 0; i < tmp; i++)
    sum += i;
```
%%% option: D
原程序：
```
for (i = 0; i < n; i++)
    y = (y * a[j]) * b[j];
```
优化程序：
```
for (i = 0; i < n; i++)
    y = y * (a[j] * b[j]);
```
