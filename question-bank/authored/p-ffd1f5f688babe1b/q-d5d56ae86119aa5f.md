7.阅读下列C代码和在x86-64机器上得到的汇编代码：
```
int a[__A__][__B__];
for (int i = 0; i < __C__; i++)
    a[i][__C__ - i] = 1;
```

```asm
    leaq 40(%rdi), %rax
    addq $440, %rdi
.L2:
    movl $1, (%rax)
    addq $40, %rax
    cmpq %rdi, %rax
    jne  .L2
```
假设`a`的地址初始时放在`%rdi`中，假设程序正常运行且没有发生越界问题，则C
代码中的A、B、C处应分别填：
