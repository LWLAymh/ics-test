%%% stem
以下各小问共用这段链表代码。按课程机器模型，`float` 为 4 字节，`short` 为 2 字节，指针为 8 字节；最后一问按大端字节序解释联合体中的机器表示。

```cpp
struct s_element {
    union u_inner {
        float f;
        short s[2];
    } u1;
    s_element *next;
};
float func(s_element *p) {
    float ans = 0;
    while (p) {
        ans += p->u1.f;
        p = p->next;
    }
    return ans;
}
```
%%% reference
参考答案对照原卷第 26 页补全。数值与代码空按显式答案核对；第 2、5、6 小问仍需按文字含义自评。不能将第 6 问的“寄存器溢出”理解成整数算术溢出。
%%% part-stem: q-4b04af65cec464e8
1. 若 `tmp` 是一个 `s_element` 类型的变量，则 `sizeof(tmp.u1)` = {{blank:q6-1-sizeof}} 字节。
%%% part-reference: q-4b04af65cec464e8
答案：`4`。

联合体的大小由最大成员及对齐要求决定。`float f` 和 `short s[2]` 都占 4 字节；这里问的是 `tmp.u1`，不是包含指针的整个结构体。
%%% part-stem: q-13fdd7e738109fe2
2. 简述函数func的功能。
%%% part-reference: q-13fdd7e738109fe2
答案：`func` 遍历以 `p` 为首结点的链表，累加所有结点的 `u1.f` 并返回；空链表返回 `0`。
%%% part-stem: q-0b593b74352e632c
3. `func` 循环部分的汇编如下，请补全代码。

提示：`vaddss S1, S2, D` 实现单精度浮点加法 `D ← S1 + S2`。

```asm
L1:
  vaddss   (%rdx), %xmm0, %xmm0
{{blank:q6-3-assembly}}
L2:
  testq    %rdx, %rdx
  jne L1
```
%%% part-reference: q-0b593b74352e632c
答案：

```asm
    movq 8(%rdx), %rdx
```

`u1` 占 4 字节，但 8 字节指针要按 8 字节对齐，故 `next` 的偏移为 8。指令读取 `p->next`，而不是立即数，不加 `$`。
%%% part-stem: q-22d8754a3541d68a
4. 同学 I 模仿书上 $2 \times 2$ 循环展开的方法，使用两个累积变量以提高代码并行性，请补全 `func1`。（原卷本小问共 4 分）

```cpp
float func1(s_element* p){
    float ans1 = 0, ans2 = 0;      //line 1
    while( p && {{blank:q6-4-1}}){      //line 2
        ans1 += p->u1.f;            //line 3
        ans2 += {{blank:q6-4-2}};      //line 4
        p = {{blank:q6-4-3}};        //line 5
    }
    if({{blank:q6-4-4}})          //line 6
        ans1 += p->u1.f;       //line 7
    return ans1 + ans2;       //line 8
}
```
将要补全的代码填在下面：
```
① {{blank:q6-4-1}}
② {{blank:q6-4-2}}
③ {{blank:q6-4-3}}
④ {{blank:q6-4-4}}
```
%%% part-reference: q-22d8754a3541d68a
答案：① `p->next`　② `p->next->u1.f`　③ `p->next->next`　④ `p`

解析（本题的 `s_element` 是一个链表结点：`union u_inner u1` 里放 `float f`，另有 `next` 指向下一个结点；原函数 `func` 就是遍历链表把每个结点的 `u1.f` 累加）：

1. ① 循环条件必须保证「还有**两个**结点可以处理」，否则第 4 行访问 `p->next->u1.f` 会解引用空指针 → 填 `p->next`（完整写法 `p && p->next`）。
2. ② 第 3 行已经把本轮第一个结点的 `p->u1.f` 加进 `ans1`，第二个累积变量对应本轮第二个结点 → 填 `p->next->u1.f`。
3. ③ 一轮吃掉两个结点，指针要一次前进两格 → 填 `p->next->next`。
4. ④ 退出循环时只可能剩下两种情况：结点数为偶数（两个两个处理完，`p == NULL`）或为奇数（还剩最后一个结点，`p != NULL`）。第 6–7 行就是把可能剩下的那个结点补加到 `ans1`，所以条件填 `p`（等价于 `p != NULL`）。若写成 `p->next`，当 `p` 是最后一个结点时会漏加，而 `p` 为 `NULL` 时还会解引用空指针。
5. 累加口径：`ans1` 收第 0、2、4… 个结点，`ans2` 收第 1、3、5… 个结点，最后 `ans1 + ans2` 就是全部结点之和 —— 功能上与原 `func` 等价。但注意：这里改变了浮点加法的结合次序，结果可能与原 `func` 不同（这正是下一小问的考点）。

5. 此时，同学 C 指出同学 I 的做法会导致新的错误，原因是 {{blank:q6-5-reason}}。
（2分）
%%% part-reference: q-e06f959730a36946
答案：浮点数加法不满足结合律；`func1` 用两个累积变量改变了相加的次序（重新结合），舍入结果可能不同，于是 `func1` 的返回值可能与原 `func` 不相等。

解析：

1. 原 `func` 用**一个**变量按链表顺序累加：`((f0 + f1) + f2) + f3 + …`，相加次序就是链表顺序。
2. `func1` 把结点按奇偶分成两路：`ans1 = f0 + f2 + f4 + …`，`ans2 = f1 + f3 + f5 + …`，最后才做一次 `ans1 + ans2`。这是典型的「重新结合（reassociation）」——相邻元素的加法次序被换掉了。
3. IEEE 754 浮点加法有舍入，**不满足结合律**，即 `(a+b)+c` 与 `a+(b+c)` 可能不相等。例如单精度下取 `a = 1e20f`、`b = -1e20f`、`c = 1.0f`：`(a+b)+c = 0 + 1 = 1.0f`；而 `b+c` 舍入后仍是 `-1e20f`，`a+(b+c) = 0.0f`。链表越长、各元素量级差别越大，出现差异的机会越多。
4. 所以把单一累积变量拆成多个（循环展开提高并行性的常用手法）时，必须确认这段浮点计算允许改变结合次序；这也是编译器在未开启 `-ffast-math` 之类选项时不会对浮点做这种重结合的原因（教材 5.8 节「重新结合变换」的限制，同时呼应书上 2×2 展开只用于整数/可结合运算的例子）。
5. 补充：差异并非必然出现——若链表只有一两个结点，或各级部分和都能被浮点精确表示，两者结果相同；但隐患是真实存在的，这就是同学 C 指出的「新的错误」。

6. 同学 S 从书上读到，`k * k` 循环展开在 `k` 很大时反而可能获得较差的效果，这是因为 {{blank:q6-6-reason}}。
%%% part-reference: q-a18d830efa0ca402
答案：寄存器溢出（register spilling），过多的活跃变量无法全部放入寄存器，部分变量被分配到栈上，增加内存读写。

这是寄存器压力引起的性能下降，不是数值运算产生的算术溢出。含义相同的解释可自评为正确。

7. 同学 B 使用改进后的 `func1` 执行下面的代码。按课程的联合体机器表示模型，在大端机器上解释两个 `short`，填写输出。

```cpp
s_element x, y, z;
x.u1.f = 1.2;
y.u1.f = 3.55;
x.next = &y;
y.next = nullptr;
z.u1.f = func1(&x);
printf("0x%x  %td\n",
       (unsigned int)(z.u1.s[0] - z.u1.s[1]),
       &z.u1.s[0] - &z.u1.s[1]);
```

十六进制数：{{blank:q6-7-hex}}；指针差：{{blank:q6-7-distance}}。

维护说明：为避免格式符类型不匹配，输出指针差使用 `%td`，十六进制实参显式转换为 `unsigned int`；不改变原题考查的字节序与同类型指针之差。
%%% part-reference: q-793aaab0d5e579d8
答案：`0x4098  -1`。

`1.2f + 3.55f` 舍入后为 `4.75f`，单精度位模式为 `0x40980000`。大端机器中 `s[0] = 0x4098`、`s[1] = 0`，相减输出 `0x4098`。两个同类型指针相减按元素计数，`&s[0] - &s[1] = -1`，不是 `-2`。
