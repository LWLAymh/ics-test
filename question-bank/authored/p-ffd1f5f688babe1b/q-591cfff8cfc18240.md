%%% stem
2. 按课程的联合体位表示模型，设 `float` 为 IEEE 754 单精度、`int` 为32位补码。函数 `g` 定义如下：
```c
int g(float f){
    union {
        float f;
        int i;
    } x;
    x.f = f;
    return x.i ^ ((1u << (x.i < 0 ? 31 : 0)) - 1);
}
```
则对于两个`float`型变量a,b，有`a<b`是`g(a)<g(b)`的:
%%% reference
答案：B。非NaN浮点数的数值严格递增时，变换后的整数也递增；但逆命题不成立。例如 `-0.0f` 和 `+0.0f` 比较相等，而 `g(-0.0f)=-1 < g(+0.0f)=0`。
