14. 考虑以下代码，假设`result.txt`中的初始内容为“666666”
```
  char *str1 = "6666";
  char *str2 = "2333";
  char *str3 = "hhhh";
  int fd1, fd2, fd3, i;
  fd1 = open("result.txt", O_RDWR);
  fd2 = open("result.txt", O_RDWR);
  dup2(fd1, fd2);
  for (i = 0; i < 5; ++i) {
    fd3 = open("result.txt", O_RDWR);
    write(fd1, str1, 4);
    write(fd2, str2, 4);
    write(fd3, str3, 4);
    close(fd3);
  }
  close(fd1); close(fd2);
```
  假设所有系统调用均成功，则这段代码执行结束后，`result.txt` 的内容中
有（）个“6”
