%%% stem
9.  对于以下一段代码，可能的输出为：
```
   int count = 0;
    int pid = fork();
    if (pid == 0){
        printf("count = %d\n",--count);
    }
    else{
        printf("count = %d\n",++count);
    }
    printf("count = %d\n",++count);
```
%%% reference
答案:A(printf从后向前处理，注意fork出的子进程与父进程执行顺序不确定)
