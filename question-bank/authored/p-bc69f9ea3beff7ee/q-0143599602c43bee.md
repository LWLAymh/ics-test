%%% stem
9. 假设fork成功、每次printf输出一整行且立即刷新，以下代码可能产生哪组输出数值？选项仅列每行的数值部分。

```c
    int count = 0;
    int pid = fork();
    if (pid == 0) {
        printf("count = %d\n", --count);
    } else {
        printf("count = %d\n", ++count);
    }
    printf("count = %d\n",++count);
```
%%% reference
答案：A。父进程依次打印1、2，子进程依次打印-1、0；两进程可交错，但各自内部先后次序不变。A表示父进程先完成再运行子进程。“printf从后向前处理”与此题无关，也不能作为C参数求值顺序的一般规则，已删除源卷这一错误解释。
