%%% stem
18. 假设客户端使用原卷年代的HTTPS方案（HTTP/1.1或HTTP/2，经TLS在TCP上传输，不使用HTTP/3），直接连接某电子商务服务器获取文件；服务器IP已知，不需代理或再次查询地址。下列哪种协议不是完成该次请求所必需的？
%%% reference
答案：C
DNS的作用是返回URL对应的IP地址，因为已知，所以不需要。其他协议都是必
须的，因为HTTPS是基于HTTP，SSL以及TCP一种协议。
%%% option: A
HTTP
%%% option: B
TCP
%%% option: C
DNS
%%% option: D
SSL/TLS
