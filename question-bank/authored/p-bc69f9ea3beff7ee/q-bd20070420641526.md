%%% stem
第五题（10分），包含进程输出与信号处理两部分。以下程序是Part I两小问的公共程序；假设系统调用成功、每次 `printf` 都立即刷新输出。原卷将三参数等待误写为 `wait`，这里恢复为 `waitpid`。

```c
int main() {
    int cnt = 1;
    int pid_1, pid_2;
    pid_1 = fork();
    if (pid_1 == 0) {
        pid_2 = fork();
        if (pid_2 != 0) {
            waitpid(pid_2, NULL, 0);
            printf("B");
        }
        printf("F");
        exit(0);
    } else {
        /* 位置A */
        /* 位置B */
        waitpid(pid_1, NULL, 0);
        pid_2 = fork();
        if (pid_2 == 0) {
            printf("D");
            cnt -= 1;
        }
        if (cnt == 0)
            printf("E");
        else
            printf("G");
        exit(0);
    }
}
```

%%% part-stem: q-bd20070420641526-I-1
Part I（1分）：若公共程序中的位置A、B都为空，列出全部可能的输出字符串。字符串之间用换行分隔，集合的书写顺序不限。
%%% part-reference: q-bd20070420641526-I-1
```text
FBFGDE
FBFDGE
FBFDEG
```

左支孙进程先输出F，子进程等待它后输出BF，因此前三个字符固定为FBF。父进程等待左支结束后再fork，剩余是父进程G与新子进程的DE交错。
%%% part-stem: q-bd20070420641526-I-2
Part I（2分）：若位置A为 `printf("C");`，位置B为 `exit(0);`，列出全部可能输出。字符串之间用换行分隔，集合的书写顺序不限。
%%% part-reference: q-bd20070420641526-I-2
```text
CFBF
FCBF
FBCF
FBFC
```

父进程只输出C就退出；左支的输出顺序仍是FBF，将C插入四个位置即可。

Part II（7分）：完成下面A～G七空，使输出为Q序列的前30项。若某位置对本次输出无影响，按题意填“无关”。只填表达式或信号名，不重复分号/赋值前缀。

本题使用原卷的抽象信号调度模型：每次发出的信号均在下一次发出前完成处理，处理函数不交错、不发生信号合并；每条语句为原子动作。真实POSIX中 `sleep(1)` 本身不能保证这些调度前提，且处理函数内 `printf` 不保证异步信号安全；不把示例当作可靠生产实现。

序列定义为：

$$
Q_0=0,\quad Q_1=1,\qquad
Q_{n+2}=\begin{cases}
Q_n+1,&n\bmod2=0,\\
2Q_n,&n\bmod2=1,
\end{cases}\quad n=0,1,2,\ldots
$$
