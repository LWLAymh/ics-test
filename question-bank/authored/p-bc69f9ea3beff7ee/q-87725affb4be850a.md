%%% stem
8. C源文件 `m1.c` 和 `m2.c` 如下。只按本题指定的传统ELF布局分析：int占4字节，三个对象按 `a4`、`a2`、`a1` 顺序紧邻放置，无额外填充，前两者在.data，后者在.bss；已知输出的第一个地址（`&a1`）为 `0x1083020`。其余两个地址 `&a2`、`&a4` 依次为多少？此布局是原卷参考答案的附加模型，不是C语言或任意现代链接器的保证。

```
$ gcc -o a.out m2.c m1.c
$ ./a.out
0x1083020
```

```c
// m1.c
#include <stdio.h>

int a1 ;
int a2 = 2 ;
extern int a4 ;

void hello()
{
    printf("%p ", (void *)&a1);
    printf("%p ", (void *)&a2);
    printf("%p\n", (void *)&a4);
}
```

```c
// m2.c
int a4 = 10 ;

int main()
{
    extern void hello() ;

    hello() ;
    return 0 ;
}
```
%%% reference
答案：D。在题目明确的布局模型中，`a2` 比 `a1` 小4字节，`a4` 再小4字节，分别为 `0x108301c`、`0x1083018`。原卷只凭源文件命令顺序推断绝对布局不充分；真实工具链还取决于链接脚本、节排序与对齐，此处不把给定模型推广为一般规则。

`0x1083018, 0x108301c`
%%% option: B
`0x1083028, 0x1083024`
%%% option: C
`0x1083024, 0x1083028`
%%% option: D
`0x108301c, 0x1083018`
