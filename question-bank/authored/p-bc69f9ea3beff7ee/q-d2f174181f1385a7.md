%%% stem
5. 按源码逐轮调用 `strlen` 的成本模型（不假设编译器自动将其外提），下列哪个描述正确？字符串长度N可由int表示，输入为ASCII字符串。

```c
void upper(char *s)
{
    for (int i = 0; i < strlen(s); i++)
        if (s[i] >= 'a' && s[i] <= 'z')
            s[i] += ('A' - 'a');
}
```
%%% reference
答案： B （考察程序性能优化与程序局部性原理）
%%% option: A
假设`s`的长度为N，该程序的时间复杂度为O(NlogN)
%%% option: B
在循环之前只计算一次 `int len = strlen(s);`，再使用 `for (int i = 0; i < len; i++)`，可以使运行时间与s的长度线性相关。
%%% option: C
B选项中的修改策略不影响程序的空间局部性与时间局部性
%%% option: D
B选项中的修改策略仅影响程序的空间局部性，不影响时间局部性
