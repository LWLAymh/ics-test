%%% stem
5.  对于下面这段程序，哪个描述是正确的：_________
```
void upper(char *s)
{
  for(int i=0; i<strlen(s); i++)
    if(s[i]>=’a’ && s[i]<=’z’)
      s[i] +=(‘A’-‘a’);
}
```
%%% reference
答案： B （考察程序性能优化与程序局部性原理）
%%% option: A
假设`s`的长度为N，该程序的时间复杂度为O(NlogN)
%%% option: B
将“`for(int i=0; i<strlen(s); i++){}`”修改为:
“int len = strlen(s); for(int i=0; i<len; i++){}”
可以使程序运行时间与S的长度线性相关
%%% option: C
B选项中的修改策略不影响程序的空间局部性与时间局部性
%%% option: D
B选项中的修改策略仅影响程序的空间局部性，不影响时间局部性
