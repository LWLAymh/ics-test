练习题 12.14：图 12-43 为每个线程 ID 分配单独的内存块来避免竞争。

相关代码如下。主线程创建所有线程后逐一 `Pthread_join`，因此不会在它们完成前退出；`Malloc` / `Free` / `Pthread_create` 是对应系统函数的错误检查包装。

```c
/* 主线程：tid 数组及 i、ptr 已声明。 */
for (i = 0; i < N; i++) {
    ptr = Malloc(sizeof(int));
    *ptr = i;
    Pthread_create(&tid[i], NULL, thread, ptr);
}

/* 对等线程 */
void *thread(void *vargp) {
    int myid = *((int *)vargp);
    Free(vargp);
    printf("Hello from thread %d\n", myid);
    return NULL;
}
```

A. 给出一种不调用 `malloc` / `free` 的替代方法。

B. 说明这种方法的优点和缺点。
%%% reference
A. 在线程创建时直接传递整数 ID，例如 `Pthread_create(&tid[i], NULL, thread, (void *)i)`，在线程例程中将 `vargp` 转成 `int myid`。

B. 优点是免去了动态分配与释放开销；缺点是依赖指针至少与 `int` 一样大，这种假设并非所有旧式或未来平台都能保证。该写法也需留意实现定义的整数/指针转换行为。
