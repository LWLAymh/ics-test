%%% stem
练习题 12.1：父进程 `fork` 出子进程后，父进程关闭自己的已连接描述符副本。为什么子进程仍能通过该描述符通信？
%%% reference
`fork` 复制描述符表并增加共享打开文件表项的引用计数。父进程关闭副本只将引用计数从 2 减为 1；内核在计数为 0 前不会关闭连接。
%%% option: A
子进程拥有独立的文件表，因此父进程关闭不会影响它。
%%% option: B
父子进程的描述符引用同一打开文件表项；父进程关闭后引用计数仍为 1。
%%% option: C
`close` 只关闭网络套接字，不会改变描述符状态。
%%% option: D
内核会在父子进程之间自动重新创建该描述符。
