A. 以下程序想让线程睡眠一秒后输出字符串，但教材环境中没有任何输出。为什么？

```c
/* WARNING: This code is buggy! */
#include "csapp.h"

void *thread(void *vargp);

int main()
{
    pthread_t tid;

    Pthread_create(&tid, NULL, thread, NULL);
    exit(0);
}

void *thread(void *vargp)
{
    Sleep(1);
    printf("Hello, world!\n");
    return NULL;
}
```

B. 用两个不同 Pthreads 函数调用中的任意一个替换 `main` 中的 `exit(0)`，即可改正。分别给出这两个调用（无须编写完整程序）。
%%% reference
A. `exit` 终止整个进程及其全部线程。主线程不等待工作线程，通常在它睡眠结束前就结束进程，因此不会打印。这是缺少同步的竞态，不能将“无输出”当作所有可能调度的保证。

B. 可用 `pthread_exit(NULL)`（教材包装为 `Pthread_exit(NULL)`），只终止主线程，允许工作线程继续；也可用 `pthread_join(tid, NULL)`（教材包装为 `Pthread_join(tid, NULL)`），等待工作线程结束，再由 `main` 返回。
