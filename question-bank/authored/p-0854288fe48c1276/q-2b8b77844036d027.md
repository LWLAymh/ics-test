%%% stem
在 Linux 中，在标准输入上键入 Ctrl+D 表示 EOF。图 12-6 的程序阻塞在 `select` 调用上时，键入 Ctrl+D 会发生什么？
%%% reference
EOF 状态下，从标准输入读取会立即返回 0，因此标准输入已准备好可读；`select` 返回时，准备好的集合中包含描述符 0。
%%% option: A
`select` 继续阻塞，因为没有输入字节可读。
%%% option: B
`select` 返回，且标准输入描述符 0 在准备好的集合中。
%%% option: C
`select` 返回，但准备好的集合为空。
%%% option: D
`select` 返回，且所有打开的描述符都在准备好的集合中。
