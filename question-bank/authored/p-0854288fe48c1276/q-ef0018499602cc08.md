练习题 12.13：图 12-43 为每个线程的整数 ID 分配独立内存。相关代码如下，`Malloc` / `Free` / `Pthread_create` 是对应系统函数的错误检查包装：

```c
/* 主线程：tid 数组及 i、ptr 已声明。 */
for (i = 0; i < N; i++) {
    ptr = Malloc(sizeof(int));
    *ptr = i;
    Pthread_create(&tid[i], NULL, thread, ptr);  /* 原图第 14 行 */
}
for (i = 0; i < N; i++)
    Pthread_join(tid[i], NULL);

/* 对等线程 */
void *thread(void *vargp) {
    int myid = *((int *)vargp);  /* 原图第 24 行 */
    Free(vargp);
    printf("Hello from thread %d\n", myid);
    return NULL;
}
```

为什么不能将 `Free` 移到主线程的 `Pthread_create` 后立即执行，而应由对等线程读取 ID 后释放？
%%% reference
若主线程在线程创建后立即 `free`，就会与对等线程对该内存块第 24 行的读取/赋值并发，形成 use-after-free 竞态。让对等线程在使用完该块后释放，才能确保其生命周期覆盖使用过程。
