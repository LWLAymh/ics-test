1）判断下表中每一行表达式对或错。如果错，请举出反例或简要说明原因（每行 1 分）。本页通过下拉框核对判断结果；反例或原因请自行思考，并与参考解析对照。

```c
int x, y;
unsigned u, v;
```

| --- | --- |
| 若 `x < 0`，则 `x * 2 < 0` | {{blank:if-x-0-then-x-2-0-r1-c1}} |
| `u <= -1` | {{blank:u-1-r2-c1}} |
| 若 `x > y`，则 `-x < -y` | {{blank:if-x-y-then-x-y-r3-c1}} |
| 若 `u > v`，则 `-u > -v` | {{blank:if-u-v-then-u-v-r4-c1}} |
%%% reference
答案：

| 表达式 | True or false | 原因或举出反例 |
| --- | --- | --- |
| 若 `x < 0`，则 `x * 2 < 0` | F | 在补码回绕模型下，取 $x = -2^{w-1}$，乘 2 后为 0。 |
| `u <= -1` | T | 比较时 `-1` 转为 `UINT_MAX`，所有 `unsigned` 值都不大于它（可以相等）。 |
| 若 `x > y`，则 `-x < -y` | F | 取 `x = 0`、$y = -2^{w-1}$，补码取负后的 `-y` 仍为最小负数。 |
| 若 `u > v`，则 `-u > -v` | F | 取 `u = 2`、`v = 1`，无符号取负按模 $2^w$ 运算，得到 `-u < -v`。 |

这里按原题采用的机器级补码模型解释；标准 C 中上述有符号溢出不是定义良好的运算。
