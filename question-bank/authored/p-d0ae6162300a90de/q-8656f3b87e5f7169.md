%%% stem
15、以下哪些程序优化编译器总是可以自动进行？（假设 `int i, int j, int A[N], int B[N], int m` 都是局部变量，`N` 是一个整数型常量，`int foo(int)` 是一个函数）
%%% reference
答案：AC
%%% option: A
优化前：
```c
for (j = 0; j < N; j++)
    m += i * N * j;
```
优化后：
```c
int temp = i * N;
for (j = 0; j < N; j++)
    m += temp * j;
```
%%% option: B
优化前：
```c
for (j = 0; j < N; j++)
    B[i] *= A[j];
```
优化后：
```c
int temp = B[i];
for (j = 0; j < N; j++)
    temp *= A[j];
B[i] = temp;
```
%%% option: C
优化前：
```c
for (j = 0; j < N; j++)
    m = (m + A[j]) + B[j];
```
优化后：
```c
for (j = 0; j < N; j++)
    m = m + (A[j] + B[j]);
```
%%% option: D
优化前：
```c
for (j = 0; j < foo(N); j++)
    m++;
```
优化后：
```c
int temp = foo(N);
for (j = 0; j < temp; j++)
    m++;
```
