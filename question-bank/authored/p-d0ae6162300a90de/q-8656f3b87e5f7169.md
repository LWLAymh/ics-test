%%% stem
15、以下哪些优化在给定条件下保持程序语义，允许编译器自动进行？假设 `int i, j, A[N], B[N], m` 都是局部变量，`N` 是正整数常量；`A`、`B` 是两个独立数组，元素不重叠，不是可能别名的两个指针。所有被读取的值已初始化，索引合法，变量非 `volatile`。整数运算采用教材的32位补码回绕模型；`foo` 是可能有副作用的普通函数，不假设编译器知道其纯函数性质。
%%% reference
答案：A、B、C。

A可把循环不变量 `i * N` 提到循环外。B在本题明确的两个独立局部数组条件下，不存在 `A[j]` 与 `B[i]` 别名；中间值无其他观察者，可用局部 `temp` 累积、最后回写。C在指定的补码回绕模型下可重新结合加法。D则可能改变 `foo` 的调用次数、副作用和返回值，不保证等价。

原卷给出AC，但它同时声明 `A[N]`、`B[N]` 是局部数组，不能套用“两个指针可能别名”来排除B。题库按题面声明更正为ABC，并把机器运算模型写明；不将这一模型表述为ISO C对有符号溢出的保证，也不保证所有编译器版本必然选择这些优化。
%%% option: A
优化前：
```c
for (j = 0; j < N; j++)
    m += i * N * j;
```
优化后：
```c
int temp = i * N;
for (j = 0; j < N; j++)
    m += temp * j;
```
%%% option: B
优化前：
```c
for (j = 0; j < N; j++)
    B[i] *= A[j];
```
优化后：
```c
int temp = B[i];
for (j = 0; j < N; j++)
    temp *= A[j];
B[i] = temp;
```
%%% option: C
优化前：
```c
for (j = 0; j < N; j++)
    m = (m + A[j]) + B[j];
```
优化后：
```c
for (j = 0; j < N; j++)
    m = m + (A[j] + B[j]);
```
%%% option: D
优化前：
```c
for (j = 0; j < foo(N); j++)
    m++;
```
优化后：
```c
int temp = foo(N);
for (j = 0; j < temp; j++)
    m++;
```
