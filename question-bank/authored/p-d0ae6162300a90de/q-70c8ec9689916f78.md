第六题（9分）
分析教材**32位 Y86** SEQ处理器上的 `cmovXX rA,rB`、`call Dest` 和新增指令 `decl rA`（将32位操作数减1，更新ZF、SF、OF）。本题使用 `%esp` 与4字节字，区别于Y86-64。填写各阶段的完整动作；同一阶段有多个动作时可用分号分开，没有动作填 `none`。每格原卷0.5分，共18格；阶段描述允许等价写法，填写后对照解析自评。

| 指令 | 编码（每个小字段为4位） | 总长度 |
| --- | --- | --- |
| `cmovXX rA,rB` | `2:fn`、`rA:rB` | 2字节 |
| `call Dest` | `8:0`、4字节小端目的地址 `Dest` | 5字节 |
| `decl rA` | `C:0`、`rA:F` | 2字节 |

信号包括 `icode`、`ifun`、`rA`、`rB`、`valA`、`valB`、`valC`、`valE`、`valP`；寄存器文件 `R[]`、数据内存 `M[]`、程序计数器 `PC`、条件码 `CC`。`M1`/`M4` 分别读写1/4字节。

### cmovXX rA,rB

| 阶段 | 动作 |
| --- | --- |
| Fetch | `icode:ifun ← M1[PC]`；`rA:rB ← M1[PC+1]`；`valP ← PC+2` |
| Decode | `valA ← R[rA]` |
| Execute | `valE ← 0+valA`；`Cnd ← Cond(CC,ifun)`，读取CC但不更新CC |
| Memory | `none` |
| Write back | `if (Cnd) R[rB] ← valE` |
| PC update | `PC ← valP` |

### call Dest

| 阶段 | 动作 |
| --- | --- |
| Fetch | `icode:ifun ← M1[PC]`；`valC ← M4[PC+1]`；`valP ← PC+5` |
| Decode | `valB ← R[%esp]` |
| Execute | `valE ← valB-4`，不更新CC |
| Memory | `M4[valE] ← valP` |
| Write back | `R[%esp] ← valE` |
| PC update | `PC ← valC` |

### decl rA

| 阶段 | 动作 |
| --- | --- |
| Fetch | `icode:ifun ← M1[PC]`；`rA:rB ← M1[PC+1]`；`valP ← PC+2` |
| Decode | `valA ← R[rA]` |
| Execute | `valE ← valA-1`；根据该减法结果设置ZF、SF、OF（Set CC） |
| Memory | `none` |
| Write back | `R[rA] ← valE` |
| PC update | `PC ← valP` |

**原参考答案勘误**

原卷第11页红字把 `cmovXX` 的条件计算标注为“也可以写Set CC”，并在 `decl` 的Execute格写了 `Cnd ← Cond(CC,ifun)`。两者不能等同：条件传送只读取已有条件码判断是否写回；减1指令应按算术结果更新条件码。上表保留原卷其余阶段动作，纠正这两处CC说明。该答案是据原卷恢复并勘误的参考，不是原红字的逐字照录。
