%%% stem
4、在完成Bomb Lab时，先执行 `gdb bomb` 启动调试，然后执行 `___ explode_bomb` 命令，使程序在进入该函数时先暂停。进行其他必要设置后，执行 `___` 命令开始运行程序。
上述两个空格对应的命令是
%%% reference
答案：C，`br` 是 `break` 的缩写，`ru` 是 `run` 的缩写。断点让GDB在函数入口停住；之后若继续执行，仍可能触发炸弹逻辑，断点本身不永久跳过函数。
%%% option: A
st, ru
%%% option: B
br, go
%%% option: C
br, ru
%%% option: D
st, go
