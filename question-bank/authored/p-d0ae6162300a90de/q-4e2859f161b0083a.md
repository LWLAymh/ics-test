%%% stem
2. 假设 `int` 和 `unsigned` 均为 32 位，`int` 使用补码表示：

```c
int x = 0x80000000;
unsigned y = 0x00000001;
int z = 0x80000001;
```
本题沿用原卷的**32 位机器数模型**：取负、加减乘法及合法位数的左移均保留低 32 位，再按结果类型解释；有符号与无符号数混合比较按 C 的类型转换规则。运算符优先级仍遵循 C，不能自行补括号；移位计数必须在 0–31 内，不能对计数取模。

注意：这是题目明确指定的机器数模型，不是 ISO C 对有符号溢出或负数左移的语言保证。

以下哪些表达式成立？（多选）
%%% reference
答案：A、B、C。原解析同时写“ABCD”和“选 ABC 也算对”，此处按原选项的实际优先级修正，不能将缺失的括号默默补上。

- A：按本题指定的截断模型，`-x` 的位模式仍为 `0x80000000`，按 `int` 解释为负数。
- B：`-1` 与 `unsigned y` 比较时转换为无符号数 `0xFFFFFFFF`，大于 1。
- C：两边截断后的位模式都为 `0x00000008`。
- D：按 C 优先级，表达式是 `(y * 24) == ((z << (5 - z)) << 3)`，不是 `(y * 24) == ((z << 5) - (z << 3))`。`5 - z` 按指定的 32 位模型得到负数 `-2147483644`，不属于合法移位计数，不能判为成立。

只有人为补上 `(z << 5) - (z << 3)` 的括号，右侧才会在本题机器数模型下得到 24；这不是原选项的写法。C 的移位语法与非法计数规则可参见 [WG14 草案第 6.5.7 节](https://open-std.org/jtc1/sc22/wg14/www/docs/n843.htm)。
%%% option: A
`(-x) < 0`
%%% option: B
`(-1) > y`
%%% option: C
`(z<<3) == (z*8)`
%%% option: D
`y*24  == z<<5 - z<<3`
