2、假设下列`int`和`unsigned`数均为32位，
```c
int x = 0x80000000;
unsigned y = 0x00000001;
int z = 0x80000001;
```

%%% reference
答案:ABCD；考虑到运算符的优先顺序，选ABC也算对
A. int中`0x80000000`的相反数还是自己
`B. signed (-1)` 和 unsinged y 比较，都按照 `unsigned`，所以强制类型转换后 （-1）很大
C: unsigned, signed左移三位 = *8
D：应该是相等关系；`signed` 左移之后，和 unsigned y*24 相比都看成 `unsigned`
%%% option: A
`(-x) < 0`
%%% option: B
`(-1) > y`
%%% option: C
`(z<<3) == (z*8)`
%%% option: D
`y*24  == z<<5 - z<<3`
