第五题（9分）

![四级流水线各流水级的工作内容和延迟](assets/期中/2013期中-带答案/p10-pipeline-structure.png)

在“取指-译码-执行-写回”的四级流水线中，各流水级的工作内容和延迟如上图所示，寄存器的延迟
也已标出。数据和指令分别存放在不同的存储器中。Cycle N写入寄存器文件的数据Cycle N+1才可读出。
请问：

第3、4小问使用同一段Y86代码：

```asm
Prog:
    irmovl $128, %edx       # instr1
    irmovl $3, %ecx         # instr2
    rmmovl %ecx, 0(%edx)    # instr3
    irmovl $10, %ebx        # instr4
    mrmovl 0(%edx), %eax    # instr5
    addl %ebx, %eax         # instr6
```

%%% part-stem: q-afe2d4c7ea8a15ef
1）若不考虑流水线填充和清空时间，吞吐率为 {{blank:pipe-throughput}} GIPS（只填数值，保留两位小数）。（1分）
%%% part-reference: q-afe2d4c7ea8a15ef
答案：吞吐率 = 1000/(280 + 20) = 1000/300 = 3.33 GIPS
%%% part-stem: q-b9d41514096fda00
2）若改造为单周期处理器（SEQ），吞吐率为 {{blank:seq-throughput}} GIPS（只填数值）。（1分）
%%% part-reference: q-b9d41514096fda00
答案：吞吐率 = 1000/(80 + 60 + 280 + 60 + 20) = 1000/500 = 2 GIPS
%%% part-stem: q-759f821ac0a5bd5d
3）执行阶段包含访问数据存储的时间。对公共题面中的Y86程序段，指令间有哪些数据相关（dependence），在未加转发时会引起哪些数据冒险（hazard）？（5分）
%%% part-reference: q-759f821ac0a5bd5d
答案：各指令的含义：1、`edx = 128`；2、`ecx = 3`；3、`[edx] = ecx`；4、`ebx = 10`；5、`eax = [edx]`；6、`eax = eax + ebx`。原卷第6条的文字把目的寄存器写反，此处以给出的 `addl %ebx,%eax` 为准。

数据相关（dependence）：1-3、2-3、1-5、4-6、5-6

数据冒险（hazard）：1-3、2-3、4-6、5-6
%%% part-stem: q-68bba4b7636ed213
4）以上的数据冒险，可以通过转发（forward）的方法解决。请结合上述程序代码和流水线结构图逐个说明
解决方案。（2分）
%%% part-reference: q-68bba4b7636ed213
答案：
2-3和5-6通过执行阶段到译码阶段的转发通路解决；1-3和4-6通过写回阶段到译码阶段的转发通路解决。
