## 独立复算

以下显式采用旧答案额外使用的模型：按字节寻址，32 位 `int` 和 4 字节 PTE，4 KiB 页，PTE 清除最高有效位和低 12 位后得到页框基址；两次指定写分别为新 PTE 写回与 `*b` 数据写。此模型仅用于核对旧计算，不能反过来充当源题已给出的条件。

| 量 | 独立关系 | 结果 |
| --- | --- | --- |
| 索引和偏移位数 | `log2(64)=6`，`log2(1024)=10`，4 KiB 页偏移 12 位 | 总计 28 位虚拟地址 |
| 一级表基址 | `0x67F0E8` 落在 4 KiB 对齐、共 `64*4=256` 字节的一级表内 | `0x67F000` |
| 一级索引 | `(0x67F0E8 - 0x67F000) / 4` | `0x3A`（58，未超过 63） |
| 二级表基址 | `0x80AA32C4 & 0x7FFFF000` | `0xAA3000` |
| 二级索引 | `(0xAA3AD0 - 0xAA3000) / 4` | `0x2B4`（692，未超过 1023） |
| 新物理页基址 | `0x80C3F110 & 0x7FFFF000` | `0xC3F000` |
| 页内偏移 | `0xC3F50D - 0xC3F000` | `0x50D` |
| 虚拟页号 | `(0x3A << 10) + 0x2B4`（不相交位段相加） | `0xEAB4` |
| `b` | `(0x3A << 22) + (0x2B4 << 12) + 0x50D` | `0xEAB450D` |
| `a` | `b - 5000*4`；其中 `5000*4=0x4E20` | `0xEAAF6ED` |

上述算式用独立 Python 整数计算复核，未运行题库编译。`b % 4 = a % 4 = 1`，不是页号拼接算错。

## 仍不能发布的最小证据

1. **24/28 位只能修复一部分。** 若“24 位地址空间”指完整虚拟地址，满两级索引需要 16 位，剩余偏移为 8 位，页大小是 256 字节，不能同时采用旧答案的 4 KiB。一级表“4KB 对齐”并不等于页大小是 4 KiB，二级表有 1024 项也不自动等于占一页。Arthals 支持将虚拟地址改为 28 位，但此勘误不能补齐其余条件；把 24 位另解释为物理地址宽度也需要明说。
2. **PTE 位域未定义完整。** 原题只给最高有效位，没有给 PTE 字节数、页框位段或地址掩码，也未完整说明二级表布局。由“32 位机器”不能严格推出所有 PTE 都为 4 字节。`0x80AA32C4 → 0xAA3000` 和 `0x80C3F110 → 0xC3F000` 都额外使用了页框掩码；不能从最低 12 位的数值推断 COW、写权限、A/D 位及其更新顺序。
3. **常规课程模型下指针不可能以 D 结尾。** 成功 `calloc` 返回可供 `int` 使用的自然对齐地址，4 字节 `int` 下 `b=a+5000` 增加 `0x4E20`，保持模 4 为 0；分页翻译保留页内偏移，`fork`/COW 改物理页框而不改虚拟指针。记录数据写若确为 `0xC3F50D`，旧模型强制 `b` 低两位为 `01`，与此矛盾。采用非通常的 `int` 对齐或非通常的访存记录含义也必须另行给出，不能默默引入。

因此，当前材料不足以唯一确定一个符合全部原条件的程序执行。`0x50C` 和 `0x510` 都能消掉这一处模 4 矛盾，却没有源证据支持选择其中一个，而且仍没有补齐 PTE 条件。恢复发布至少需要可溯源修订说明，明确虚拟/物理地址宽度、PTE 布局、页大小、相关读写含义，并纠正数据地址或程序对象类型。现有 review 题稿保留全部原始地址和条件性旧答案，供届时对照。
