# v5 题面噪声清理记录

清理日期：2026-10-10。

## 范围与方法

本轮针对反馈的「题面里莫名其妙的空格」「选择题题面却有个『答（）』」，只读枚举
`question-bank/authored` 全库 965 道题，逐题扫描 `stem`、综合题 `part-stem`，以及
用户可见的 `reference` / `part-reference`。

扫描前先把**围栏代码块与行内代码跨度整体屏蔽**再匹配。第 2 章有 719 个 U+00A0 用于
汇编对齐、`_init`/`B.main` 选项行用 U+00A0 在行内代码里对齐，若不做屏蔽会被当成
「多余空格」删掉、破坏对齐与语义，因此所有规则一律不作用于代码内容。

候选模式：纸卷答题占位（`答（　）`、空括号、`答：`）、全角空格 U+3000、不换行空格
U+00A0、零宽字符、CJK 标点前空格、两个 CJK 之间单空格（PDF 字距/断行残留）、行尾空白、
下划线占位、省略号占位。

与前一轮选项审阅不同，本轮**先跑只读分类与 dry-run，再逐条人工阅读 diff 后才写盘**。
原因是本轮多数规则是机械空白归一化，逐题手改 900 余文件不现实；但为保留人工判定，
每条规则都限定在可举证的形态上，并且先出报告再落盘、落盘后做结构校验（见下）。

## 判定为「不是噪声」而保留

- **全角空格 U+3000 作为编号分隔与缩进**：`① 　② 　③`、`1. {{blank:blank-1}}　2. …`、
  `A {{blank:A}}　B {{blank:B}}`、`　　IRET in { … }`、表格单元格内的对齐。这是刻意排版，
  全库 228 处未动。
- **行尾两个空格**：Markdown 的强制换行（v5 文档明确「真正的强制换行用行尾两个空格」），
  16 处保留。
- **输入框两侧的空格**：`二进制表示为 {{blank:subnormal}} ，可表示…` 是刻意留白，保留。
- **纸卷手写位**：`为      ；`、`R1: ；W1: ；` 这类多空格/冒号后空格是作答位置，保留。
- **`____` 下划线占位 191 处**：v5 文档明确「旧题的 `____` 等保留原文」，未动。
- **参考区标签**：`【说明】`、`【答案】`、`【评分标准】`、`答：`；**题面标签**：
  `参考信息：`、`原卷给出的源文件：`（`docs/OPTION_NOISE_AUDIT.md` 记录的刻意标注）。保留。
- **`（    ）` 属于填空语义的 2 处**（`q-48830bbf91e759fa` 第二题 3，判断题作答位，
  已登记 `blank-positions-unresolved`）：删除会让该小问失去可见作答位，保留。
- **已停用错题**（`retired-invalid-question`）：保留原样，不改动留档文本。

## 未处理的系统性项：中文逐行折行

全库仍有 **524 处**「行尾汉字 + 下一行行首汉字」（204/965 个文件）。Markdown 软换行
在 `breaks:false` 下渲染为一个空格，因此页面上会显示成「访问扇 区中的第一个字节」。

v5 文档写明前端「不删除中文折行」，且「要调整排版，应逐题改人工 Markdown」，即这是
已知且刻意的渲染行为；修它等于逐题重排 204 个文件的段落换行，与本轮「清除噪声残留」
不是同一件事，故未纳入。若确定要处理，应单独立项并逐卷复核，不能靠脚本整体合并行。

## 校验

- 修改后重新解析全库并通过 Schema／链接／图片／空位定位校验（`npm run check` 退出码 0），
  `npm run compile-bank`、`npm run build` 均通过。
- 逐文件与清理前备份比对，确认：**围栏代码、行内代码、`{{blank:…}}` 标记、Markdown
  表格行、`$` 公式定界符数量、图片引用**在 96 个改动文件中全部逐字未变；
  `id`／`paperId`／`paperOrder`／`type`／`number`／`grading`／`blankAnswers`／
  `correctOptionIds`／`publication` 未变。
- 每个改动题目 `revision` 由 1 增至 2（共 96 题），未新增或删除题目。
- 本轮是题面空白与纸卷残留的机械+人工复核，不等于原卷逐字重校，也不保证答案正确性。
