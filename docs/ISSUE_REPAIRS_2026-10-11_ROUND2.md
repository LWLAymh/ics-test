## Agent / MCP 接入面板

桌面按“添加服务／连接练习”两栏整理，手机纵向排列。服务地址可直接复制，自动复制失败时选中地址供手动复制。详细连接规则默认折叠；只读范围、当前题共享及不能代填／修改／提交等边界始终可见。原有连接、共享开关、撤销机制和三个 MCP 工具权限不变。

浏览器验证另发现：切换小问时，面板同步提示由长变短再变长会引起页面滚动锚定，误关刚打开的下拉。常规同步期间保留最近一次状态说明，只更新状态标签；正常提示不再堆叠内部题号／小问 ID，避免此类高度变化。
