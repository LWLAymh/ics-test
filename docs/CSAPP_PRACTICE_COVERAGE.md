## 录入规则

- 逐题人工写 Markdown，不用提取脚本或渲染器猜测、合并、重排题面。
- 保留原题给定项与全部符合范围的小问。已有题扩展原 ID，递增 `revision`，不为同一练习重复建题。
- 完整写程序、实际运行实验、要求绘制图形的交付任务可排除，并逐题说明原因；“有图片”“需要读代码”“有表格”不能作为排除理由。
- 图片应保存到题库资产目录并插入题面；也可手工转写为完整的等价数据表。不得只保留“见图某某”而缺少图及其条件。
- 明确数值、位串、有限选择等使用填空和显式判分；有限候选使用下拉或多选空。推导说明用综合题中的简答小问自评，不让整题因此失去客观判分。
- 只有来源答案且尚未交叉复核时如实标注。发现来源错误须写明修订依据，不能悄悄改答案。

## 只读盘点与验收

在仓库根目录运行：

```powershell
npm run audit-csapp -- --source 'D:\Studying Materials\Homework\ICS\TA-2026\csapp-zh-markdown'
```

此工具只扫描编号并比较 authored 文件，不生成、不改写题目。它会列出各章缺失编号和重复编号；缺失项还需与人工排除清单核对。`authoredExercises` 仅表示存在同编号 authored 文件，不证明整题已补全或已发布。

新增题还需接入 `question-bank/authored/papers.json`，按原练习编号顺序排列；对应章节家庭作业继续排在章内练习之后。验收依次执行 `npm run compile-bank`、`npm run check`、`npm run build`，并在浏览器验证完整表格、原位输入框、实际提交判分与移动端布局。
