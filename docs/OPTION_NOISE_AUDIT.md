审阅日期：2026-10-10。

## 范围与方法

本次针对用户截图所示“选项 D 混入答题占位”的问题，读取 `question-bank/authored` 全库 738 个题目记录，逐份人工阅读其中全部 **530 个带结构化选项的作答单元、2,150 个选项**。作答单元包括根题与综合题小问，也包括尚未发布、单多选类型待确认的题。无结构化 `options` 的简答题／填空题文本中的内嵌备选项不在这个数量内；本次不是全库题面和答案正确性复核。

使用只读枚举工具输出选项及所属试卷、唯一编号后逐条阅读，再用逐题补丁修改 authored Markdown；未编写批量清洗脚本，未在渲染器增加删除噪声的逻辑，未修改 `_curated` 历史文件。题目 ID、选项 ID、已登记的答案及发布范围保持不变。每个修正的题目 `revision` 从 1 增加至 2。

对边界明显的多余答题框和重复答案，检查当前 `stem` / `reference` 后移除选项中的重复内容；共同源文件和参考信息移入题面，不能当噪声删掉。缺字与代码标点存疑时追溯 `sources.document` 的原文文本，不根据知识点猜改正确选项。

## 结果与限制

- 修正后重新读取全库并通过现有 canonical schema / 链接校验；结构化选项中不再有本轮确认的 `答：`、`【答案】`、`【说明】`、`参考信息：`、`原卷给出的源文件：` 边界混入。
- 这个检查是选项文本和段落归属的人工审阅，不等于对全部 738 题原卷截图的逐字重校，也不保证所有科学内容或原卷答案正确。
- 没有把选择题中故意写错的 C／汇编语法“自动修正确”，没有删除“以上答案都不对”等正常选项；原卷单位勘误这类确有用途的说明也没有仅因含“原卷”就清除。
- 原有 25 道单多选形式待复核题仍待复核；本次没有推断并解除它们的发布限制。用户另行要求的 2015 期中比较表达式填空改造由主任务处理，不属于本报告的 25 个文件。
- 生成数据、前端回归与最终提交由主任务统一进行；本报告不宣称已上线。
