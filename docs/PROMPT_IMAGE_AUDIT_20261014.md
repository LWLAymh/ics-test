## 来源及验证方式

原卷位于用户提供的 `Introduction-to-Computer-System-2026Fall-PKU/往年题` 目录。用 PDF 原生图像提取，或按逐张核实的边界渲染 PDF 中的配图区域；没有生成替代电路或猜测缺失连线。

- authored 内容逐题手工修改并增加 revision；保留稳定 ID、客观答案及作答历史关联。
- `tests/prompt-images.test.cjs` 使用 Markdown token 检查所有已发布题面/选项，不允许直接挂常见原始 `page-NN` 整页文件，也不允许题面 SVG 依赖外部图像；这不是自动识图，新增图片仍需目视审阅。
- `tests/prompt-image-fixtures.cjs` 逐题声明本次核对过的配图，不允许修复后回退到旧图或重复挂图。
- `tests/browser-prompt-images.cjs` 在桌面和 390px 窄屏检查 18 道题、空位和小问是否完整；实际解码全部题面配图；检查 4 套受影响试卷的打印预览默认不含答案。测试不向线上提交作答或报错。
- 全量 Schema、题库编译、评分规则、安全回归和浏览器测试均需通过后发布；上线核对成功后才清理对应线上报告。

本次检查针对配图范围和可显示性，不声称证明全题库所有题面文字或参考答案无误。
