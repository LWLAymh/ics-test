# 搜索与手写作答

首页“搜索题目”支持试卷名、题号、唯一编号、知识模块、题面及选项；多个关键词以空格分隔，同时匹配。不会搜索参考答案。首次查询才按需加载题库，打开结果会保留进行中的练习。

每题上方可选择“打字”或“手写 / 批注”，偏好保存在当前浏览器。手写模式保留选择、填空、简答框等交互：触控笔在原题、题图及空位上书写，手指可滚动、点选和输入；鼠标在控件之外也可书写。需要手指画图时开启“允许手指书写”。支持颜色、粗细、橡皮、撤销和重做；清空可撤销。额外草稿纸默认折叠。

笔迹按题目唯一编号和 revision 存入 IndexedDB，刷新或切题后可恢复，不上传 Supabase 或 MCP。浏览器拒绝存储或容量不足时会显示提示；清除站点数据会删除笔迹。已有笔迹保持原书写版面宽度，窄屏可横向移动，避免文字重新换行导致批注错位。需要适配新宽度时可清空笔迹、切换模式后重新书写。

“提交答案”仍按实际点选和键入的客观答案自动核对，不识别笔迹。手写作答可选择“核对手写答案并自评”，确认自评后才计入记录；“直接显示答案”及跳过不计次。AI 建议评分不会提交答案或自动计分。

“预览整题并交给 AI 评测”先在本地生成截图，用户检查预览并点击“发送并评测”后才调用其自行配置的 API。截图包含当前整题、题图、点选、输入及笔迹，另附当前题的文字参考答案；不含其它题、历史、熟知进度或 API 配置。此次图片授权独立于文字评测的“以后不再显示”：每次图片评测均需确认。修改笔迹、回答、配置或切题会取消在途请求并使旧建议失效；已经发出的请求可能仍由供应商计费。

请求由浏览器直接发送至固定官方接口，密钥只放 Authorization 请求头，不经过本站服务器。仅使用支持图片输入的模型。实现依据 [OpenAI 图片输入文档](https://developers.openai.com/api/docs/guides/images-vision)及 [DeepSeek Vision 文档](https://api-docs.deepseek.com/guides/vision/)，核对日期 2026-11-15。长题截图按顺序分段，不静默截断；超过本地截图或发送限制会提示改用人工自评。请检查预览是否包含完整、清晰的图表及手写，横向滚动区以截图实际显示范围为准。

截图使用按需加载、本地固定版本的 html2canvas 1.4.1（MIT，许可证随组件保留），不使用远程截图服务，不放宽 CSP。题库的 Markdown、安全清洗和结构化答案不因手写功能改变。

自动化覆盖 Chromium 的触控点选与填写、鼠标笔迹、保存恢复、撤销、版面变化、API 发送确认与不自动记分；原生 iPad / Apple Pencil 的压感及掌触效果仍需真机体验验证。
